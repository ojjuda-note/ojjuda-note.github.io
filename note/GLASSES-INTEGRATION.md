# 공원 카드와 Even G2

공원에서 **G2 안경으로 보기**를 열고 Even Realities 앱 개발자 모드로 QR을 스캔한다. QR은 고정 HTTPS 주소 `https://ojjuda.kr/park/glasses.html?g2=1`만 담는다. 일반 브라우저는 같은 배치를 미리 보여 준다. 공식 SDK 0.0.16은 Pages 빌드에서 같은 출처의 `park/even-g2.bundle.mjs`로 묶인다. 이 경로는 개발용 QR 테스트이며 스토어 등록·실기 검증은 별도다.

렌즈 왼쪽 위에는 시간, 오른쪽 위에는 안경 배터리와 충전 중 번개, 오른쪽에는 카드 두 장이 표시된다. 왼쪽 아래는 기상청 관측 기온과 날씨, 오른쪽 아래는 위치 측정 속도(km/h)다. 값이 없거나 오래되면 대시를 표시한다. 카드 오른쪽 아래는 작성 위치까지의 거리 구간이다. 목록에서 스크롤로 이동하고 탭하면 원글과 공개 답카드 수가 보인다. 원글에서 아래로 넘기면 가까운 답카드부터 한 장씩 읽는다. 위로 넘기면 원글로 돌아가고 탭하면 목록으로 닫힌다. 두 번 탭하면 종료를 확인한다.

처음 열면 실제 공개 카드를 최신순으로 읽는다. **지역 선택**에서 시·군·구를 고르면 로그인이나 기기 위치 권한 없이 해당 지역의 기상청 관측 날씨와 지역 기준 30km 이내 카드를 본다. 비회원이 선택한 지역 이름은 다음 방문을 위해 기기에 기억한다. 가까운 카드가 없으면 최신 공개 카드와 해당 이유를 표시한다. 위치 기준이 없는 카드에는 거리를 붙이지 않는다. 공개 답카드는 공원 공개 범위 안에서 최신순으로 읽는다.

회원의 **내 위치로 보기**는 계정 위치 설정과 보호자 동의를 확인하고 기기 위치를 사용한다. 브라우저 권한이 이미 있으면 자동으로 시작한다. 원글과 답카드 모두 가까운 순으로 읽고, 거리 미확인 답카드는 마지막에 둔다. 위치를 끄면 기기 위치와 거리를 지우고 공개 카드로 돌아간다. 화면 숨김·계정 변경 시 측정을 중단한다. 예시 카드는 예시 보기를 선택했을 때만 사용한다.

지역 선택 지점은 기상청 단기예보 조회서비스의 행정구역별 격자·위경도 자료(2024-01-01)의 시·군·구 대표점이다. 날씨 요청에는 5km 격자만 전송한다. [기상청 단기예보 조회서비스](https://www.data.go.kr/data/15084084/openapi.do)
