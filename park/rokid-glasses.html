안경에서 가까운 공원 카드와 답카드를 읽어요.

안경에서 열기

처음에는 Hi Rokid와 같은 계정으로 공원을 등록하고 동기화해 주세요.

  1. Rokid AIUI Studio에 로그인한 뒤 Import from GitHub에서 공원 프로젝트를 가져오세요.
  2. Studio의 Build & Review → Package AIX를 누르세요.
  3. 휴대폰 Hi Rokid 앱에서 설정 → 개발자 → 안경 리소스 패키지 업데이트를 누르세요.

동기화가 끝나면 안경에 “Hi Rokid, 오쭈다 공원 열어 줘”라고 말해 보세요.

카드 읽기

안경 다리를 앞뒤로 쓸어 항목을 옮기고 한 번 탭해 카드와 답카드를 여세요. 뒤로 가면 읽던 화면으로 돌아옵니다.

개발자용 설치 파일

컴퓨터와 안경을 USB로 연결해 설치할 때 사용해요.
