## 앱 설치 아이콘 — 2026-11-20 이름 중심 디자인

아지트·공원·파장의 설치 아이콘은 **아지트·공원·파장이라는 한글 이름을 크게** 보여줍니다. 둥글고 굵은 글자에 크림색을 쓰고, 앱별 배경색과 작은 계절·행사 장식을 조합합니다. 웹 화면의 기존 로고와 공유 이미지는 별도로 유지합니다. `ops/render-brand.py`는 아래 PNG를 덮어쓰지 않습니다.

| 앱 | 일반 원본 | 마스킹용 원본 | 배포 폴더 |
| --- | --- | --- | --- |
| 아지트 | `app-icons/agit-1024.png` | `app-icons/agit-maskable-1024.png` | 저장소 루트 |
| 공원 | `app-icons/park-1024.png` | `app-icons/park-maskable-1024.png` | `park/assets/` |
| 파장 | `app-icons/pajang-1024.png` | `app-icons/pajang-maskable-1024.png` | `features/pajang/assets/` |

위 6개 파일도 현재 이름 중심 디자인의 **여름 기본 아이콘**으로 교체했습니다. 일반 원본은 여름 원본의 중앙 800×800을 잘라 1024×1024로 만든 파일이고, 마스킹용 원본은 여름 원본 전체입니다. 각 배포 폴더의 `icon-192.png`, `icon-512.png`, `apple-touch-icon.png`, `icon-maskable-512.png`는 아래 계절·기념일 생성 절차에서 그날의 테마로 만듭니다.

제작 원본과 미리보기는 [이름 중심 아이콘 안내](app-icons/wordmark/README.md)에 있습니다. `ops/render-wordmark-app-icons.py`가 Bagel Fat One에서 필요한 글자만 남기고 이름을 바꾼 OFL 글꼴을 SVG 윤곽선으로 변환합니다. 앱에서 별도 글꼴을 내려받지 않습니다. 색상표, 재생성 명령, 원본 글꼴 출처·해시·라이선스는 해당 안내를 따릅니다.

아지트의 기존 아이콘 경로와 manifest `id`·`start_url`은 유지합니다. 공원·파장은 각각 전용 manifest와 아이콘 경로를 사용합니다. 설치된 앱의 갱신 경로를 유지하기 위해 manifest URL의 `?v=20261119-illustrated-icons-1`도 바꾸지 않습니다. 아이콘 URL과 해당 아이콘을 사용하는 HTML·`shared/pwa/app-identity.js`·설치 안내의 revision만 함께 갱신합니다.

## 계절과 기념일 자동 아이콘

`app-icons/seasonal/<앱>/<테마>.png`의 불투명 1024×1024 이름 글자 원본 24개를 사용합니다. 앱별로 봄·여름·가을·겨울·새해·설·추석·크리스마스 8종입니다. 글자를 중심에 두고 장식이 글자를 가리지 않도록 구성합니다. 일반 아이콘은 중앙 800×800의 배경 여백을 정리한 뒤 비율 그대로 축소하고, 마스킹용은 전체 1024×1024를 축소합니다. 실제 마스킹과 작은 크기에서의 가독성은 미리보기로 검수합니다. 앱 아이콘·웹 탭·설치 안내에 같은 이미지를 적용합니다.

날짜 선택은 기존 `shared/app-icons/calendar.json`과 `selector.mjs`를 유지하며 한국 날짜를 기준으로 결정합니다. 행사는 본날 7일 전부터 시작합니다. 크리스마스는 12월 18~25일, 새해는 12월 25일~1월 1일, 설·추석은 D-7~D+1이며, 12월 25일은 크리스마스가 우선합니다.

Pages 배포는 `ops/build-seasonal-app-icons.mjs`로 선택한 이미지를 기존 아이콘 경로에 생성합니다. 매일 한국시간 자정에도 배포를 예약해 계절·행사 종료 후 다음 테마로 전환합니다. 같은 테마·같은 원본이면 icon revision을 유지합니다. 현재 배포 테마와 원본 해시는 `shared/app-icons/current.json`에 기록합니다. 운영과 확인 방법은 [계절·기념일 앱 아이콘 배포](../ops/SEASONAL-APP-ICONS.md)를 따릅니다.

공원은 `/park/`에서 `/world.html?place=park`로 이동하므로 World 진입 시 `app-identity.js`가 공원 메타데이터를 선택합니다. 파장의 두 HTML 진입점에도 같은 파장 manifest를 연결합니다. 이미 열린 앱의 정체성은 내부 탭 이동으로 바꾸지 않습니다. Android 네이티브 앱의 런처 아이콘은 별도 앱 패키지 업데이트가 필요합니다.

X 등 외부 서비스가 이미 저장한 페이지 제목과 미리보기는 사이트 배포만으로 즉시 바뀌지 않을 수 있습니다. 서버 원문 확인과 외부 서비스에서의 실제 미리보기 확인을 구분하며, 외부 확인 전에는 갱신 완료로 기록하지 않습니다.
