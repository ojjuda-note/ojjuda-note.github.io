# 파장 질문 작성 기준

- 사용자가 2026-11-22 지시한 목표는 답변에서 성격과 성향을 알아볼 수 있는 질문이다.
- 일상에서 겪을 수 있는 구체적인 상황과 평소의 생각·선택·행동을 묻는다. 음식·장소·물건의 단순 취향이나 시적인 상상을 질문의 중심에 두지 않는다.
- 대상과 상황을 문장 안에서 설명한다. 맥락 없는 ‘마지막 한 조각’, ‘그것’, ‘이 순간’처럼 독자가 추측해야 하는 표현을 쓰지 않는다.
- 소리 내어 말해도 자연스러운 쉬운 한국어를 쓴다. 한 문항은 한 가지만 묻고, 추상적인 비유·번역투·명사만 바꾸는 반복 문장을 피한다.
- 자유 답변을 기본으로 한다. 선택지를 제시할 때 어느 답도 도덕적으로 우월하게 보이지 않게 한다.
- 각 질문의 예시 3개는 해당 질문에 직접 답하는 서로 다른 자연스러운 대응이어야 한다. 성격 유형이나 진단 결과를 단정하지 않는다.
- 문장 길이와 문항 수 통과만으로 검수를 마치지 않는다. 문법, 상황의 현실성, 답변 연결성, 서로 비슷한 질문, 성격·행동 차이가 드러나는지를 사람이 읽듯 점검한다.
- 이미 답변한 질문의 의미를 덮어쓰지 않는다. 의미가 달라지는 개편은 새 ID로 제공하며 저장된 question_prompt와 답변 본문은 보존한다.
- 일반 질문의 분야를 번갈아 배치한다. 계절·기념일 질문에도 같은 품질 기준을 적용하고 기존 한국시간 오전·오후 및 계절 일정은 유지한다.
