# 우리집 가구 제작·배치 규칙

2026-10-02 수정. 사용자 지시: **3D를 사용하지 않고 배경과 가구를 모두 그림으로 만든다.** 이전 조립식 가구와 제작 파일은 제거한다. 바닥·벽 격자는 그림의 꼭지점과 위치·크기·원근을 맞추는 기준으로만 사용한다.

아래 아홉 가지를 적용한다.

1. **가구 뒤쪽 두 모서리를 격자 모서리에 맞춘다.**
2. **가구 특성에 따라 앞쪽에 여유를 둔다.** 책장은 폭·높이를 유지하고 깊이만 ⅔를 채운다.
3. **이미지 생성 단계에서 좌·정면·우 세 장을 각각 만든다.**
4. **모양과 색감은 기준 그림의 해당 가구 확대본과 직접 비교한다.** 기준 파일은 [home-style.png](references/home-style.png)다. 전체 방을 작게 본 상태로 디자인을 추측하지 않는다.
5. **밑면은 뜨거나 비뚤어지지 않게 놓고, 천장과 가구 윗부분의 기울기는 같은 높이의 벽 격자에 맞춘다.**
6. **벽 쪽과 방 중앙의 가구 모양은 위치·방향에 맞게 달라진다.** 보이는 면과 원근을 배치할 때마다 다시 계산한다.
7. **모든 가구는 제작 전에 기준 사진에서 해당 부분을 확대해 확인하고, 원본과 같은 모습으로 만든다.** 생성 전에 이 문서의 1~9번을 읽고, 해당 가구를 원본 픽셀 그대로 잘라 확대한 확인본을 실제로 본다. 형태·가로세로 비율·상판/판재 두께·다리 단면/벌어짐·손잡이·하부 구조·색·나뭇결을 확인한 뒤 제작 조건에 기록한다. 기준 사진의 보이는 형태를 임의로 바꾸거나 일반적인 가구 디자인으로 대체하지 않는다. 기준 확대본을 생성 참고로 직접 제공하고, 생성 결과도 확대본과 나란히 비교한 후 제작실 기준점을 등록한다. 크기·앞쪽 여유·세 방향·접지·기울기·위치별 표현도 함께 반영한다.
8. **검증은 최소화하고, 배치 후 확인하여 규칙에 맞게 제작되었는지 확인한 뒤 배포한다.** 실제 방에서 필요한 모습만 확인하고, 같은 검사를 반복하거나 확인 범위를 불필요하게 늘리지 않는다.
9. **다른 아이템들과의 충돌을 확인한다.** 실제 배치에서 다른 아이템과의 겹침·관통·배치 공간 충돌을 확인하고, 문제가 있으면 배포 전에 수정한다.

새 가구도 이 규칙으로 하나씩 제작하고, 실제 방에서 결과를 확인한 뒤 다음 가구로 넘어간다.

2026-10-03 사용자 재지시: **“앞으로 모든 가구는 만들기 전에 기준사진에서 확대해서 확인 후 똑같이 만들어.”** 가구마다 반복 확인을 요구하지 않으며 위 4·7번을 필수 선행 절차로 적용한다. 원본에서 보이는 부분은 그대로 유지하고, 소품에 가려진 부분을 복원했다면 원본에서 직접 확인한 세부라고 주장하지 않는다. 책·컵 등 소품은 테이블 원본에 붙여 그리지 않고 별도 편집 가능한 그림으로 제작한다.

## 소파·쿠션·담요 적용 지시 — 2026-10-02

사용자는 소파·쿠션·담요가 제작 프로그램에만 등록된 상태임을 안내받은 뒤 **“배포해”**라고 승인했다. 기존 운영 버전을 기준으로 해당 가구·소품과 필요한 앱 기능만 연결한다. 의자 시안과 제작 프로그램 전체는 이 변경에 포함하지 않는다.

- 소파는 좌측·정면·우측의 서로 다른 원본 그림을 사용한다. 팔·몸통은 원본 캔버스의 기준점을 공유한다. 쿠션은 소파 좌판의 부착 위치에 연속된 그림 면으로 투영하고, 모든 부위와 소품이 같은 부모 위치·방향과 방 좌표를 따른다.
- 쿠션 네 종류와 소파용 담요는 개별로 켜고 치울 수 있다. 소파와 함께 이동·방향 변경하며 배치 완료·취소의 적용 범위를 공유한다.
- 바닥용 담요는 별도의 바닥 그림 개체로 놓는다. 서 있는 가구보다 먼저 그려 의도적으로 가구 아래에 둘 수 있게 한다.
- 침대용 담요 그림을 바닥용이나 소파용으로 대신 사용하지 않는다. 침대 본체가 없는 현재 앱에서는 침대에 배치하는 기능을 제공했다고 보고하지 않는다.
- 기존 방·책상·책장·기록을 유지한다. 새 가구를 기존 저장의 모든 방에 자동 추가하지 않는다.
- 부위 가림과 소품 배치를 실제 세 방향에서 확인한다. 등록된 기준점 검증과 원본의 미관·형태 일치 판정을 구분한다.

## 담요·쿠션 겹침 수정 — 2026-10-02

- 소파용 담요를 사각형으로 줄인 뒤 소파 전체 삼각망으로 변형하지 않는다. 담요의 윗부분·좌판 접힘·늘어진 끝단을 담요 자체 기준으로 방 좌표에 연결한다.
- 담요의 좌판 위 부분은 쿠션 아래에, 내려오는 부분은 소파 앞에 그린다. 바닥 끝단은 별도로 바닥 높이에 연결한다.
- 쿠션은 고정 목록 순서로 그리지 않는다. 서로 다른 자리에서는 방향에 따라 먼 자리부터, 같은 자리를 공유하면 좌판의 뒤쪽부터 그린다. 복숭아색 작은 쿠션은 꽃무늬 쿠션 뒤에 유지한다.
- 제작기와 앱은 동일한 `sofa-blanket-drape.js`, `sofa-cushion-placement.js`를 사용한다. 제작기에서 저장·다시 열기·세트 내보내기를 거쳐도 담요 기준점과 쿠션 식별자를 보존한다.

## 1. 방과 좌표

- 방 바닥은 **가로 10칸 × 깊이 7칸**, 이동 단위는 **0.5칸**이다.
- 왼쪽 뒤 모서리가 `(0, 0)`, 오른쪽 앞 모서리가 `(10, 7)`이다.
- `model.js`의 `ROOM`, `FLOOR_CORNERS`, `CEILING_CORNERS`, `floorPoint`, `roomPoint`가 유일한 기준이다. 가구마다 별도의 카메라 각도나 화면 좌표 공식을 만들지 않는다.
- 현재 방 원본은 1507×1044px. 배치 영역 모서리는 뒤왼쪽 `(293,614)`, 뒤오른쪽 `(1209,614)`, 앞오른쪽 `(1494,910)`, 앞왼쪽 `(12,910)`이다. 벽 앞끝 밖의 원본 바닥 여분은 화면에서 잘라낸다.
- 천장 기준 모서리는 뒤왼쪽 `(293,200)`, 뒤오른쪽 `(1209,200)`, 앞오른쪽 `(1494,55)`, 앞왼쪽 `(12,55)`다. 방 높이는 4.5 높이 단위다. 바닥만으로 천장을 추정하지 않고 두 평면 사이의 같은 수직선으로 가구 높이를 계산한다.
- 편집 화면의 벽 격자와 가구 높이 점선은 가구와 같은 `roomPoint`를 쓴다. 가구 윗모서리는 해당 높이의 벽 격자에 맞고, 높이가 다른 천장선을 무조건 평행 복사하지 않는다.
- 낮·새벽/저녁·밤에도 방과 가구의 위치·크기·각도는 같다. 조명과 창밖만 바뀐다.

## 2. 배치 공간과 실제 밑면을 구분한다

| 항목 | 책장 기준 |
|---|---|
| 정면 배치 공간 | 2×1칸 |
| 옆 방향 배치 공간 | 1×2칸 |
| 실제 밑면 면적 | 배치 공간 면적의 **⅔** |
| 실제 정면 밑면 | 2×⅔칸 |
| 실제 옆 방향 밑면 | ⅔×2칸 |
| 본체 높이 | 3.8 높이 단위, 밑면 축소와 무관하게 유지 |
| 상단 상자 높이 | 본체 위 0.32 높이 단위 |

⅔는 책장의 **앞뒤 깊이 비율**이다. 폭과 높이는 유지하므로 밑면 면적도 배치 공간의 ⅔가 된다. 가로·깊이를 동시에 줄여 뒤 모서리가 격자 안쪽으로 들어가게 만들지 않는다.

- 뒤쪽 두 모서리는 배치 공간의 뒤 모서리와 일치한다. 정면은 뒤쪽, 왼쪽 방향은 왼쪽, 오른쪽 방향은 오른쪽이 가구의 뒤쪽이다.
- 책장은 앞쪽 ⅓을 비운다. 다른 가구는 특성에 맞는 `depthFill`을 검토 후 등록한다.
- 점선은 배치 공간, 실선은 실제 접지 밑면이다. 뒤쪽은 두 선이 일치하고, 앞쪽만 여유가 생긴다.
- 이동·회전·저장·확대 후에도 뒤 기준점, 폭, 높이, 앞쪽 여유는 유지된다.

## 3. 그림과 기준점

- 따뜻한 원목·크림색·부드러운 광원 등 확정된 참고 사진의 재질을 따른다.
- **좌·정면·우를 별도 파일 세 장으로 생성한다.** 한 장을 좌우 반전해서 다른 방향 이미지로 대신하지 않는다. 선택한 방향의 실제 이미지를 렌더러가 읽는다.
- 실제 투명 배경을 사용한다. UI, 방, 바닥 조각, 외부 그림자, 이웃 가구를 이미지에 포함하지 않는다.
- 이미지의 투명 여백이나 전체 사각형을 가구 크기로 사용하지 않는다. **발이 바닥에 닿는 위치**와 각 면의 모서리를 측정한다.
- 정면·측면의 원본 모서리 4개와 표시 마스크를 카탈로그 또는 가구별 기준점 파일에 등록한다. 2D 캔버스에서 원본 그림의 기준점을 방의 격자에 맞춘다.
- 책·손잡이가 있는 정면을 단순 좌우 반전하지 않는다. 카메라에서 보이는 면만 표시하고, 반대편은 목재 면으로 처리한다.
- 상단 상자도 승인한 같은 그림 안의 기준점을 등록한다. 새로운 도형이나 재질을 생성해 덧붙이지 않는다.
- 색상 검수는 기준 그림과 같은 낮 조명에서 한다. 원목의 노란색·붉은색 정도, 크림색 벽과의 조화, 연보라 포인트와의 조화, 밝기·채도·그림자 농도를 직접 나란히 비교한다. 세 방향의 재질과 색상이 달라지면 승인 전에 수정한다. 밤 필터를 씌운 결과를 낮 원본과 비교하지 않는다.
- 위치를 옮길 때 앞면·측면·윗면의 노출 여부와 너비, 상하 기울기를 다시 계산한다. 중앙에서 정면을 보는 경우와 좌우 벽 근처의 측면이 보이는 경우를 별도로 검수한다. 사용자 선택 방향은 유지하며, 위치에 따라 몰래 가구를 회전시키지 않는다.
- 가구별 임의 CSS 확대·기울이기·아래 중심점 맞추기는 금지한다.
- 완성 그림의 실제 픽셀을 2D 캔버스에 그린다. 기본 위치에서는 전체 이미지를 그대로 쓰고, 옮기면 연결된 기준점에 따라 이미지 원근만 변환한다. CSS 3D 변환, 도형 부품 조립, 모델, 조명·재질 엔진은 쓰지 않는다. 원본 픽셀을 보존한 투명 그림 부위를 겹치는 방식은 사용한다.
- 배경은 낮·새벽/저녁·밤의 `room-*-v3.webp`, 커튼은 `curtains.webp`, 책장은 승인한 `bookshelf-{left,center,right}-v2.webp`를 사용한다.
- 이전 책상·의자·협탁·화분의 조립 코드, 이미지, 제작 기록과 책장 v1 이미지를 제거했다. 새 가구는 같은 기준 그림에서 하나씩 다시 제작하고 확인받는다.

## 4. 배치·회전·저장

- `normalizePlacement` 하나로 0.5칸 반올림과 방 경계를 처리한다.
- 회전하면 가로·깊이만 교환한다. 실제 면적과 높이는 유지한다.
- `canPlaceFurniture`는 같은 높이 분류의 **배치 공간**이 겹치는지 검사한다. 실제 밑면 바깥의 여유 공간까지 다른 가구로 채우지 않는다.
- 작은 바닥 장식·러그 등 겹칠 수 있는 항목은 별도 분류로 등록한 후 검토한다. 현재 승인한 책장과 서랍 책상이 바닥 가구로 등록되어 있다.
- 편집 중 변경은 임시 상태이며, **배치 완료**에서만 저장한다. 취소·다른 메뉴 이동은 원래 상태로 돌아간다.
- 저장값은 칸 좌표와 방향이다. 화면 픽셀이나 현재 확대율을 저장하지 않는다.
- 기존 8칸 방 저장은 새 10칸 방으로 한 번만 옮긴다. 좌우 벽에 붙인 책장은 벽 위치를 유지하고, 가운데 가구는 한 칸 옮겨 중앙을 유지한다.

## 5. 제작·확인·배포 순서

1. **제작 전:** 위 1~9번을 읽고 기준 사진에서 해당 가구 부분을 실제로 확대해 확인한다. 원본의 형태·비율·두께·다리/손잡이/하부 구조·색·재질을 기록하고 확대본을 직접 참고해 제작한다. 확대 확인 없이 생성부터 시작하지 않는다.
2. **제작 후:** 실제 방에 배치한다. 책장은 왼쪽 벽·중앙·오른쪽 벽의 대표 배치를 확인한다.
3. **배치 확인:** 뒤 모서리 정렬, 앞쪽 여유, 세 방향 이미지, 기준 색감, 바닥 접지·윗면 기울기, 위치에 따른 보이는 면과 다른 아이템과의 충돌이 규칙에 맞는지 확인한다.
4. **필요한 부분만 검증:** 이상이 있거나 배치·저장 코드를 바꾼 경우 그 부분만 추가 확인한다. 가구 하나를 만들 때마다 모든 좌표·시간대·화면 크기의 전체 검사를 반복하지 않는다. 배포 시스템이 요구하는 기존 검사는 따른다.
5. **사용자 확인 후 배포:** 완성 결과를 먼저 보여주고 사용자 승인을 받은 뒤 배포한다. 이미 승인한 변경은 중복으로 승인받지 않는다. 다음 가구는 그다음에 진행한다.
