적용하면 이 기기의 우리집에 새 아이템으로 등록돼요. 원본 가구 목록은 유지됩니다.

그림 넣기 → 자동 준비

그림을 넣으면 방향·부위 구성을 준비합니다. 실제 윤곽과 격자는 확인이 필요해요.

1그림 준비

종류·용도를 바꾸면 작업 설정만 바뀝니다. 다른 걸침 모양은 아래 그림 세트를 선택해 불러오세요.

개체 하나에 좌측·정면·우측 그림이 들어 있습니다. 격자 기준점은 아직 등록하지 않은 그림입니다.

PNG · JPG · WebP
원본 그림의 방향을 선택해 넣으세요. 좌측·정면·우측 그림을 각각 불러와 주세요.

2필요하면 그림 정리

가구 둘레를 찍고 윤곽을 완성하면 주변 그림이 지워집니다.

3부위와 사이 물건

같은 방향의 완성 그림을 먼저 준비하세요. 윤곽으로 보이는 부위를 나누고, 가려진 부분만 별도 그림으로 보완하세요. 숨은 부분을 자동으로 그리지는 않습니다.

물건은 원본 그림 안에 놓입니다. 격자에 연결하면 부위와 물건 전체가 한 개체로 함께 움직입니다.

4꼭지점과 면

발 접지점·봉제선 끝·곡선 외곽을 그림에서 찍고, 각 점의 방 좌표를 입력하세요. 여백 모서리를 발 위치로 쓰지 마세요.

한 면의 모서리를 1 → 2 → 3 → 4 둘레 순서로 찍으세요. 점은 끌어서 고칠 수 있습니다.

5함께 이동 · 방 확인

크기는 세 방향에 함께 적용됩니다. 단위는 우리집 격자 한 칸입니다.

서랍장 안쪽 면처럼 들어간 부분은 격자에 맞춘 뒤 거리를 조절하세요.

그림 ZIP은 입력한 세 원본과 작업 파일을 저장합니다. 기준점·격자·가구 배치 검증을 대신하지 않습니다.

격자 연결 세트에는 배치 각도의 PNG와 작업 파일이 담깁니다. 작업 중에는 세트 저장을 사용하세요.

자동 임시저장 대기

그림 넣기 → 자동 준비 → 확인·저장

하나의 개체를 세 방향으로 만듭니다. 소파 본체·쿠션·담요는 각각 다른 세트로 저장하세요.
