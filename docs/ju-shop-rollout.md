## 구현한 1차 범위

- 월드·공원 메뉴의 쭈 상점. 서버가 정한 가격만 사용한다.
- 마음 스티커 6종 5쭈 영구, 책갈피 글꼴 3종 5쭈/월, 금빛 카드 효과 10쭈/월.
- 꽃빛·민트 프로필 테두리 각각 5쭈/월, 별빛 이름 장식 5쭈/월.
- 밤하늘 오락실 테마 5쭈 영구. 게임 바깥 화면·헤더 꾸미기이며 점수·게임 규칙에 영향을 주지 않는다.
- 서버 구매 원장과 소유권을 한 트랜잭션으로 기록한다. 같은 요청 재전송은 추가 차감하지 않는다. 아직 유효한 상품을 다시 구매해도 추가 차감·기간 연장하지 않는다.
- 나사 상자 3쭈, 보관칸 1쭈. 평면 나사 구멍·이동 횟수 가격은 각각 1쭈 유지.
- 틀린그림찾기 힌트 1쭈, 30초 연장 1쭈. 화면에서 한 판당 힌트 2회·연장 1회로 제한하고 도움을 사용한 판은 점수를 제출하지 않는다.
- 게임 구매는 v2 RPC로 분리해 캐시된 구버전 화면과 구매 영수증을 보존한다. 이전 3쭈 시간 연장 영수증은 60초로 복구한다.
- 구매 중 계정 변경, 잔액 부족, 만료, 중복 클릭, 응답 유실 후 복구를 검사한다.
