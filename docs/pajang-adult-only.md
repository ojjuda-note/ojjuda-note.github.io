# 파장 성인 전용 운영

2026-11-22 지시에 따라 파장은 **만 19세 이상 회원만 이용하는 소개팅·소통 서비스**로 운영합니다.

- 기존 파장 가입·질문·답변·채팅·신호·사진/프로필 교환과 성인 회원 데이터는 보존합니다.
- 가입 시 확인한 생년월일과 계정 권한을 서버에서 검증하며, **19세 미만·나이 미확인·차단 계정**은 성인 기능을 이용할 수 없습니다.
- 실서비스에 노출되지 않았던 청소년용 질문 20개, 답변·댓글·공감·신고·관리 화면 및 API는 완전히 종료합니다. 삭제 전에 확인한 청소년 회원 게시물·신고·차단 기록은 모두 0건입니다.
- 과거 DB 마이그레이션 파일은 **재현성과 감사 이력을 위해 보존**하되, 마지막 제거 마이그레이션이 최종 상태에서 청소년 스키마와 API를 삭제합니다.
- 아지트·공원 등 다른 서비스의 만 14세 이상 가입 정책과 아동 안전 신고 기준은 변경하지 않습니다.

관련 검증: `tests/pajang-adult-endpoint-guards-db.test.cjs`, `tests/pajang-adult-only-retirement.test.cjs`.
