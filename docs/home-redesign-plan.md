# 우리집 개편 — 작은 단계로 진행

2026-10-04 사용자와 확인한 화면 및 기능. 크림색 배경, 연보라 포인트와 기존 오쭈다 테마를 유지한다. 각 단계는 수정·검사를 끝낸 뒤 결과를 공유한다.

## 1단계 — 상단 프로필과 방 미리보기

- 왼쪽: 프로필 사진 자리 → 실제 닉네임 → 한줄소개.
- 오른쪽: 글씨 없는 실제 방 미리보기. 누르면 기존 방 화면으로 진입.
- 내 기록으로 돌아오면 다시 상단 요약과 기록을 표시한다.
- 기존 방 배치, 글, 앨범 저장 방식을 유지한다.
- 현재 World 프로필에는 사진 필드가 없으므로 이 단계는 기본 프로필 아이콘을 표시한다. 사진 업로드·저장은 후속 단계에서 구현한다.
- 구현: `world.html`, `house-test/host.js`, `house-test/app.js`, `house-test/index.html`, `house-test/style.css`.
- 검사: `tests/house-home-summary-ui.test.cjs`, 기존 기록·앨범·World 탐색/관리자 화면 검사.

## 2단계 — 작은 탭·폴더와 기록 목록

- 전체·게시판·사진·동영상 탭을 파일철 모양으로 줄였다. 첫 화면은 전체다.
- 전체는 기존 계정 앨범의 사진·동영상을 함께 최신순으로 조회한다. 페이지를 넘겨도 혼합 정렬과 계정 구분을 유지한다.
- 폴더 선택을 작은 둥근 네모 버튼으로 바꾸고 전체·저장된 폴더·미분류·+ 새폴더 순서로 표시한다. 사진/동영상 탭을 바꿔도 선택한 폴더를 유지한다.
- 익명·친구·여행은 사용자가 + 새폴더에서 만들 수 있는 이름이다. 기존 폴더를 바꾸거나 예시 폴더를 계정에 자동 생성하지 않는다.
- 모든 기록 행은 112px로 통일하고 글은 왼쪽, 76px 썸네일은 오른쪽에 둔다. 긴 글은 줄여 표시하고 썸네일을 누르면 원본과 전체 설명을 연다.
- 기존 기기 보관 글은 요약 행으로 보이고 게시판에서 편집한다. 서버 게시판의 다중 글 저장·폴더 연결은 아직 추가하지 않았다. 서버 앨범과 기기 보관 사진/영상은 저장 위치를 표시해 구분한다.
- 기존 저장·폴더 공개범위 편집·파일 설정·계정 격리·기기 미디어 저장 방식은 유지한다. 새 친구 그룹 권한이나 폴더 삭제는 이번 단계에 포함하지 않는다.
- 검증: 앨범 UI 320/390/1280px, 탭/폴더 크기, 행 높이와 좌우 배치, 혼합 목록·원본 보기·폴더 선택 유지, 혼합 페이지 조회, 기존 기록/상단 배치/계정·저장 실패 검사.

## 3단계 첫 순서 — 설정과 안전한 폴더 관리

- 동영상 바로 옆 톱니바퀴에서 폴더 만들기·이름 변경·삭제와 사진/동영상 선택·이동을 연다.
- 폴더 삭제는 서버에서 하나의 작업으로 처리한다. 사진/동영상 원본과 정보는 지우지 않고 미분류·나만 보기로 옮긴다. 취소 또는 실패하면 기존 상태를 유지한다.
- 선택한 사진/동영상은 한 번에 최대 100개까지 이동한다. 전부 내 자료인지, 대상 폴더가 내 것인지 서버에서 확인하며 하나라도 실패하면 전체 이동을 취소한다.
- 게시물의 설명과 개별 폴더/공개범위 수정은 기존 기능을 유지한다. 폴더 관리 이후 World 캐시도 같은 내용으로 갱신한다.
- 서버 함수는 SECURITY INVOKER로 기존 RLS를 적용하며 비로그인·정지 계정·다른 계정의 폴더/파일 접근을 거부한다. 새 데이터 열이나 전체 자료 변경은 없다.
- 기존 World 앨범의 폴더 삭제도 같은 안전한 서버 작업을 사용한다.
- 검사: 실제 PostgreSQL 엔진 기반 권한/일괄 처리/실패 롤백 검사, 모바일 설정·키보드 닫기·폴더 이름/삭제 취소/실패 재시도·페이지 선택 유지·기존 기록 보존 검사.

## 3단계 다음 순서 — 계정 게시판과 휴지통

- 전체·게시판에서 여러 글을 계정에 저장·수정한다. 글은 폴더에 연결하고 기존 폴더 공개범위를 따른다. 긴 글은 같은 높이의 목록에서 요약하고 누르면 전문을 연다.
- 기기에 보관한 기존 글은 그대로 유지한다. 별도 복사 버튼으로 게시판에 옮겨 적을 수 있고 원본을 자동으로 지우지 않는다. 작성 중인 글은 우리집 안에서 탭을 바꿔도 유지한다.
- 글·사진·동영상을 함께 선택해 폴더 이동 또는 휴지통 보관을 한다. 서버에서 전체 성공 또는 전체 취소로 처리한다.
- 톱니바퀴의 휴지통에서 원본을 확인하고 복원한다. 복원은 미분류·나만 보기로 하며 본문·원본 파일·작성 시각을 유지한다. 이 단계에서는 영구 삭제나 자동 만료를 추가하지 않는다.
- 미디어는 별도 소유자 전용 휴지통 표로 옮기고 실제 저장소 파일을 삭제하지 않는다. 기존 World/Note 앨범 조회에서도 삭제한 파일이 빠진다. 이미 발급된 미디어 서명 URL은 기존 유효기간까지 남을 수 있다.
- 새 게시판/휴지통 표에 RLS를 적용하고 통합 목록 뷰는 security_invoker를 사용한다. 비로그인·정지 계정·다른 계정 수정, 다른 계정 휴지통 열람을 차단한다.
- 검증: 실제 PostgreSQL 권한·친구/폴더/방 공개범위·실패 롤백·복원 충돌 자료 보존, 모바일 혼합 목록·작성 실패/탭 이동·휴지통 취소/재시도·계정 전환을 확인한다.

## 4단계 — 친구 그룹과 폴더 공개범위

- 우리집 톱니바퀴의 친구 그룹에서 만들기·이름 변경·구성원 선택·삭제를 한다. 실제 친구만 선택하며 그룹 이름/구성원 표는 소유자만 읽고 바꿀 수 있다.
- 폴더 공개범위는 전체 공개·친구 공개·선택한 친구·그룹·나만 보기다. 선택 공개에서는 여러 그룹과 개별 친구를 함께 선택할 수 있다. 아무도 선택하지 않거나 빈 그룹만 선택하면 소유자만 본다.
- `chosen`이라는 기존 공개범위 값과 개별 친구 목록은 유지하고 `allowed_groups`를 추가한다. 그룹원을 개인 선택 목록에 복사하지 않고 열람 시점에 실제 구성원을 확인한다. 그룹에서 빼거나 친구가 해제되면 폴더의 글·사진·동영상과 새 원본 URL 요청에 대한 권한이 사라진다. 이미 발급된 서명 URL은 기존 유효기간(우리집 15분)까지 남을 수 있다.
- 그룹 삭제는 해당 폴더 선택만 원자적으로 해제한다. 친구 관계·폴더·게시물·원본 파일은 지우지 않는다. 마지막 선택을 없애도 전체 공개로 바뀌지 않는다. 오류가 나면 그룹 삭제와 폴더 변경을 함께 취소한다.
- 공개 표와 쓰기 함수는 RLS 및 SECURITY INVOKER를 사용한다. 소유자 전용 그룹을 폴더 RLS에서 확인하는 읽기 보조 함수만 비노출 스키마의 SECURITY DEFINER를 사용하며, 호출자의 실제 계정 이외 열람자 ID는 거부한다.
- 검증: 실제 PostgreSQL의 개별/그룹 합집합 열람·친구 해제·닫힌 방·다른 계정/비로그인 거부·직접 API 검증·삭제 실패 롤백. 모바일 320/390/1280px, 여러 그룹 선택·편집·삭제 취소/재시도·빈 선택·계정 전환과 기존 게시판·앨범 동작.

## 5단계 — 생활 화면과 메뉴 이동

- 하단과 데스크톱 메뉴를 동네·우리집·생활·메뉴 순서로 통일했다. 생활 한 화면에 주소록·가계부·계산기를 순서대로 펼쳐 사용한다.
- 우리집 기록 화면에서 왼쪽으로 밀면 생활로 이동한다. 방 꾸미기, 입력 중인 폼, 원본 보기 창과 가로 스크롤 폴더에서는 해당 조작을 우선한다. 세 도구를 별도 스와이프 페이지로 분리하지 않는다.
- 주소록의 직접 입력·검색·전화 연결·삭제, 가계부 수입/지출 입력·월별 합계·내역 삭제, 기본 계산기를 연결했다. 예시 연락처나 금액은 생성하지 않는다.
- 주소록/가계부는 로그인한 계정별로 현재 브라우저에 저장한다. 화면에서 다른 기기와 자동 동기화되지 않음을 알린다. 서버 저장이나 휴대폰 연락처 가져오기는 아직 추가하지 않았다.
- 저장 실패 시 입력을 유지하고 기존 자료를 덮어쓰지 않는다. 다른 계정으로 전환하면 목록을 분리하며, 작성 중인 입력은 같은 계정으로 탭을 오갈 때 유지한다.
- 검증: 4개 메뉴 한 줄 배치, 320/390/1280px, 브라우저/앱 뒤로가기, 실제 터치로 우리집→생활 이동 및 방 조작 보호, 저장 실패·중복 전화번호·월별 합계·새로고침 보존·계정 구분·계산 오류 처리.

## 이후 순서

6. 동네의 친구찾기: 기존 검색·신청 기능을 먼저 확인하고 필요한 배치와 검색 항목을 보완한다.
7. 생활 도구 확장: 휴대폰 연락처 가져오기와 서버 저장·기기 간 동기화. 직접 입력과 현재 기기 저장은 5단계에서 제공한다. 주소록의 휴대폰 연락처 가져오기는 사용자가 선택·허용한 이름/전화번호만 가져오고 중복을 정리한다. 웹 지원 여부를 확인하며 전체 자동 동기화를 약속하지 않는다.

## 시안과 운영

대화 속 시안의 예시 회원·친구·연락처를 운영 데이터로 옮기지 않는다. 운영 반영 상태와 검사 완료 상태를 구분해 알린다.
