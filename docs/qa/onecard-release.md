# 원카드 2.0.0 검수 · 2026-11-20

## 이번 변경

- 모든 새 판은 5자리다. 혼자는 나와 컴퓨터 4명, 멀티는 로그인 회원 1~5명과 나머지 컴퓨터로 시작한다. 방장 혼자도 시작할 수 있다.
- 매 새 판에 사람과 컴퓨터를 함께 무작위로 섞고 첫 차례를 정한다. 화면에서는 항상 내가 아래에 보이며, 게임 순서는 시계 방향으로 고정한다.
- 멀티에서 나간 회원의 자리와 손패는 컴퓨터가 이어받는다. 탈락자는 되살리지 않는다. 사람이 모두 나가면 방을 닫는다.
- 시작 화면은 `shared/games/game-entry.css`, 결과 화면은 `shared/games/game-results.css`를 직접 사용한다. 솔리테어·사천성·윷놀이와 같은 색, 글꼴, 패널, 버튼 구성을 따른다.
- 결과는 아이콘 → 제목 → 승자 → 안내 → 세 버튼 → 5명 카드 수 순서다. 다시 하기/대기실, 게임판 보기, 오락실로 이동할 수 있다.
- 게임 2.0.0, 오락실 메뉴 1.1.1, 게임 리비전 `20261120-onecard3`. 아지트와 공원 버전은 변경하지 않는다.

## 규칙

각자 7장. 같은 무늬나 숫자를 한 장씩 낸다. 2는 +2, A는 +3, 검정/빨강 조커는 +5/+7. 공격 중에는 공격 카드끼리 무늬와 관계없이 누적할 수 있다. 7과 조커는 무늬를 고른다. J는 다음 사람 건너뛰기, K는 한 번 더, Q는 일반 카드다. 방향을 뒤집는 카드는 없다.

받으면 차례가 끝난다. 원카드는 2장일 때 미리 외치거나 1장이 된 직후 외친다. 다음 사람이 행동할 때까지 외치지 않으면 2장 벌칙을 받는다. 20장 이상이면 탈락하며, 마지막 카드를 내면 즉시 승리한다. 멀티의 사람 차례는 30초이며 첫 배분에는 5초를 더 준다.

## 화면과 소리

배경은 은은한 2D 테이블, 카드는 벡터 무늬·입체 테두리·그림자로 표현한다. 35장 배분과 첫 펼친 카드 1장은 하나의 Web Animations 타임라인에서 62ms 간격으로 겹쳐 출발한다. 움직임은 transform/opacity로 처리하고 카드마다 서버에 요청하지 않는다. 배분 중에는 입력을 잠근다.

효과음은 기존 CC0 카드/테이블 실물 녹음을 사용한다. 전자음 합성은 없다. 효과음 켜기/끄기와 움직임 줄이기를 지원한다.

680×469 공개 화면에서 확인한 중앙 카드 라벨·무늬 표시 겹침을 수정했다. 짧은 가로 화면은 무늬·진행 방향을 카드 오른쪽에 둔다. 시작 화면과 방 대기실도 짧은 가로 화면에서 두 열로 정리한다.

## 서버와 저장

- 기존 마이그레이션 `20261119180311_onecard_online_rooms.sql`은 수정하지 않는다. 새 변경은 `20261119190634_onecard_fixed_five_computer_seats.sql`에 둔다.
- 방 회원 목록은 사람의 UUID와 방장 권한을 관리한다. 실제 경기의 5자리 순서와 분리하며 모든 차례 권한은 플레이어 ID로 확인한다.
- 컴퓨터는 자기 손패와 공개 정보만 보고 서버에서 행동한다. 컴퓨터 차례는 약 1.6초 간격이며 첫 차례는 배분을 위해 5초 기다린다. 한 요청에서 자동 행동은 최대 한 번이다.
- 동시에 여러 화면이 요청해도 상태 버전 비교(CAS)로 한 동작만 반영한다. 요청 중복 방지, 본인 확인, 차단·정지, 방장 이전, 만료와 새로고침 복구를 유지한다.
- `ojjuda_onecard_internal.rooms`는 RLS가 켜진 비공개 테이블이다. anon/authenticated는 테이블과 서비스 RPC를 직접 사용할 수 없다. JWT를 확인한 Edge Function만 서비스 RPC를 호출한다.
- 이전 2~4자리 온라인 판이 있다면 그 손패를 유지해 마친 뒤 다음 판부터 5명으로 시작한다. 로컬 이어하기는 기존 5자리 저장만 지원하며, 다른 저장을 자동 삭제하지 않는다.
