# 원카드 2.2.0 검수 · 2026-11-20

## 이번 변경

- 오락실에서는 원카드를 **함께하는 플레이에만** 표시한다. 혼자 하기는 원카드에 들어간 뒤 컴퓨터 대전에서 선택한다.
- 모든 새 판은 5자리다. 혼자는 나와 컴퓨터 4명, 멀티는 로그인 회원 1~5명과 나머지 컴퓨터로 시작한다. 방장 혼자도 시작할 수 있다.
- 매 새 판에 사람과 컴퓨터를 함께 무작위로 섞고 첫 차례를 정한다. 화면에서는 항상 내가 아래에 보이며, 처음은 시계 방향이다. 방향 바꾸기 카드를 내면 현재 진행 방향이 뒤집힌다.
- 멀티에서 나간 회원의 자리와 손패는 컴퓨터가 이어받는다. 탈락자는 되살리지 않는다. 사람이 모두 나가면 방을 닫는다.
- 시작 화면은 `shared/games/game-entry.css`, 결과 화면은 `shared/games/game-results.css`를 직접 사용한다. 솔리테어·사천성·윷놀이와 같은 색, 글꼴, 패널, 버튼 구성을 따른다.
- 공통 대문에서 컴퓨터 대전과 온라인 대전을 고른다. 온라인은 실제 `OjjudaArcadeRooms`의 방 제목 양식과 방 목록을 재사용하며, 만든 방은 오락실 전체 대전방에서도 생성·참여·취소·이어하기가 가능하다. 기존 코드방 입력은 첫 화면에서 제거하고 초대 링크를 유지한다.
- 결과는 아이콘 → 제목 → 승자 → 안내 → 세 버튼 → 5명 카드 수 순서다. 다시 하기/대기실, 게임판 보기, 오락실로 이동할 수 있다.
- 바닥 카드는 다음 카드가 착지할 때까지 유지한다. 애니메이션 취소·화면 복귀·온라인 상태 재동기화 뒤에도 최신 펼친 카드가 남아 있어야 한다.
- 손패는 페이지를 나누지 않는다. 전체 패를 카드 영역에서만 좌우로 밀거나 마우스로 끌어 확인하며, 숫자순·색상순 버튼은 표시 순서만 바꾼다. 드래그를 끝낼 때 카드를 잘못 내지 않아야 한다.
- 오락실·대전방·사용법의 원카드 그림은 `assets/design/games/onecard.webp`를 사용한다. 기존 게임 그림과 같은 480×320 크기이며, 입체 카드 네 장에 숫자·공격·방향 바꾸기를 표현한다.
- 로그인한 컴퓨터 대전과 온라인 대전은 같은 월간 연승으로 기록한다. 공통 게임순위·월간 상세 순위에 원카드를 추가하고, 결과에 현재 연승·이번 달 최고 연승·저장 여부를 표시한다.
- `guide.html`에 시작 방법, 카드 규칙, 손패 드래그·정렬, 방향 바꾸기와 연승 집계 조건을 추가한다. 원카드는 함께하는 플레이에 한 번만 표시한다.
- 게임 2.2.0, 엔진 1.3.0, 게임 리비전 `20261120-onecard7`. 원카드 메뉴·순위를 바꾸므로 오락실 버전은 1.3.0으로 올린다. 아지트·공원 버전은 유지한다.

## 규칙

오쭈다 전용 4색 카드 54장을 사용하고 각자 7장을 받는다. 숫자는 1~7이며 같은 색이나 숫자·기호를 한 장씩 낸다. +2·+3 및 전체 색 +5·+7은 표시된 수만큼 공격한다. 공격 중에는 직전에 놓인 공격 카드와 같거나 더 큰 숫자의 공격 카드만 이어 낼 수 있다. 색은 달라도 되며, 받아야 할 누적 장수와 비교하지 않는다. 예를 들어 +2 다음 +3은 가능하지만 +5 다음 +2·+3은 불가능하다. 컴퓨터와 온라인 서버도 같은 규칙을 사용한다. 색 바꾸기와 전체 색 공격은 다음 색을 고른다.

건너뛰기는 현재 방향의 다음 사람을 건너뛰고, 한 번 더는 내 차례를 유지한다. 방향 바꾸기는 시계·반시계 방향을 뒤집으며, 두 명만 남아도 상대에게 차례를 넘긴다. 탈락한 자리는 모든 방향에서 건너뛴다. 방향 바꾸기는 색마다 한 장씩 네 장이며, 서로 반대인 두 화살표와 한글로 표시한다. 기존 `Q` 카드 ID를 방향 바꾸기로 사용하지만 화면에는 트럼프 문자를 표시하지 않는다. 다른 카드 ID와 54장 덱 구조를 보존한다.

받으면 차례가 끝난다. 원카드는 2장일 때 미리 외치거나 1장이 된 직후 외친다. 다음 사람이 행동할 때까지 외치지 않으면 2장 벌칙을 받는다. 20장 이상이면 탈락하며, 마지막 카드를 내면 즉시 승리한다. 로그인한 컴퓨터·온라인 대전의 사람 차례는 30초이며 첫 배분에는 5초를 더 준다.

## 화면과 소리

배경은 산과 나무, 텐트와 랜턴을 담은 은은한 2D 캠핑장이다. 정적인 벡터 장면을 사용해 카드 이동 중 배경이 계속 다시 그려지지 않게 한다. 공통 시작·결과 화면 구성은 유지한다. 전용 카드는 파랑·빨강·노랑·초록의 큰 숫자와 동작 기호, 두께·종이 질감·입체 테두리·그림자로 표현한다. 트럼프 문양·문자·궁정·조커 그림을 사용하지 않는다. 색별 도형도 함께 표시한다. 35장 배분과 첫 펼친 카드 1장은 하나의 Web Animations 타임라인에서 62ms 간격으로 겹쳐 출발한다. 움직임은 transform/opacity로 처리하고 카드마다 서버에 요청하지 않는다. 배분 중에는 입력을 잠근다.

효과음은 기존 CC0 카드/테이블 실물 녹음을 사용한다. 전자음 합성은 없다. 효과음 켜기/끄기와 움직임 줄이기를 지원한다.

680×469 공개 화면에서 확인한 중앙 카드 라벨·색 표시 겹침을 수정했다. 짧은 가로 화면은 색·진행 방향을 카드 오른쪽에 둔다. 시작 화면과 방 대기실도 짧은 가로 화면에서 두 열로 정리한다.

## 서버와 저장

- 기존 마이그레이션 `20261119180311_onecard_online_rooms.sql`은 수정하지 않는다. 5인 규칙은 `20261119190634_onecard_fixed_five_computer_seats.sql`, 공통 대전방 목록은 `20261119193643_onecard_native_arcade_rooms.sql`에 둔다. 공통 방번호를 사용하고 목록에는 손패나 회원 UUID를 내보내지 않는다.
- 새 마이그레이션 `20261119212348_onecard_streak_rankings_and_reverse.sql`이 방 모드·결과 원장·공통 월간 순위 연결과 양방향 턴 상태 검증을 추가한다. 기존 RPC 인자와 다른 게임의 순위 기준은 유지한다.
- 방 회원 목록은 사람의 UUID와 방장 권한을 관리한다. 실제 경기의 5자리 순서와 분리하며 모든 차례 권한은 플레이어 ID로 확인한다.
- 컴퓨터는 자기 손패와 공개 정보만 보고 서버에서 행동한다. 컴퓨터 차례는 약 1.6초 간격이며 첫 차례는 배분을 위해 5초 기다린다. 한 요청에서 자동 행동은 최대 한 번이다.
- 동시에 여러 화면이 요청해도 상태 버전 비교(CAS)로 한 동작만 반영한다. 요청 중복 방지, 본인 확인, 차단·정지, 방장 이전, 만료와 새로고침 복구를 유지한다.
- `ojjuda_onecard_internal.rooms`는 RLS가 켜진 비공개 테이블이다. anon/authenticated는 테이블과 서비스 RPC를 직접 사용할 수 없다. JWT를 확인한 Edge Function만 서비스 RPC를 호출한다.
- 로그인한 컴퓨터 대전은 비공개 `solo` 방에서 서버가 진행한다. 공개 방 목록에서 숨기고 코드 참여를 거절하며, 본인만 이어할 수 있다. 온라인은 기존 `multiplayer` 모드와 공통 대전방을 유지한다.
- 로그인 확인이 실패하면 연습으로 자동 전환하지 않는다. 사용자가 직접 연습을 선택할 수 있으며, 화면에서 순위 제외 상태를 안내한다. 비로그인 플레이와 이전 로컬 저장 이어하기도 연습으로 구분한다.
- 이전 2~4자리 온라인 판이 있다면 그 손패를 유지해 마친 뒤 다음 판부터 5명으로 시작한다. 로컬 이어하기는 기존 5자리 저장만 지원하며, 다른 저장을 자동 삭제하지 않는다. 이전 로컬 저장은 순위로 소급하지 않는다.

## 연승 집계

- 서버에서 실제 5인 판이 `active`에서 `finished`로 끝날 때만 결과 원장에 기록한다. 방·판 번호·회원의 고유 키로 같은 결과를 한 번만 넣는다.
- 로그인한 컴퓨터 대전과 온라인 대전의 완료 결과를 시간순으로 함께 센다. 승리하면 현재 연승이 늘고, 패배·무승부·20장 탈락으로 마친 판은 현재 연승을 0으로 만든다. 그달 최고 연승은 남는다.
- 끝나기 전에 나갔거나 컴퓨터가 이어받은 자리는 해당 회원의 기록에서 제외한다. 사람이 모두 나가 닫힌 미완료 판과 비로그인·로컬 연습은 기록하지 않는다. 이미 끝난 판의 결과를 뒤늦게 나가기로 취소할 수 없다.
- 기존 공통 순위처럼 한국 시간 매월 1일 오전 1시를 월 경계로 사용한다. 같은 최고 연승은 먼저 달성한 사람이 앞서고, 0연승은 순위에서 제외한다. 10위 밖의 내 순위·차단·정지·회원 공개 범위는 공통 정책을 따른다.
- `ojjuda_onecard_internal.results`는 직접 읽거나 쓸 수 없는 비공개 원장이다. 결과 응답에는 해당 회원의 저장 완료 여부·현재 연승·월 최고 연승만 담는다. 과거 미기록 경기는 추정하거나 소급하지 않는다.

## 배포 경로

공개 주소 `/games/onecard/index.html`, 짧은 주소 `/onecard/`. 기존 GitHub Pages 자동 배포와 Supabase `onecard` 함수를 사용한다. 초기 출시 PR은 #1377이며 이번 변경은 별도 PR로 검수·배포한다.

배포 순서는 새 DB 마이그레이션 → 동일 엔진의 `onecard` Edge Function → 프런트엔드다. 로그인 컴퓨터 방은 서버가 `mode: "solo"`를 확인해 주어야 시작하므로 DB·함수 준비 전에 프런트엔드부터 내보내지 않는다. 배포 후 오락실 그림·방향 카드·사용법·순위 항목과 실제 파일 리비전을 확인한다.
