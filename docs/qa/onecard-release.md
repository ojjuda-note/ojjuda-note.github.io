# 원카드 2.1.0 검수 · 2026-11-20

## 이번 변경

- 오락실에서는 원카드를 **함께하는 플레이에만** 표시한다. 혼자 하기는 원카드에 들어간 뒤 컴퓨터 대전에서 선택한다.
- 모든 새 판은 5자리다. 혼자는 나와 컴퓨터 4명, 멀티는 로그인 회원 1~5명과 나머지 컴퓨터로 시작한다. 방장 혼자도 시작할 수 있다.
- 매 새 판에 사람과 컴퓨터를 함께 무작위로 섞고 첫 차례를 정한다. 화면에서는 항상 내가 아래에 보이며, 게임 순서는 시계 방향으로 고정한다.
- 멀티에서 나간 회원의 자리와 손패는 컴퓨터가 이어받는다. 탈락자는 되살리지 않는다. 사람이 모두 나가면 방을 닫는다.
- 시작 화면은 `shared/games/game-entry.css`, 결과 화면은 `shared/games/game-results.css`를 직접 사용한다. 솔리테어·사천성·윷놀이와 같은 색, 글꼴, 패널, 버튼 구성을 따른다.
- 공통 대문에서 컴퓨터 대전과 온라인 대전을 고른다. 온라인은 실제 `OjjudaArcadeRooms`의 방 제목 양식과 방 목록을 재사용하며, 만든 방은 오락실 전체 대전방에서도 생성·참여·취소·이어하기가 가능하다. 기존 코드방 입력은 첫 화면에서 제거하고 초대 링크를 유지한다.
- 결과는 아이콘 → 제목 → 승자 → 안내 → 세 버튼 → 5명 카드 수 순서다. 다시 하기/대기실, 게임판 보기, 오락실로 이동할 수 있다.
- 바닥 카드는 다음 카드가 착지할 때까지 유지한다. 애니메이션 취소·화면 복귀·온라인 상태 재동기화 뒤에도 최신 펼친 카드가 남아 있어야 한다.
- 손패는 페이지를 나누지 않는다. 전체 패를 카드 영역에서만 좌우로 밀거나 마우스로 끌어 확인하며, 숫자순·색상순 버튼은 표시 순서만 바꾼다. 드래그를 끝낼 때 카드를 잘못 내지 않아야 한다.
- 게임 2.1.0, 게임 리비전 `20261120-onecard6`. 아지트·오락실 메뉴·공원 버전은 변경하지 않는다.

## 규칙

오쭈다 전용 4색 카드 54장을 사용하고 각자 7장을 받는다. 숫자는 1~8이며 같은 색이나 숫자·기호를 한 장씩 낸다. +2·+3 및 전체 색 +5·+7은 표시된 수만큼 공격한다. 공격 중에는 직전에 놓인 공격 카드와 같거나 더 큰 숫자의 공격 카드만 이어 낼 수 있다. 색은 달라도 되며, 받아야 할 누적 장수와 비교하지 않는다. 예를 들어 +2 다음 +3은 가능하지만 +5 다음 +2·+3은 불가능하다. 컴퓨터와 온라인 서버도 같은 규칙을 사용한다. 색 바꾸기와 전체 색 공격은 다음 색을 고른다. 건너뛰기와 한 번 더 카드가 있고 방향을 뒤집는 카드는 없다. 저장 및 서버 호환을 위해 기존 카드 ID를 내부 식별자로만 유지한다.

받으면 차례가 끝난다. 원카드는 2장일 때 미리 외치거나 1장이 된 직후 외친다. 다음 사람이 행동할 때까지 외치지 않으면 2장 벌칙을 받는다. 20장 이상이면 탈락하며, 마지막 카드를 내면 즉시 승리한다. 멀티의 사람 차례는 30초이며 첫 배분에는 5초를 더 준다.

## 화면과 소리

배경은 산과 나무, 텐트와 랜턴을 담은 은은한 2D 캠핑장이다. 정적인 벡터 장면을 사용해 카드 이동 중 배경이 계속 다시 그려지지 않게 한다. 공통 시작·결과 화면 구성은 유지한다. 전용 카드는 파랑·빨강·노랑·초록의 큰 숫자와 동작 기호, 두께·종이 질감·입체 테두리·그림자로 표현한다. 트럼프 문양·문자·궁정·조커 그림을 사용하지 않는다. 색별 도형도 함께 표시한다. 35장 배분과 첫 펼친 카드 1장은 하나의 Web Animations 타임라인에서 62ms 간격으로 겹쳐 출발한다. 움직임은 transform/opacity로 처리하고 카드마다 서버에 요청하지 않는다. 배분 중에는 입력을 잠근다.

효과음은 기존 CC0 카드/테이블 실물 녹음을 사용한다. 전자음 합성은 없다. 효과음 켜기/끄기와 움직임 줄이기를 지원한다.

680×469 공개 화면에서 확인한 중앙 카드 라벨·색 표시 겹침을 수정했다. 짧은 가로 화면은 색·진행 방향을 카드 오른쪽에 둔다. 시작 화면과 방 대기실도 짧은 가로 화면에서 두 열로 정리한다.

## 서버와 저장

- 기존 마이그레이션 `20261119180311_onecard_online_rooms.sql`은 수정하지 않는다. 5인 규칙은 `20261119190634_onecard_fixed_five_computer_seats.sql`, 공통 대전방 목록은 `20261119193643_onecard_native_arcade_rooms.sql`에 둔다. 공통 방번호를 사용하고 목록에는 손패나 회원 UUID를 내보내지 않는다.
- 방 회원 목록은 사람의 UUID와 방장 권한을 관리한다. 실제 경기의 5자리 순서와 분리하며 모든 차례 권한은 플레이어 ID로 확인한다.
- 컴퓨터는 자기 손패와 공개 정보만 보고 서버에서 행동한다. 컴퓨터 차례는 약 1.6초 간격이며 첫 차례는 배분을 위해 5초 기다린다. 한 요청에서 자동 행동은 최대 한 번이다.
- 동시에 여러 화면이 요청해도 상태 버전 비교(CAS)로 한 동작만 반영한다. 요청 중복 방지, 본인 확인, 차단·정지, 방장 이전, 만료와 새로고침 복구를 유지한다.
- `ojjuda_onecard_internal.rooms`는 RLS가 켜진 비공개 테이블이다. anon/authenticated는 테이블과 서비스 RPC를 직접 사용할 수 없다. JWT를 확인한 Edge Function만 서비스 RPC를 호출한다.
- 이전 2~4자리 온라인 판이 있다면 그 손패를 유지해 마친 뒤 다음 판부터 5명으로 시작한다. 로컬 이어하기는 기존 5자리 저장만 지원하며, 다른 저장을 자동 삭제하지 않는다.
