# 원카드 출시 준비 · 2026-11-20

## 구현

- 게임: `games/onecard/`, 자체 버전 1.0.0.
- 오락실: 혼자/함께 목록에 원카드 추가, 오락실 버전 1.1.0.
- 공개 주소 예정: `/games/onecard/`, 짧은 주소 `/onecard/`.
- 혼자: 로그인 없이 컴퓨터 1~4명, 이어하기, 한 화면에서 진행.
- 멀티: 로그인 회원 2~5명, 방 코드·초대 링크·방장 시작·30초 자동 진행·새로고침 복구·퇴장·재경기.
- 배경은 CSS 2D, 카드는 벡터 무늬와 입체 테두리/그림자. 카드 이동은 한 Web Animations 타임라인에 겹쳐 예약하며 네트워크 호출과 분리.
- 효과음은 기존 CC0 카드/테이블 실물 녹음. 전자음 합성 없음.

## 규칙

처음 7장. 무늬 또는 숫자 일치. 2는 +2, A는 +3, 검정/빨강 조커는 +5/+7. 공격 중에는 공격 카드끼리 무늬와 관계없이 누적 가능. 7과 조커는 무늬 선택. J는 건너뛰기, Q는 역방향(2명은 한 번 더), K는 한 번 더. 받으면 차례 종료. 원카드는 2장일 때 예약 선언하거나 1장이 된 직후 선언. 다음 동작까지 미선언하면 2장 벌칙. 20장이 되면 탈락. 마지막 카드를 내면 즉시 승리.

## 검증 완료

- 엔진 15개 테스트: 2~5명 240판/17,959턴 완주, 매 동작 54장 보존, 공격/무늬/승리/고갈/퇴장/벌칙.
- 온라인 클라이언트 5개 테스트: 중복 입력, 18초 요청 제한, 재시도, 늦은 응답, 계정 변경 격리.
- 실제 SQL + Edge 핸들러 통합: 5명 101턴 완주, 여섯 번째 참여 거절, 비회원/차단/정지 접근, 동시 입력·마지막 자리 경합, 중복 요청, 타임아웃, 복귀, 퇴장과 방장 이전, 탈락 후 재경기.
- 실제 앱 코드 + JSDOM + Edge/SQL 7개 시나리오: 배분 중 입력 잠금, 선언, 컴퓨터 진행, 무늬 선택/취소, 승리/재시작/이어하기, 카드 페이지, 로그인 실패, 5개 독립 앱의 동기화와 재경기.
- 소스 위치 검사와 짧은 주소 4개 검사, 아지트 버전을 바꾸지 않는 게임 출시 검사 통과.
- 별도 미리보기 HTML에서 컴퓨터 4명과 7장 배분 및 입력 가능 상태 확인.

DOM 검증은 배치·음원 재생·실제 애니메이션 프레임을 모의한다. 실제 브라우저의 모바일/데스크톱 화면과 프레임 품질은 아직 확인하지 못했다.
