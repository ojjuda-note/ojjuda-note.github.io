**현재 청소년 공개 스위치는 꺼져 있습니다.** 운영 인력과 대응체계를 확정하고 실제 테스트를 통과하기 전에는 열지 않습니다.

## 운영 흐름
1. 관리자 계정으로 `/admin/pajang-teen.html`에 들어가 연령 제한 답변·댓글의 검토 대기를 확인합니다. 승인/숨김은 관리자 인증을 통과한 서버 RPC로만 처리합니다.
2. 실명·연락처·학교/주거지·계정 비밀번호·만남 장소, 성적 유인·협박·금전 요구·괴롭힘 등을 포함하면 승인하지 않고 숨깁니다.
3. 신고 목록은 원문·관계 정보를 확인하고 판단합니다. 삭제·숨김 등의 보호 조치가 필요하다면 **조치를 먼저** 한 뒤 신고 처리 완료로 기록합니다.
4. 심각한 아동 대상 성적 착취/협박·응급 위험은 즉시 접근 제한 여부와 관계 당국 신고 필요성을 판단하고 증거 취급 권한을 제한합니다. 정당하지 않은 재유포·다운로드를 금지합니다.
5. 잘못된 숨김에 대한 이의 제기와 개인정보 삭제 요청을 기존 문의 창구로 접수·기록합니다.
