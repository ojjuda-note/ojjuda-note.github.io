# 맞고 오락실 연결 · 2026-10-03

## 회원 대결

- 오락실 맞고는 회원 대기방으로 열립니다. 빠른 대결, 비공개 방 만들기, 8자리 코드 입장을 지원하며 컴퓨터 대결도 선택할 수 있습니다.
- 빠른 대결은 5초간 상대를 찾고, 없으면 컴퓨터 대결을 바로 시작합니다. 서버가 입장과 대기 종료를 같은 잠금으로 처리하므로 막 연결된 상대를 두고 나가지 않습니다. 비공개 방은 자동 전환하지 않습니다.
- 두 회원 모두 서버의 가입 생년월일 기준 만 19세 이상인지 확인합니다. 한 계정은 동시에 한 방만 사용할 수 있으며, 회원 대결 중에는 다른 창의 컴퓨터 대결 정산·충전도 막습니다.
- 각 차례는 **15초**입니다. 보너스 교환·바닥 패 선택·고/스톱 중에도 같은 차례의 시간이 유지됩니다. 기한이 지나면 서버가 해당 차례의 패·선택·고/스톱을 자동 처리합니다. 시간 초과만으로 회원 자리를 빼앗지 않으므로 다음 차례부터 직접 칠 수 있습니다.
- 상대가 나가면 **PC가 그 자리의 남은 판을 이어서 칩니다**. 정상 나가기는 즉시, 닫힘 알림을 받지 못한 연결 끊김은 마지막 응답 후 30초에 PC 자리로 바뀝니다. 15초 차례 제한은 그 사이에도 적용됩니다. 두 사람 모두 나가면 미완료 판은 취소하고 정산하지 않습니다.
- 손패 전체, 더미 순서, 섞기 비밀값은 서버에만 저장합니다. 각 회원에게는 자기 손패와 공개된 카드만 내려보냅니다. 서버가 카드·차례·총통·흔들기·폭탄·바닥 선택·고/스톱을 검증하며 클라이언트의 결과나 금액을 믿지 않습니다.
- 첫뻑·승패 골드는 판 종료 시 두 지갑을 같은 트랜잭션에서 한 번만 정산합니다. 회원 간 이동은 상대의 실제 잔액까지만 가능하며 잔액은 0 미만이 되지 않습니다. **중간에 나간 사람은 승리 보상을 받지 못하며 패배 금액은 판 종료 시 정산됩니다.**
- 끝난 뒤 양쪽이 ‘한 판 더’를 누르면 같은 방에서 재대결합니다. 선·나가리 이월은 직전 판 결과를 이어받습니다. PC가 대신 친 판은 대기방에서 새 상대를 찾습니다.
- 대결 상태는 약 1.2초마다 갱신합니다. 서버가 기한을 판정하며 브라우저 시계 변경으로 자동 진행을 늦출 수 없습니다. 요청 ID와 방 버전으로 재전송·동시 선택의 중복 처리를 막습니다.

서버 변경은 `20261003033418_matgo_online_matches.sql`과 `supabase/functions/matgo/online.mjs`입니다. 비공개 스키마의 방·원본 대국 기록에는 클라이언트 권한이 없으며 공개 RPC도 서비스 역할만 호출할 수 있습니다. 기존 CPU 대결 엔진과 v1/v2/v3/v4 정산 호환성을 유지합니다. 서버 SQL과 Edge를 먼저 적용한 후 프런트를 배포합니다.

`tests/matgo-online.test.cjs`는 회원 매칭·코드·외부 계정 차단·상대 손패 비공개·동시 요청·골드 보존·잔액 하한·재대결·15초 자동 차례·PC 대체·이탈 무보상을 검사합니다. `tests/matgo-online-ui.test.cjs`는 실제 두 브라우저에서 방 입장부터 정산·재대결·이탈 후 PC 진행까지 확인하며, 실제 15초 경과와 모바일 폭 320/390/768px을 검사합니다.

## 구쌍피 선택 · 짝패 표시 · 휴대폰 화면

- 같은 월 4장 중 2장이 나 또는 상대의 먹은 패에 있고 나머지 2장을 내가 들고 있으면 손패 두 장에 파란 ‘짝’ 표시를 붙입니다. 한 장을 내면 표시를 지우며 상대 손패·더미는 참고하지 않습니다.
- 구쌍피(9월 국진)를 먹는 순간 **그림(열끗)** 또는 **쌍피(피 2장)**를 선택합니다. 손패·뒤집기·폭탄·뻑 회수 모두 선택한 분류로 점수를 계산한 뒤 고/스톱을 판정합니다. 뻑으로 바닥에 묶인 동안은 선택하지 않습니다.
- 회원 대결은 먹은 사람에게만 선택창이 뜹니다. 기존 차례의 15초를 유지하며, 시간 초과·PC 대행은 현재 점수가 높은 쪽을 선택합니다(동점이면 그림). 서버에 선택을 기록하고 위조·누락된 선택은 거절합니다.
- 휴대폰의 실제 보이는 화면 높이에 맞추고 하단 메뉴 안전 여백을 확보합니다. 오락실의 중복 제목·닫기 줄을 없애고 규칙·소리·회원 대결·구쌍피 변경은 작은 메뉴에 모았습니다.
- 내가 먹은 패 위의 이름·안내·분류 글씨를 숨기고 패를 32×48px로 키웠습니다. 패 묶음을 누르면 54×81px로 펼쳐 봅니다. 내 점수는 상단에 작게 표시합니다. 첫뻑 이벤트와 종료 후 정산은 유지하고 예정 금액은 메뉴에서 확인합니다.
- 이벤트 제목·설명과 정산 안내는 휴대폰에서 한글 단어를 유지하며 줄바꿈합니다. 정산 항목과 숫자는 고정된 두 열로 맞추고 합계 아래에 계산식을 표시합니다. 상단 말풍선이 하단 위치까지 늘어나는 문제를 막았으며 상대가 뻑으로 쌓인 패를 가져가면 컴퓨터·회원 대결 모두 ‘아이고!!’를 표시합니다.
- CPU 정산은 `rules_version: 4`이며 v1/v2/v3 화면에서 시작한 판도 기존 규칙으로 검증합니다. 기존 회원 대결 기록의 구쌍피 분류도 유지합니다. 구쌍피·화면 변경은 SQL이 필요 없으며, 빠른 대결 자동 전환은 `matgo_quick_cpu_fallback` 마이그레이션을 함께 적용합니다.

## 공통 규칙과 컴퓨터 대결

- 손패 2장 + 같은 월 바닥 2장은 두 장 폭탄입니다. 네 장을 함께 먹고 피 1장을 가져오며 점수 배수 ×2, 이후 내 차례에 쓰는 폭탄 뒤집기 1회를 받습니다. 기존 세 장 폭탄은 뒤집기 2회를 유지합니다. 회원 대결·시간 초과 자동 진행에도 적용합니다.

- 자뻑을 먹으면 상대 피 2장을 가져옵니다. 손패·뒤집은 패 모두 적용하며, 상대 뻑은 1장입니다. 다른 피 가져오기 보상과 합산하고, 부족하면 있는 만큼만 가져옵니다.
- 뒤집은 보너스 뒤에 뻑이 나면 보너스도 그 더미에 묶입니다. 먹을 때 보너스 1장마다 피 1장을 더 가져옵니다. 자뻑 + 보너스 1장은 피 3장, 보너스 2장은 피 4장입니다. 묶일 때에는 보너스 점수나 피 뺏기 보상을 먼저 받지 않습니다.
- 손패에 같은 월 4장이 모이면 총통입니다. 7점 승리 또는 계속하기를 선택합니다. 계속하기는 고 선언이 아니며 같은 월의 선택을 다시 물어보지 않습니다. 손패 보너스 교환으로 네 장이 된 경우도 적용합니다. 양쪽 모두 총통이면 선부터 선택하고 컴퓨터는 7점 승리를 선택합니다.
- 한 판에서 같은 사람이 뻑을 3번 내면 기본 7점으로 자동 승리합니다. 상대가 이미 고를 선언했다면 고박 ×2를 적용해 14점(1,400골드)으로 정산합니다. 뻑을 먹어도 횟수가 유지되고 다음 판에 초기화됩니다. 총통·3회 뻑에는 일반 점수·흔들기·이월 배수를 더하지 않습니다.
- 각자 첫 차례에 뻑이 나면 **첫뻑**으로 상대에게 300골드를 받습니다. 손패의 보너스 교환은 첫 차례를 소모하지 않습니다. 첫뻑도 뻑 3회 계산에 포함됩니다.
- 첫뻑 이벤트와 정산 예정 금액을 표시하되 게임 중 잔액은 바꾸지 않습니다. **모든 골드는 판 종료 후 한 번에 정산**합니다. 중간에 나가거나 새로고침하면 미완료 판의 예정 골드는 지급하지 않습니다. 서버는 전체 대국이 끝났는지 검증한 뒤에만 지급합니다.
- 첫뻑 300골드는 점수·고박 배수에 곱하지 않고 승패 금액과 합산합니다. 나가리도 종료된 판이므로 첫뻑 금액은 정산합니다. 양쪽 모두 첫뻑이면 서로 300골드가 상쇄됩니다. 최종 잔액만 최소 0으로 처리합니다.
- 만 19세 이상만 입장할 수 있습니다. 미만·비로그인·생년월일 미등록 계정에는 오락실의 맞고 버튼이 보이지 않습니다. 직접 URL, 게임 시작, 골드 조회·충전·정산도 나이를 확인합니다.
- 나이는 서버에 저장된 가입 생년월일을 한국시간 기준으로 계산합니다. 현재 정보는 직접 등록한 생년월일이며 휴대폰 본인인증으로 확인한 나이는 아닙니다.
- 게임머니는 골드입니다. 처음 한 번 5,000골드를 지급하며, 패배 후 잔액은 최소 0입니다.
- 0골드일 때 한국시간 하루 2회, 매회 5,000골드 무료 리필. 이후에는 사용자가 `5쭈 사용 · 5,000골드` 버튼을 누르면 5쭈를 차감하고 충전합니다. 한국시간 자정에 무료 횟수가 초기화됩니다.
- 골드와 무료 횟수는 계정별 서버 저장입니다. 초기 지급 중복, 반복 정산, 충전 중복 차감, 잔액 부족, 날짜 전환을 처리합니다.
- 실제 손패 진행·선택·고/스톱·흔들기·국진 전환 기록을 서버의 같은 규칙 엔진으로 재생하고 골드를 정산합니다. 클라이언트가 주장하는 승리/잔액/가격은 사용하지 않습니다.
- 골드에서 쭈로 바꾸거나 승리 보상으로 쭈를 지급하는 기능은 없습니다.

## 배포 파일

`world.html`, `matgo-access.js`, `matgo-bridge.js`, `games/matgo.html`, `games/matgo-engine.mjs`, `games/matgo-wallet.mjs`.
기존 `config.js`는 오쭈다 월드 프로젝트를 계속 사용합니다. 서버 마이그레이션은 `supabase/migrations/20261002195728_matgo_gold_wallet.sql`, Edge Function은 `supabase/functions/matgo/`입니다.
서버 적용 후 프런트 파일을 함께 배포해야 합니다. HTML 하나만 교체하는 예전 설치 방법은 이 버전에 적용되지 않습니다.
Edge Function은 요청마다 Supabase Auth로 사용자를 재검증하고, 서비스 전용 함수에서 회원 나이를 확인합니다. 서비스 키는 서버 환경변수에만 둡니다.
게임과 Edge의 엔진 파일은 동일해야 하며 테스트가 이를 검사합니다.
새 클라이언트는 정산에 `rules_version: 4`을 전송합니다. 이미 열린 이전 화면은 `engine-v1.mjs`·`verify-v1.mjs` , `engine-v2.mjs`·`verify-v2.mjs` 또는 `engine-v3.mjs`·`verify-v3.mjs`로 해당 규칙을 재생 검증하므로 배포 중 정산이 깨지지 않습니다. 규칙 버전을 생략하면 v1이며 알 수 없는 버전은 거절합니다. 프런트 모듈과 오락실 진입 주소에 새 캐시 버전을 적용했습니다. 첫뻑 기능은 기존의 판 종료 정산을 사용하며 구쌍피·화면 변경은 SQL이 필요 없으며, 빠른 대결 자동 전환은 `matgo_quick_cpu_fallback` 마이그레이션을 함께 적용합니다.

## 검사

- 구쌍피 선택 22개 상황, 7점 직전 분류 선택·서버 검증·상대 선택 차단·15초 자동 선택·기존 기록 호환을 검사합니다. 모바일 320×568, 360×640, 390×560에서 하단 34px를 확보해도 손패가 가려지지 않는지, 내 먹은 패 문구 제거·확대 보기를 브라우저로 확인합니다.

- 자뻑과 상대 뻑의 양쪽 플레이어·손패·뒤집기, 보너스·싹쓸이 합산, 피 부족: 16가지.
- 보너스 뻑 묶기·회수, 한 사람의 뻑 3회·초기화·고박, 총통 승리·계속·양쪽 동시 총통·보너스 교환·위조 선언 차단을 검사합니다. 실제 전체 대국을 서버에서 재생해 뻑 3회 7점/고박 14점 정산을 확인합니다.
- 자동 대국 300판: 전부 종료, 매 단계 50장 보존·중복 없음.
- 서버 대국 재생 100판, 금액 위조·미완료 대국 차단, 잔액 0 처리.
- 서버 금액·연령·무료/유료 리필·중복·쭈 부족·한국시간 날짜 전환 검사.
- 브라우저: 직접 접속 차단, 19세 미만 버튼 숨김, 성인 오락실 입장, 로그아웃, 모바일 320/390/768px, 실제 한 판 정산, 무료/유료 충전 화면.
- 브라우저에서 총통 선택창의 두 선택, 컴퓨터 총통, 보너스 뻑 표시와 피 3장 회수, 뻑 3회·고박 14점 결과표를 검사합니다.
- 첫뻑의 양쪽 플레이어·보너스 교환·첫 차례 이후 제외·나가리·고박과 합산·0 하한·중도 종료 시 무지급·완료 후 한 번 지급을 검사합니다. 브라우저에서는 첫뻑 이벤트, 예정 금액 표시, 중도 종료/새로고침 시 잔액 유지, 최종 합산 표시를 확인합니다.
