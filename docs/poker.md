# 세븐포커

오락실 멀티 목록의 맞고 오른쪽에 표시하며, 서버에 등록된 생년월일 기준 만 19세 이상만 입장할 수 있다. 연령 미확인·로그아웃·만 18세 이하는 숨기고 입장도 차단한다.

- 사람들과 플레이: 공개 방 목록 또는 8자리 방 코드로 2~4명 참여. 방장 시작, 각자 패 버리기·공개, 4구~히든 베팅, 쇼다운, 전원 준비 후 다음 판.
- 한 차례 30초. 패 선택은 서버 자동 선택, 베팅은 체크 가능한 경우 체크하고 아니면 다이. 다음 카드 배분은 2초 후 진행.
- 진행 중 퇴장은 다이 처리. 대기실 방장이 나가면 다음 참여자에게 방장 이전. 새로고침 뒤 사람들과 플레이를 누르면 참여 중인 방 복원.
- 방마다 연습칩 5,000 G로 시작하며 다음 판에 잔액을 이어간다. 참가비 50 G 미만이면 무료로 5,000 G 보충. 계정 ZU·맞고 골드·기기 컴퓨터 연습 골드와 독립.
- 중앙 덱에서 차례로 카드를 배분하며 효과음을 재생한다. 모션 감소 설정에서는 즉시 배분한다.

## 서버 경계

`poker` Edge Function은 Auth 사용자 조회 후 private RPC를 호출한다. 회원·생일·차단·정지·방 소속·호스트·버전·차례를 서버에서 확인한다. private room 상태는 클라이언트에서 읽거나 갱신할 수 없다. 덱·버린 패·상대 히든·내부 회원 ID·요청 기록은 명시적인 응답 투영에서 제외한다. 쇼다운에서 다이하지 않은 패만 공개한다. 한 사용자당 참여 중인 방 한 개, 방당 잠금, 요청 ID 중복 제거, 버전 비교로 동시 요청을 처리한다.

상태는 1.2초 간격으로 동기화한다. 서버 시계 기준 제한 시간을 표시하며, 재접속 시 서버 상태를 다시 받는다. 호스트 브라우저가 게임 상태를 결정하지 않는다.

## 확인

`tests`에서 `npm run test:poker` 실행. 엔진·효과음·딜링 DOM·생일 경계, 실제 SQL과 Edge 핸들러를 거치는 2/4인 전체 판 및 독립된 두 DOM의 방 생성/참여/패 선택/베팅/퇴장을 검사한다. 실제 기기에서 애니메이션의 시각적 품질은 별도 확인이 필요하다.
