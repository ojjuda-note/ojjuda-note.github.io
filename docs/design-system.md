# 오쭈다 월드 디자인 · 0.46.2

오락실·공원·설정 세 가지 목적에 맞춰 화면을 다시 구성했다. PC에서는 상단 탐색을, 작은 화면에서는 하단 탐색을 사용한다. 순위는 오락실 상단에 두고, 게임 목록과 대전방을 분리했다. 오락실의 공개 채팅과 공원 이동 버튼, 공원의 상단 소개 배너는 제거했다. 공원은 정렬 메뉴와 카드 목록으로 바로 시작한다. 계절·기념일 그림은 별도 소개 카드 대신 게임순위 게시판의 배경에 표시한다. 설정은 내 정보, 이용 설정, 활동·도움으로 묶었다. 친구 관리의 검색·신청·수락·삭제 동작과 작성 중인 프로필 값은 유지한다.

## 시각 체계

기본은 아이보리·포레스트·세이지·앰버. Noto Sans KR와 시스템 한글 글꼴, 얇은 경계선, 절제된 그림자, 일관된 간격을 사용한다. 새 로고, 인터페이스 심벌, 16개 게임 그림, 기본 환영 그림, 18개 계절·기념일 그림은 이번 디자인을 위해 새로 제작한 벡터 자산이다. 기존 게시물의 사진·작성 내용·유료 꾸미기 선택에는 손대지 않는다.

이미지 생성으로 만든 별도의 도자기 정물 컨셉은 Canva 인증 만료로 원본 전송이 완료되지 않았다. 출시 자산은 저장소에 직접 포함된 새 벡터 그림이며 외부 이미지 호스팅에 의존하지 않는다.

## 자동 테마

`world-themes.js`가 한국 시각(UTC+9)으로 날짜를 계산한다. 첫 진입, 한국 시각 자정, 탭 복귀 시 자동 갱신한다. 화면의 DOM을 다시 만들지 않아 작성 중인 카드·프로필과 게임 상태를 유지한다. 공원 iframe도 같은 한국 날짜를 사용한다. 예전에 저장한 수동 테마는 무시한다.

기념일은 계절보다 우선한다. 같은 날에는 설·추석·부처님오신날을 우선한다. 대체공휴일이나 주말까지 자동 연장하지 않는다. 종료 후 계절 테마로 복귀한다. 설정의 나의 화면과 수동 테마 선택은 제거했다. 강조색 선택은 기본 테마에 적용된다.

음력 변환은 `korean-lunar-calendar` Python 0.3.1의 평달 변환 결과를 2026–2050년 날짜로 빌드해 포함했다. 2051년 이후 음력 기념일은 자료 갱신이 필요하며, 미지원 연도에도 계절 및 양력 기념일은 작동한다. 한국천문연구원 자료와 2026·2027년 설·추석·부처님오신날을 대조했다.

## 친구 쪽지

설정의 친구 목록에서 쪽지를 보내고 알림에서 읽고 답장한다. 수락한 친구 사이에만 전송하며 양쪽 서비스의 차단 상태를 확인한다. 관리자 모드 → 콘텐츠 → 쪽지 관리에서 닉네임·내용으로 검색하고 전송 시간을 확인한다. 조회는 현재 관리자 권한을 확인하며 반환한 쪽지 번호만 별도 접근 기록에 남긴다. 본문은 별도 비공개 테이블에 보관하고 참가자 또는 관리자 전용 RPC로만 접근한다.

카드 상세에서는 답글 쓰기를 사용하고 일반 카드 쓰기 버튼은 카드 목록에서만 표시한다.
