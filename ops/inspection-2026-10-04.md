# 2026-10-04 전체 기능 점검

기준: 운영 main `fa4f96309eae57acab1a7b3ce452f19707dfd15c`. 배포 표시 버전: `0.45.35-beta`.

## 발견 및 수정

1. 공원에서 문의를 전송하는 동안 월드 메뉴를 누르면 공원 iframe이 제거되었습니다. 느린 응답이나 실패 시 작성 내용과 처리 결과를 잃을 수 있었습니다. 문의·의견·신고의 공통 전송 상태를 외부 이동 검사에 연결했습니다.
2. 공원에서 쭈 충전을 요청하고 충전창을 닫은 뒤 메뉴로 이동하면, 응답을 처리할 화면이 제거되었습니다. 창의 표시 여부와 별도로 충전 요청이 끝날 때까지 이동을 막고 안내합니다. 응답으로 잔액이 반영되면 이동이 다시 허용됩니다.

두 문제 모두 실제 화면 코드와 가상 지연 응답으로 수정 전 실패를 재현했습니다. 수정 후에는 iframe 유지, 문의 실패 시 글 보존, 충전 1회 요청, 잔액 갱신과 이동 제한 해제를 확인했습니다. 로그아웃·계정 변경 시 기존 화면 폐기 동작은 유지합니다.

## 한계와 서버 권한 검토
