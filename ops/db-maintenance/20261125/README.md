# 2026-11-25 운영 DB 변경 보존

운영 Supabase의 마이그레이션 이력에서 두 변경의 원문을 보존한다. 이미 적용 및 확인된 변경이며, 이 폴더는 자동 배포 대상이 아니다. 이전 함수 정의 해시가 일치하지 않으면 실행을 중단하도록 가드가 포함되어 있다. 특히 공원 V2의 이전 스키마 의존성을 확인하기 전 새 환경에 직접 적용하지 않는다. 회원 데이터·자격 증명은 포함하지 않는다.

- 공원 자동 게시: 운영 데이터 선택 결과 64건 비교 통과, 격리 게시 시험 통과, 권한 및 기존 기록 유지 확인. 다음 실제 게시 확인 필요.
- 권한/금칙어 함수 4개: 변경 전 217건, 변경 후 5건 통과. 함수 소유자, 실행 권한 유지 확인.

전체 웹 회귀 검사 및 PR #1534 검증은 별도 진행한다. 아바타 테스트는 대상에서 제외한다.
