# 관리자 모드 정리 — 2026-10-04

대상 버전: `0.45.39-beta`

## 메뉴

| 영역 | 메뉴 |
| --- | --- |
| 계정 관리 | 요약, 가입자, 탈퇴 계정 |
| 신고·문의 | 신고, 문의·의견, 공원 이용 제한 |
| 월드 관리 | 우리집 글·댓글, 앨범·기존 글, 채팅, 삭제·만료 보관, 퀴즈, 운영 설정 |
| 공원 관리 | 전체 카드, 위험 신호, 이벤트 카드, 삭제·만료 보관, 위치 지도, 공지, 도배 방지 |
| 쭈 관리 | 무료 충전, 사용자별 쭈 |
| 운영 관리 | 운영 연결, 오류, 금칙어, 작업 기록 |

기존 관리자 링크와 같은 계정의 새로고침 복원을 유지한다. 옮긴 메뉴의 이전 링크는 새 위치로 연결한다. 모바일 상위 메뉴는 3열 2행으로 표시한다.

## 발견 내용과 수정

| 발견 | 수정 |
| --- | --- |
| 신고·문의·운영 기능이 계정 메뉴에 혼재 | 목적별 6개 영역으로 분리 |
| 가입자 목록에 상태 필터·총수·페이지 이동이 없음 | 전체·오늘 가입·정지 중·관리자 필터, 검색, 20개 단위 페이지 |
| 요약의 정지 중 버튼이 전체 가입자로 이동 | 정지 중 필터로 직접 연결. 전체·오늘 가입 통계도 목록 연결 |
| 탈퇴 계정 기록을 조회할 관리자 화면이 없음 | 보관 기간 내 기록만 조회. 이메일 마스킹, 가입·탈퇴·파기 시각 표시 |
| 새 우리집 글과 앨범 댓글이 기존 관리 피드에서 빠짐 | 종류·공개 범위·위험 신호·검색, 본문 수정·삭제, 변경 충돌 확인 |
| 작업 기록이 최신 일부에 한정되거나 서비스별로 흩어짐 | 월드·공원 선택, 작업 분류, 총수, 30개 단위 페이지, 상세 기록 |
| 문의 답변 저장 중 이동하면 초안·실패 안내가 소실 | 저장 중 이동 차단, 작성 중 이동 확인, 실패 후 초안·재시도 유지 |
| 특정 작성자·지도에서 카드로 이동할 때 숨김 필터가 남음 | 진입 시 숨김 상태 필터 초기화 |
| 보관 답글 추가 조회 실패가 기존 내용까지 지움 | 기존 답글 보존, 같은 위치에서 재시도 |
| 보관함 조회만으로 파일 정리를 시도 | 정리 대기와 오류 표시, 명시적 정리 버튼 제공 |
| 새로고침이 모듈을 재생성하거나 요약의 기록·위험 신호를 갱신하지 않음 | 모듈 자체 새로고침 연결, 요약 캐시 초기화 |
| 보관함 마지막 페이지 삭제·만료 후 잘못된 범위 표시 | 남아 있는 마지막 페이지로 이동 후 다시 조회 |
| 관리자 진입 의존성 로딩 실패 시 재시도 버튼이 작동하지 않음 | 재시도 버튼으로 페이지 재로딩 |
| 실제 서체에서 긴 하위 메뉴가 좁은 고정 열을 벗어남 | 이전 grid 우선순위를 해제하고 글자 폭에 맞춘 버튼·44px 터치 영역 적용. 화면을 다시 그린 뒤에도 선택한 메뉴가 보이도록 위치 유지 |

## 데이터·권한

- 신규 RPC는 로그인과 기존 관리자 권한을 서버에서 확인한다. 공개 함수는 invoker wrapper, 실제 구현은 비공개 스키마의 고정 `search_path` 함수다. 익명 실행을 허용하지 않는다.
- 탈퇴 기록의 기존 1개월 보관·자동 파기 정책을 바꾸지 않았다. 전화번호·생년월일·원본 계정 스냅샷을 목록에 제공하지 않는다.
- 작성자가 휴지통에 넣은 우리집 글은 관리자 피드에서 제외한다. 관리자 삭제는 작성자 복원으로 다시 노출되지 않는다.
- 관리자 삭제 보관은 기존 정책대로 공개 원문만 30일이다. 비공개·닫힌 방·탈퇴 작성자 자료를 새로 보관하지 않는다. 새 작업 기록에는 비공개 본문을 복제하지 않는다.
- 기존 쭈 지급·관리자 지정·금칙어·운영 설정 권한을 유지했다. 폐기된 보상·VIP·서비스 토글을 다시 넣지 않았다.
- 운영 자료에 시험용 글·답변을 쓰거나 삭제하지 않았다. 수정·삭제·충돌·실패 검사는 합성 데이터로 실행했다.

## 검증

- 계정·작업 기록·우리집 관리 DB 테스트: 비관리자/익명 차단, 페이지 경계, 검색, 한국 날짜 경계, 보관 만료, 공개 범위, 편집 충돌.
- 새 UI 테스트: 조회 실패·재시도, 느린 응답·계정 변경, 저장 중 이동 보호, 초안 확인, 보관 마지막 페이지, 이전 링크, 모듈 새로고침.
- 320·390·1280px 화면 및 밝은/어두운 배경 확인.
- 기존 단위·화면 회귀검사 통과. 신규 마이그레이션 3개를 운영 DB에 적용했다. 신규 공개 RPC 6개의 익명 실행 차단과 기존 보관 종류 보존을 확인했고, 적용 전후 보안 점검의 추가 경고는 0건이다.
