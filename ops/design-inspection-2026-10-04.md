# 오쭈다 디자인 점검 — 2026-10-04

대상: 0.45.36-beta. 기능 점검 뒤 별도로 모바일·PC의 실제 렌더링을 확인하고 아래 디자인 문제를 수정했다.

## 발견 및 수정

| 위치 | 발견 | 수정 |
| --- | --- | --- |
| 대문 | 320px에서 긴 닉네임과 관리자 링크가 로고·로그아웃 글자를 세로로 밀어냄 | 고정 동작 버튼의 줄바꿈 방지, 닉네임 말줄임, 최소 폭 조정 |
| 공원 카드 | 좁은 카드에 네 자리 답글·공감 수와 거리가 함께 있으면 작성자가 사라지고 날짜·거리가 겹침 | 카드 폭 340px 이하에서 정보와 동작 버튼을 두 줄로 배치 |
| 생활 | 저장 버튼이 카드 오른쪽으로 30px 넘침, 다크모드에 밝은 카드가 남음 | 영역의 border-box 적용, 카드·입력·버튼·구분선의 다크 테마 지정 |
| 가구 제작실 | 모바일 주요 버튼 글자가 여러 줄로 깨짐, PC 저장 버튼만 다음 줄에 남음, 태블릿 간편 모드의 입력 영역이 과도하게 좁음 | 모바일 2열·44px 버튼, 헤더 가용 폭 사용, 간편 모드 입력 영역 너비 조정 |
| 안내 페이지 | 새 우리집 그림에 이전의 긴 화면 캡처 자르기 규칙이 적용되어 파란 빈 공간만 표시 | 현재 그림의 원래 비율과 위치 복원 |
| 카페·도서관·오락실 | 다크모드에서 밝은 배너·대화 패널과 밝은 글씨가 겹쳐 읽기 어려움 | 배너·패널을 테마 배경으로 변경. 본문 대비 1.11~1.13:1 → 13.68:1 |
| 공통 테마·충전·공원·관리자 | 분홍 배경의 흰 글씨와 옅은 강조 글씨 대비 부족 | 배경색과 글자색 토큰 분리, 테마별 강조 글자색과 어두운 버튼 글자색 적용 |
| 우리집·제작실·안내·나사게임 | 작은 설명과 보조 글씨가 배경에 묻힘 | 각 화면의 기존 색 계열 안에서 대비 개선, 필요한 작은 안내 글자 크기 조정 |
| 게임 | 당구의 선택 버튼 및 장기의 진영 표시 대비 부족 | 선택 버튼과 진영별 문자색의 밝게/어둡게 대비 보정 |

키보드 초점, 입력 예시 글자, 동작 줄이기 설정도 보완했다. 장소와 가구 그림, 배치 좌표, 사용자 카드의 선택 색상, 저장 데이터는 변경하지 않았다.

## 확인 범위

- 기본 화면 폭: 320·390·1280px. 제작실 640·850·1024px 경계 추가 확인.
- 대문/로그인, 공원 목록·상세·답글·글쓰기·꾸미기·사진선택·이벤트·태그·글래스.
- 우리집 홈·설정·가구 목록·배치 편집, 제작실 초기·불러오기·캔버스·고급 설정.
- 생활 주소록·가계부·계산기, 공통 메뉴·프로필·충전·문의·알림·관리자·안내 검색/탭.
- 카페·도서관·오락실의 밝게/어둡게 화면, 장기·체스·당구·오락실 게임, 나사게임·맞고·온라인 맞고·틀린그림의 대표 대기·진행·확대 화면.
- 공통 테마 5색 × 밝게/어둡게 × 기본/마우스 올림에서 140개 대표 글자/배경 조합 측정: 최저 4.60:1, 전부 4.5:1 이상.
- 테스트용 가상 계정/데이터로 확인했다. 실제 Android/iOS 기기의 렌더링과 모든 사용자 콘텐츠 조합까지 보장하는 검사는 아니다.
