# 공원 카드 자동 예약

2026-10-21부터 오쭈다 아지트는 오락실·공원·설정만 운영한다.
우리집·앨범·비디오·게시판·생활 기능과 예약은 종료했다.

## 게시 간격 — 2026-11-04 사용자 변경

공원 카드는 **2시간 12분(132분)마다 한 장** 게시한다.
기준 시각은 `2026-11-04 03:01:00+09:00`이며, 이후에는 기준 시각에 132분의 정수배를 더한다.
예: 11월 4일 03:01 → 05:13 → 07:25 → 09:37.
날짜가 바뀌어도 간격을 초기화하지 않는다. 날짜별 게시량은 보통 10~11장이다.
이전의 6시간/하루 4장, 2시간/하루 12장 고정 편성은 사용하지 않는다.

`ojjuda_note_internal.auto_card_copy`와 `auto_card_schedule`에 원고와 예약을 함께 저장한다.
`planned_at`은 실제 게시 예정 분까지 포함한 시각이다. 별도로 1분을 더하지 않는다.
`local_day`는 `planned_at AT TIME ZONE 'Asia/Seoul'`의 날짜이며,
`slot`은 그날 기준 시각 격자에 속한 게시 시각의 1부터 시작하는 순번이다.
지나간 슬롯을 생략하더라도 그날의 순번은 바꾸지 않는다.
본문은 1–200자, `content_source='curated_automation'`, `gender='private'`,
기존 전국 후보 `site_id`를 사용한다.

`ojjuda_note_daily_auto_cards`의 cron은 UTC `1,13,25,37,49 * * * *`이며,
명령은 `SELECT ojjuda_note_internal.run_auto_cards()`이다.
이는 12분마다 예약 도래 여부를 확인하는 작업이다. 실제 카드는 `planned_at`이 된 경우에만
132분 간격으로 게시하며, 12분마다 새 글을 생성하거나 게시하지 않는다.

## 예약 보충

매번 실제 DB의 설정·cron·원고·예약을 조회하고, 다음 게시부터 최소 72시간 뒤까지
기준 시각 격자의 빈 예약만 채운다. 미래 예약이 없으면 현재 시각보다 뒤인 첫 격자 시각부터 준비한다.
기존 미래 예약, 이미 공개된 카드와 실제 회원 글은 보존한다.
놓친 과거 시각을 몰아서 발행하지 않는다.
날짜별 트랜잭션에서 `pg_advisory_xact_lock(284726,(local_day-date '2000-01-01')::integer)`를 잡고 기존 슬롯을 다시 확인한다.
본문과 예약은 같은 트랜잭션에 저장하며 금지어·본문 중복·길이·위치 존재 여부를 확인한다.
문구는 밥·커피·산책 제안과 은근한 호감 표현 같은 짧은 플러팅 글이다.
시간대가 바뀌어도 자연스럽게 읽히도록 시간 특정 표현을 줄인다.

구형 `stage_auto_cards`와 `plan_auto_cards`를 직접 호출해 새 일정을 생성하지 않는다.
실제 발행은 기존 `run_auto_cards()`와 서버 cron에 맡긴다.
중지된 설정이나 예약 작업을 임의로 재개하지 않는다.
최종 조회에서 인접한 미래 예약 간격이 모두 132분인지, 중복이나 빈 예정 시각이 없는지,
설정과 cron이 정상인지 확인한다. 준비 수와 실제 게시 수는 구분한다.
현재 조회와 검증 없이 변화 없음으로 처리하지 않는다.
