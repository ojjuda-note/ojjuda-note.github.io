# 오쭈다 노트 내일 짧은 글 준비

한국 시간 내일 게시할 카드 48개를 준비한다. 프로젝트는 `ziezbdjofcugznowiuda`이고 기존 자동화는 매일 22:30 Asia/Seoul에 실행한다. 현재 서버의 48개 예약 규칙과 연결된 자동화 설정을 먼저 확인한다.

1~24번은 매시간 정각의 위로·응원·공감·창작 명언, 25~48번은 매시간 30분의 가벼운 유머·유행·검증된 정보다. 30분대 글 중 4개는 확인한 신조어·줄임말의 쉬운 뜻과 예문을 담는다. 확인할 표현이 부족하면 유머로 채운다. 성별은 `private`, 위치는 기존 전국 후보를 사용한다.

한두 문장, 약 20~80자로 쓴다. 데이터베이스의 200자 제한보다 읽기 쉽고 자연스러운 문장을 우선한다.

## 문장 검수

- 친구에게 실제로 할 법한 말을 쓴다. 문장마다 누가 무엇을 하는지 분명하게 하고 주어·서술어와 앞뒤 뜻을 맞춘다.
- 비유를 넣으려고 사물에 억지 행동을 시키거나 뜻이 모호한 말을 붙이지 않는다. ‘마음의 속도’, ‘절반의 용기’, ‘양말 세탁기의 비밀 통로’처럼 설명이 필요한 표현은 구체적인 상황으로 풀어 쓴다.
- 감동적인 결론이나 명언을 억지로 붙이지 않는다. 두 번째 문장이 첫 문장과 연결되지 않으면 다시 쓰거나 한 문장으로 끝낸다. 지나친 훈계와 같은 응원 문구의 반복을 줄인다.
- 유머는 쉽게 떠올릴 수 있는 일상 상황에서 만든다. 상황과 농담이 바로 이해되는지 확인한다. 신조어도 뜻에 맞는 예문 하나를 쓴다.
- 48개를 게시 시각 순서(1, 25, 2, 26, …, 24, 48)로 읽는다. 소재·문장 시작·말끝이 계속 반복되지 않게 하고, 아침·점심·퇴근·잠자리 표현이 예정 시각과 맞는지 확인한다.
- 띄어쓰기와 조사, 생략한 목적어, 화자가 갑자기 바뀌는 부분을 마지막으로 점검한다. 소리 내 읽듯 검토했을 때 바로 이해되지 않는 문장은 다시 쓴다. 길이 검사 통과만으로 검수를 끝내지 않는다.

## 카드 줄바꿈

두 문장은 문장 사이에서 줄을 바꾸고, 긴 한 문장은 의미가 끊기는 구절에서 나누어 대체로 2~4줄로 읽히게 한다. 짧은 문장을 억지로 잘게 나누거나 글자 수에 맞춰 단어·조사·문장부호를 잘라내지 않는다. 연속 빈 줄과 각 줄 앞뒤 공백을 넣지 않는다. 줄바꿈은 실제 LF 문자로 저장한다. SQL에 넘길 때 문자 그대로의 `\n`이 본문에 남지 않게 하고, LF를 포함해 20~80자 기준을 확인한다. 신조어는 뜻풀이와 예문 사이에서 줄을 바꾼다.

휴대폰 카드에서 읽는 흐름을 마지막으로 확인한다. 노트의 기존 카드 렌더러는 LF를 줄바꿈으로 표시하므로 본문을 한 줄로 합치지 않는다. 최근 14일 중복 검수에서는 줄바꿈을 공백으로 바꿔 비교하여 같은 글을 새 글로 취급하지 않는다.

뉴스와 신조어는 공식 기관·원출처의 날짜와 실제 쓰임을 웹에서 확인한다. 본문에는 필요한 출처를 짧게 밝히고, 근거 없이 최신·인기라고 단정하지 않는다. 확인되지 않은 사실은 쓰지 않는다. 실존 회원의 경험이나 제보를 꾸미지 않고 광고·정치·비하·혐오·성적 표현·욕설·해시태그를 넣지 않는다. 본문에 자동 작성·임의 위치 표시를 덧붙이지 않는 기존 정책을 유지한다.

## 준비와 확인

`ojjuda_note_internal.auto_card_copy`의 내일 준비 건수, `auto_card_schedule`의 내일 일정, 최근 14일 본문을 먼저 읽는다. 이미 48개가 준비·예약되어 있으면 덮어쓰지 않는다. 부분 일정이 있으면 원인을 확인하고 중복 생성하지 않는다. 최근 14일 문장과 신조어·예문을 중복하지 않는다.

내일 일정이 없고 새 글을 준비해야 할 때 검수한 48개 본문을 순서대로 아래 함수에 넘기고, 계획 함수를 호출한다. 문자열은 SQL 규칙에 따라 이스케이프한다.

```sql
SELECT ojjuda_note_internal.stage_auto_cards(
  ((now() AT TIME ZONE 'Asia/Seoul')::date + 1),
  -- 검수한 48개 본문의 text[] 배열
  ARRAY[...]::text[],
  'curated_automation'
);
SELECT ojjuda_note_internal.plan_auto_cards(
  ((now() AT TIME ZONE 'Asia/Seoul')::date + 1)
);
```

준비·일정 각각 48개, 정각/30분 시각, 성별 `private`, 전국 후보 연결을 다시 조회한다. 실패나 부분 준비는 그대로 보고한다. 이 정기 작업에서 계정·크론·기존 공개 카드를 변경하지 않는다.

2026-09-29 사용자의 문장 교정 요청에 따른 일회성 수정은 `supabase/auto_card_copy_polish_2026_09_29.sql`에 기존 문장과 교정문을 함께 기록했다. 날짜·슬롯·원문과 전용 자동 작성 계정이 일치하는 글만 고치며, 본문과 정상 수정 시각을 제외한 사진·글꼴·색·태그·예약·보관 정보가 달라지면 전체 작업을 되돌린다.

같은 날 요청한 줄바꿈은 `supabase/auto_card_line_breaks_2026_09_29.sql`에 기록했다. 준비·예약된 자동 글 76개와 연결된 공개 카드의 단어 사이 공백만 LF로 바꾸며, 글의 내용과 다른 정보는 보존한다. 원문 일치·전용 계정·예약 잠금·메타데이터 보존 검사 후 반영하며 재실행 시에는 다시 수정하지 않는다.
