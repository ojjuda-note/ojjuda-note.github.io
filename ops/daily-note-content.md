# 오쭈다 다음 예약 준비

2026-10-13 사용자 변경을 반영한다. 웃긴 짤은 앨범에 올리고 짧은 동영상도 포함한다. 이 문서가 이전의 짤 노트 발행, 48/24/12장 공원 카드 지시 및 소설·유머·이슈·일상 각 3편 지시보다 우선한다.

먼저 최신 `docs/AUTO-HOUSE-NOTES.md`, `docs/AUTO-HOUSE-MEDIA.md`, `scripts/prepare-house-media.py`와 Supabase 프로젝트 `ziezbdjofcugznowiuda`의 실제 설정/예약을 읽는다. 공원은 한국 날짜 내일·모레의 빈 예약을 채운다. 미디어는 앞으로 약 48시간 동안 쓸 큐를 보충한다.

- 공원: 짧은 플러팅 글 하루 4장, 6시간 간격. 슬롯 1·4·7·10, 01:01·07:01·13:01·19:01 KST.
- 우리집 앨범·비디오: 웃긴 짤 이미지와 재미있는 짧은 영상, 장면에 맞는 한국어 캡션을 `ojjuda_media_internal.items`로 준비한다. 사진은 앨범, 영상은 비디오에 표시된다. 합쳐 최소 2시간 간격, `queued`+`importing` 최대 24편을 목표로 한다. 사진/영상을 번갈아 고르고 파일·출처·라이선스·원본 및 파일 해시·이미지 유사도를 실제 검수한다. 파일 없는 글이나 이미지 링크만으로 완료라고 보고하지 않는다. 새 짤을 노트 큐와 `public.house_posts`에 넣지 않는다.

전용 자동 계정과 공원/미디어 경로를 구분하며 config/cron이 멈췄으면 재개하지 않는다. 중지된 별도 사진·영상 보충 작업을 켜지 않는다. 실제 회원 글과 이미 공개된 글은 건드리지 않는다. 기존 유효한 예약은 보존하고 중복 본문·원본 이미지는 제외한다. 공원은 날짜별 트랜잭션/잠금을 사용하고 미디어는 기존 원본/파일 해시 유일성 및 이미지 유사도 검사를 따른다. 구형 `stage_auto_cards`/`plan_auto_cards`를 새 일정 생성에 사용하지 않는다. 게시 실행은 기존 서버 cron과 `dispatch()`/`auto-house-media`에 맡기며 누락분을 몰아서 발행하지 않는다.

준비 수와 게시 수를 구분하고, 실제 반영한 경우만 쉬운 한국어로 짧게 한 번 보고한다. 접근 오류나 검수 불가로 일부만 준비되면 그대로 밝힌다. 비밀키·토큰·원본 파일의 Base64를 대화나 소스에 붙이지 않는다.
