# 오쭈다 다음 예약 준비

2026-10-12 사용자 변경을 반영한다. 이 문서가 과거 48/24/12장 공원 카드 지시 및 소설·유머·이슈·일상 각 3편 지시보다 우선한다.

먼저 최신 `docs/AUTO-HOUSE-NOTES.md`와 Supabase 프로젝트 `ziezbdjofcugznowiuda`의 실제 설정/예약을 읽는다. 한국 날짜 내일·모레의 빈 예약을 채운다.

- 공원: 짧은 플러팅 글 하루 4장, 6시간 간격. 슬롯 1·4·7·10, 01:01·07:01·13:01·19:01 KST.
- 우리집 노트: 웃긴 짤 이미지와 장면에 맞는 짧은 농담 중심, 하루 최대 12편, 기존 2시간 간격. `curated_humor`와 검수된 실제 이미지 링크/출처를 사용한다. 사진 없이 글만 작성한 것을 짤 준비 완료로 보고하지 않는다.

전용 자동 계정과 두 경로를 구분하며 config/cron이 멈췄으면 재개하지 않는다. 실제 회원 글과 이미 공개된 글은 건드리지 않는다. 기존 예약은 보존하고 중복 본문·원본 이미지는 제외한다. 날짜별 트랜잭션/잠금을 사용하고 기존 키를 다시 확인한다. 구형 `stage_auto_cards`/`plan_auto_cards`를 새 일정 생성에 사용하지 않는다. 게시 실행은 기존 서버 cron에 맡기며 누락분을 몰아서 발행하지 않는다.

준비 수와 게시 수를 구분하고, 실제 반영한 경우만 쉬운 한국어로 짧게 한 번 보고한다. 접근 오류나 검수 불가로 일부만 준비되면 그대로 밝힌다. 비밀키·토큰·원본 파일의 Base64를 대화나 소스에 붙이지 않는다.
