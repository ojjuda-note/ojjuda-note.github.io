# 바람의 궁수

휴대폰과 데스크톱에서 플레이하는 숲속 사격 게임. 화면은 정적 HTML/CSS/ES 모듈로 동작하며 빌드 단계가 없습니다. 이벤트 총알과 쭈 구매는 오쭈다 계정의 서버 RPC로 처리합니다. 오쭈다 오락실의 싱글게임에 테스트게임으로 등록되어 있고, 게임 화면 자체에는 테스트 모드가 없습니다.

실행 주소: `/world.html?game=archery`

## 본편: 50단계

사격장이나 아래 조준 영역을 누른 채 움직여 조준하고, 손을 떼면 발사합니다. 키보드는 방향키로 조준하고 스페이스를 누르고 있다가 놓습니다.

- 10초 안에 놓지 않으면 현재 방향으로 한 번 자동발사합니다. 뒤늦게 손을 떼어도 추가 발사하지 않습니다.
- 당기기 시작 후 1~9.5초에서 무작위로 뽑은 시점부터 정확히 0.5초 동안 조준 흔들림이 멈춥니다. 그동안 손가락이나 방향키로 조준을 조절할 수 있습니다.
- 기본 활의 흔들림은 앞선 조정의 2/3 수준을 유지합니다. 그립감이 높으면 흔들림이 줄고, 오래 당기면 피로가 늘어납니다.
- 50단계에 고정·이동 과녁, 새, 가까운 토끼, 먼 사슴, 돌담, 나무 울타리, 기둥, 지나가는 사람이 배치됩니다. 풍속은 단계에 따라 0.12에서 4.0까지 커지며 나뭇잎의 방향과 속도로 표현합니다.
- 토끼·사슴·새는 무작위 방향에서 나타나 반대편으로 지나갑니다. 이동 중 속도가 바뀌며 새는 위아래로 움직입니다. 각 통과 개체에 고유 번호가 있어 꽂힌 화살이 다음 동물로 옮겨 붙지 않습니다.
- 일반 이동 과녁도 연속적인 속도 변화를 보입니다. 본편 과녁 거리 14~104m, 토끼 24~33m, 사슴 55~74m, 새 36~67m입니다.
- 벽 뒤 과녁은 라운드마다 왼쪽·가운데·오른쪽의 불규칙한 위치에 배치됩니다. 시작할 때 높은 시점에서 실제 위치를 보여주며, ‘과녁 보기’로 다시 확인할 수 있습니다. 벽에는 과녁 위치 표시가 없습니다.
- 여러 기둥 뒤의 과녁은 이동하면서 틈 사이로 나타났다 가려집니다. 기둥은 각각 독립적인 충돌 상자이며 틈을 통과하는 화살을 막지 않습니다.
- 멀리 지나가는 사람 사이로 과녁을 겨누는 단계가 있습니다. 사람에게 닿으면 해당 발사는 0점이며 상처나 꽂힌 화살은 표시하지 않습니다.
- 본편은 5번 발사하면 한 판이 끝납니다. 목표 점수는 참고와 추가 보상 기준이며 다음 단계로 이동하는 조건이 아닙니다. 모든 50단계를 처음부터 선택할 수 있고, 이전·지금 단계 다시·다음 단계 버튼을 제공합니다. 화살과 표적은 같은 0.32배 시계로 움직이고 화면은 화살을 따라가다가 명중·착지 후 돌아옵니다.
- 화살과 궤적은 과녁·벽·기둥·사람에 가려집니다. 이동 과녁에 맞은 화살은 원래 위치와 각도를 유지하며 함께 움직입니다.

## 장비

### 활 10종, 석궁 10종

활은 그립감과 탄성이 독립적입니다. 안정적이지만 느린 장비, 빠르지만 흔들리는 장비를 선택할 수 있습니다. 석궁은 게임 균형을 위해 빠르게 출발하고 감속이 크게 설정되어 보통의 발사 각도에서 활보다 사거리가 짧습니다.

- 일반 석궁 5종은 단발입니다.
- 레어 석궁 5종만 3연발입니다. 한 번 놓으면 세 화살이 짧은 간격으로 발사되고 각각 독립적으로 충돌·낙하·바람을 계산합니다.
- 레어 석궁의 집탄성은 35·50·70·84·96으로 높아지며, 같은 조준점 주변에 점점 좁게 모입니다. 화살이 정확히 한 좌표로 겹치지는 않습니다.
- 3연발은 발사 기회 1회를 사용하며 세 화살의 최고 점수 하나를 반영합니다. 한 발이라도 사람에게 닿으면 해당 발사 전체가 0점입니다. 보상과 진행도는 한 번만 처리합니다.
- 상위 장비에는 3배 조준경을 구매해 장착할 수 있습니다. 조준경은 그 장비에 영구 귀속되고 다른 장비로 옮길 수 없습니다. 장비별로 별도 구매하며, 실제 카메라 확대와 세밀한 조준선이 적용됩니다.

### 화살 12종

촉 무게, 날개 면적, 공기 저항, 발사 속도의 안정성이 독립적입니다. 같은 활에서 무거운 화살은 출발이 느리지만 감속과 옆바람의 영향을 덜 받습니다. 넓은 날개는 옆바람과 공기 저항을 더 받고 좁은 날개는 덜 받습니다. 무거운 촉이 항상 더 멀리 가는 방식은 아닙니다.

상점에서 현재 활·화살 조합의 기준 발사 속도와 각 특성을 확인할 수 있습니다. 물리는 중력, 일정한 횡풍, 선형 공기 저항을 사용한 게임용 근사 모델이며 비행과 충돌은 렌더링 프레임 간격에 독립적인 해로 계산합니다.

## 5판마다 접시·UFO 이벤트

본편 라운드를 5판 완료할 때마다 이벤트가 자동으로 시작됩니다. 점수와 관계없이 완료한 판 수에 포함되며, 이벤트 플레이는 본편 판 수에 포함하지 않습니다. 본편 진행 화면에 다음 이벤트까지 남은 판 수를 표시합니다. ‘접시 사격’ 버튼으로 별도 연습도 가능합니다.

- 이벤트 난이도는 본편 5판 단위로 1~10단계가 됩니다.
- 한 번에 2개에서 최대 10개까지 표적이 뜨고 한 이벤트에 세 차례 등장합니다. 초기에는 천천히 올라가고 후반에는 빠르게 지나갑니다.
- 8단계부터 접시와 불규칙하게 움직이는 UFO가 함께 등장합니다.
- 제한시간 동안 깬 접시·UFO 개수를 기록하며 표적 하나마다 10코인을 얻습니다. 최소 점수나 격파 수와 관계없이 본편 다음 판으로 계속할 수 있습니다. 깨진 표적은 사라지며 다른 탄환으로 중복 기록할 수 없습니다.
- 이벤트는 제한된 시간 동안 연속으로 쏩니다. 탄환이 날아가는 동안에도 다음 표적을 겨눌 수 있습니다. 본편의 화살 추적과 달리 이벤트는 전체 사격 화면을 유지합니다.
- 탄창을 비우면 자동 장전하며, 장전 중 발사할 수 없습니다. 총기를 바꿨다가 돌아와도 해당 탄창과 남은 장전 시간을 유지합니다. 상점·도움말을 열거나 화면이 숨겨지면 게임 시계와 장전도 멈춥니다.
- 탄환은 전용 탄약을 사용합니다. 선택한 화살의 촉·날개나 당기는 시간은 총기의 탄속에 영향을 주지 않습니다.

| 총기 | 탄창 | 자동 장전 |
|---|---:|---:|
| 훈련용 공기총 | 2발 | 3.0초, 느림 |
| 숲길 카빈 | 2발 | 1.3초, 빠름 |
| 안정형 소총 | 4발 | 3.2초, 느림 |
| 장거리 소총 | 4발 | 1.5초, 빠름 |
| 정밀 사격총 | 10발 | 2.8초 |

기본 총기는 무료입니다. 총기 5종은 이벤트 전용 상점에서 선택하며, 본편의 활·석궁 선택과 별도로 저장합니다. 총기는 본편 동물·사람 단계에 사용할 수 없습니다. 이벤트 최고 격파 기록은 단계별로 저장합니다. 이벤트에서도 이전·지금 단계 다시·다음 단계를 자유롭게 고를 수 있습니다.

## 이벤트 총알과 쭈

- 본편 누적 완료 판 수가 처음 5·10·15·…·50판에 도달할 때마다 총알 20발을 받습니다. 계정당 열 번의 달성 보상이며, 이미 받은 구간에서는 중복 지급하지 않습니다. 5·10·15·20판 보상을 같은 날 받았다면 사용 전 총 80발입니다.
- 첫 달성 보상을 받은 다음 날부터, 한국 시간 기준 하루 첫 확인 때 총알을 20발까지 보충합니다. 남은 총알에 20발을 더하지 않습니다. 0·5·19발은 20발이 되고, 20·21·80발은 그대로입니다.
- 20발 이상이어서 보충하지 않은 날에도 확인을 완료한 것으로 기록합니다. 그날 모두 소모해도 같은 날 다시 무료 보충되지 않습니다.
- 구매한 총알도 남은 총알에 포함해 일일 보충 여부를 계산하며 날짜가 바뀌어도 사라지지 않습니다. 추가 구매는 20발에 1쭈입니다. 가격과 지급량은 서버에서 결정합니다.
- 총알 한 발은 발사 승인 때 한 번 차감합니다. 탄창 장전·총기 변경·단계 재시작·이벤트 재입장은 총알을 늘리지 않습니다. 탄창에 든 수량도 보유 총알에 포함됩니다.
- 서버 응답을 기다리는 동안 이벤트 시계와 표적·탄환 움직임을 멈추고 놓았을 때의 조준 방향을 유지합니다. 승인된 뒤 발사하므로 통신 지연으로 남은 시간이 줄지 않습니다.
- 실패 여부를 모르는 구매·발사 요청은 원래 요청 번호로 확인합니다. 새로고침 후 이전 요청 확인만으로 새 구매나 발사를 실행하지 않습니다. 쭈 차감과 총알 지급은 하나의 서버 트랜잭션입니다.

## 저장과 구조

- 게임 코인, 보유 장비, 선택한 활·화살·이벤트 총기, 장비별 조준경, 선택 단계, 본편 완료 판 수와 이벤트 기록을 브라우저에 저장합니다.
- 기존 v1 저장의 코인·장비·기록을 유지하며 새 필드를 보완합니다. 장비와 사격 점수는 다른 기기와 자동 동기화되지 않습니다.
- 총알, 달성 보상, 일일 보충 날짜와 쭈 구매 내역은 계정별 서버 기록입니다. 브라우저 저장값으로 총알이나 보상 판 수를 지급하지 않습니다. 로그인한 오락실에서 이용합니다.
- 장비는 게임에서 모은 코인으로 구매합니다. 활·석궁의 화살은 계속 사용할 수 있고 이벤트 총알은 발사할 때 소모합니다. 총알 추가 구매만 오쭈다 쭈 지갑과 연결하며 순위 기록은 변경하지 않습니다.
- `engine.mjs`: 장비·50단계·이벤트 데이터, 탄도, 충돌, 동물·사람·접시·UFO 움직임
- `scenery.mjs`: 절차적 숲, 동물, 사람, 장애물, 활·석궁·총기·탄약 그림
- `view.mjs`: 추적·미리보기 카메라, 투영과 가림 기하
- `game.mjs`: 입력, 3연발, 이벤트 연속 사격·장전, 진행, 저장, 상점, 렌더링
- `ammo-client.mjs`: 계정 브리지, 총알 조회·사용·구매·판 완료 요청, 재시도와 영수증 확인
- `index.html` / `style.css`: 한국어 UI, 반응형 레이아웃

## 검증

```sh
cd tests
npm run test:archery
```

물리 검증은 50단계와 여러 랜덤 배치의 명중 가능성, 기둥 사이 통과, 이동 사람의 연속 충돌, 동물 개체 유지, 레어 집탄성, 모든 이벤트 난이도의 다중 표적, UFO 경로, 총기 탄환과 탄창을 포함합니다. 게임 통합 검증은 실제 모듈을 실행하며 DOM과 시간만 대체합니다. 구매·저장·귀속 조준경, 10초 자동발사·0.5초 안정, 3연발 점수와 보상, 50단계 진행, 이벤트 전환·총기 분리·장전·다중 표적을 확인합니다.

브라우저 검수에는 실제 렌더러를 사용한 데스크톱과 390px 폭의 모바일 레이아웃이 포함됩니다. 개발용 검증 버튼은 별도 복사본에서만 사용하며 배포 코드에는 포함하지 않습니다.
