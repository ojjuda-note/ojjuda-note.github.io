# 바람의 궁수

휴대폰과 데스크톱에서 플레이하는 숲속 사격 게임. 화면은 정적 HTML/CSS/ES 모듈로 동작하며 빌드 단계가 없습니다. 이벤트 총알의 쭈 구매는 오쭈다 계정의 서버 RPC로 처리합니다. 코치는 무료 기본 기능이며 계정 연결 없이도 사용합니다. 오쭈다 오락실의 테스트 게임 구역에 등록되어 있고, 게임 화면 자체에는 테스트 모드가 없습니다.

실행 주소: `/world.html?game=archery`

## 화면과 안정제

- 활·석궁의 시위 당기는 게이지와 퍼센트는 사격장 바로 위에 표시합니다. 총기 이벤트에서는 같은 위치에 장전바를 보여줍니다. 게이지는 사격장 밖의 고정 높이 영역에 있어 표적을 가리지 않고 당기는 동안 화면 크기가 바뀌지 않습니다.

- 명중·빗나감 안내는 사격장 밖의 작은 상태 행에 표시합니다. 비행·이벤트 시간·안정제 상태도 단계 제목 아래에서 표시하므로 표적을 가리지 않으며, 표시가 바뀌어도 사격장 크기는 유지됩니다.

- 원형 과녁의 중심에 10점으로 명중하면 실제로 기록한 마지막 약 3.4m 경로를 다시 보여줍니다. 화살을 비껴 따라가는 0.48초, 충돌을 보여주는 0.82초, 조준 화면으로 돌아오는 0.60초로 총 1.90초입니다. 명중 직후에는 카메라가 짧게 다가갔다 회복하며 작게 흔들립니다. 동물과 접시·UFO 이벤트는 대상이 아니고, 연출 중 점수·코인·발사 횟수를 다시 더하지 않습니다.
- 벽·기둥이 있는 미션에서는 추적·명중 카메라에서 실제 화살촉과 몸통까지의 시선이 벽의 앞·뒤·옆면에 막히는지 확인합니다. 가려지는 경우 위나 옆의 보이는 시점으로 보정하고 화살을 화면 안에 맞춥니다. 일반 명중, 움직이는 과녁에 붙은 화살, 3연발의 대표 화살, 10점 확대 장면과 움직임 줄이기 설정에 적용하며, 복귀는 마지막으로 보여 준 시점에서 원래 조준·확대·화면 이동 상태까지 이어집니다. 벽의 실제 충돌과 깊이 순서는 유지하므로 벽 안에 들어간 화살 부분까지 투시하지 않습니다.
- 실제 명중 위치에서 짧은 별 모양 금빛 충격과 대비가 선명한 파동 두 겹, 방사형 속도선이 터집니다. 금빛 불꽃과 나무 조각은 감속하며 중력 방향으로 휘어져 1.2초 안에 사라집니다. 꽂힌 화살은 촉을 명중 위치에 고정한 채 몸통만 0.60초 동안 잔떨림을 보이고, 10점 배지는 실제 충돌 순간에 맞춰 나타납니다. 시작 전환과 명중 순간에는 화면 가장자리만 잠깐 어두워져 중앙의 과녁을 유지합니다. 움직임 줄이기 설정에서는 추가 추적·확대·흔들림, 날아가는 입자와 가장자리 효과를 생략하고 작은 고정 금빛 후광을 표시합니다.

- 사격장과 조작 버튼이 한 화면에 들어오도록 화면의 남은 높이를 사용합니다. 세로 화면은 아래 조작부, 높이가 짧은 가로 화면은 오른쪽 조작부를 사용합니다. 상단의 글자가 보이는 `무기 상점` 버튼으로 장비를 고릅니다. `메뉴`에 이전·지금·다음 단계, 전체 단계 선택, 소리, 도움말을 모았습니다.
- 총기 이벤트에서 접시나 UFO를 하나 깨면 안정제 교환용 접시 점수 1개가 즉시 적립됩니다. 여러 판의 점수를 모을 수 있고, 빗나간 발사나 본편 과녁에는 적립되지 않습니다.
- 상단 안정제 버튼에서 접시 점수 5개로 안정제 1개를 구매합니다. 게임 코인이나 쭈를 차감하지 않습니다.
- 총기 이벤트에 들어오면 준비 화면에서 선택 총기·탄환 잔량·제한 시간을 보여주고 `사격 시작`을 기다립니다. 시작 전에는 시간·표적·탄환 소모가 진행되지 않으며, 총기 상점이나 총알 충전 창을 닫아도 준비 화면으로 돌아옵니다. 총알 확인 중이거나 잔량이 0이면 시작 버튼을 비활성화합니다.
- 이벤트가 끝나면 마지막 탄환의 명중까지 한 번만 정산한 뒤, 결과창에 안정제 교환·총기 구매 및 장착·이전/지금/다음 단계 선택을 함께 보여줍니다. `안정제 1개 교환`을 누를 때만 접시 점수 5개를 차감합니다. 5개 미만이거나 보유 한도이면 교환 버튼만 비활성화하며, 총기를 사거나 다음 단계로 갈 수 있습니다. 상점에서 돌아와도 결과와 단계 선택을 유지합니다.
- 결과창에서 교환 후 점수가 5개 이상 남으면 계속 교환할 수 있습니다. 부족해지면 교환 버튼만 비활성화하고 같은 결과창을 유지합니다. 상단에서 따로 여는 수동 교환창은 닫기·Escape·바깥 영역 누르기로 나갈 수 있습니다. 교환한 안정제는 다음 판에서 직접 사용합니다.
- 발사를 준비하는 상태에서 안정제를 사용하면 재고 1개를 소비하고, 이번 판의 남은 발사에서 조준 흔들림이 정확히 50%로 줄어듭니다. 활·석궁·이벤트 총에 적용되며 한 판에 한 번만 사용할 수 있습니다.
- 다음 판·재도전·다른 단계·이벤트 전환·새로고침으로 새 판을 시작하면 효과가 끝납니다. 쓰지 않은 접시 점수와 안정제는 기존 진행 기록과 함께 저장됩니다. 바람, 화살 속도, 기존의 조준 안정 시간은 그대로입니다.

## 본편: 220단계

사격장 화면 아래 3분의 1은 보이지 않는 터치 조작 영역입니다. 조이스틱 원이나 버튼을 표시하지 않습니다. 아래 영역을 누르면 기존 조준점을 유지하고, 손가락을 움직인 방향과 거리(CSS 픽셀)만큼 위쪽 조준점이 1:1로 움직입니다. 1·2·3배 확대에서도 같은 손가락 이동은 같은 화면 이동이 됩니다. 가속이나 이동 감쇠가 없고, 손가락을 멈추면 수동 조준 이동도 멈춥니다. 장비의 흔들림·조준 안정 시간·안정제 효과는 별도로 적용됩니다. 먼 거리의 빠른 동물은 확대를 낮춰 현재 몸과 앞쪽 겨냥점을 함께 보며 움직임을 읽을 수 있습니다.

위쪽에서 시작한 터치는 조준이나 발사를 시작하지 않습니다. 아래 영역에서 시작한 조작은 손가락이 밖으로 나가도 유지되고, 손을 떼면 마지막 위치까지 반영해 한 번 발사합니다. 조준 기준점은 화면 위쪽 3분의 2 안에서 움직이며, 가장자리에서는 넘친 거리만큼 연속적으로 화면이 이동합니다. 취소·화면 이탈·화면 크기 변경에는 발사하지 않습니다. 키보드는 방향키로 조준하고 스페이스를 누르고 있다가 놓습니다.

- 10초 안에 놓지 않으면 현재 방향으로 한 번 자동발사합니다. 뒤늦게 손을 떼어도 추가 발사하지 않습니다.
- 본편 20개 무기를 성능 순서로 올릴수록 조준 안정 시간이 0.5~2초로 길어집니다. 기본 활은 0.5초, 최고급 레어 명인석궁은 2초입니다. 당기기 시작 때 현재 장비의 안정 시간을 고정하고, 시작 시점은 1초부터 `10초 - 안정 시간` 사이에서 한 번 무작위로 뽑습니다. 안정 구간 시작 0.6초 전부터 흔들림 배율을 smoothstep 곡선으로 1에서 0까지 서서히 낮춥니다. 완전히 멈춘 구간의 길이는 장비별 0.5~2초를 유지하고, 그 구간이 끝나는 순간에는 원래 흔들림으로 즉시 돌아옵니다. 내부 흔들림 계산은 정지 중에도 이어져 복귀할 때 새로 시작하지 않습니다. 전체 안정 구간이 10초 자동발사 전에 들어오며 그동안 손가락이나 방향키로 조준을 조절할 수 있습니다. 이벤트 총기의 안정 시간은 0.5초입니다.
- 활·석궁·총기의 실제 조준 흔들림을 1.6.1 버전보다 20% 더 낮췄습니다. 기본 흔들림 계산의 68%를 실제 조준에 적용합니다. 그립감에 따른 차이와 오래 당길 때의 피로 변화는 유지하고, 안정제를 사용하면 줄어든 흔들림에서 다시 절반이 됩니다.
- 본편은 기존 120단계 뒤에 장거리 100단계를 더한 총 220단계입니다. 처음 120단계는 30개 과제에 네 거리씩 배치합니다. 기본 고정·높은 고정·이동·바람·높낮이 → 부분 가림 → 동물 추적 → 사람 사이 빈틈 → 완전 가림과 복합 과제 순서로 연습합니다. 일반 과제는 10m·20m·30m·50m, 완전히 가려진 벽 넘기 과제는 활·석궁의 도달 가능성을 고려해 30m·35m·40m·50m를 사용합니다.
- 1~20단계는 기본 활로 거리·높은 곳 조준·이동·옆바람·높낮이를 익힙니다. 처음 1~8단계는 바람이 없고, 9~12단계와 17~20단계는 0.03~0.08의 약한 바람을 사용합니다. 13~16단계의 바람 읽기 네 과제는 1·1.1·1.2·1.3의 옆바람으로 화살이 실제로 밀리는 방향과 거리별 보정 차이를 익힙니다. 이후 21~48단계는 0.1~0.32, 49~105단계는 0.35~0.65, 106~120단계는 0.75~1.3입니다. 나뭇잎은 화살을 미는 방향으로 흐르며 바람이 강할수록 빨라집니다. 상단에는 방향 화살표와 세기를 표시하고, 바람이 없을 때만 ‘바람 없음’이라고 표시합니다.
- 초반 원형 과녁의 기본 반지름은 10m·20m·30m·50m에서 각각 1.45m·1.65m·1.85m·2.1m입니다. 먼 거리에서 표적이 갑자기 너무 작아지지 않도록 여유를 두며, 과제별 크기·움직임·바람·참고 목표와 권장 장비 구간을 함께 조정합니다.
- 양옆 벽 사이의 고정 과녁은 21~24단계에서 3/4, 25~28단계에서 1/2, 29~32단계에서 1/3이 보입니다. 비율은 원형 과녁의 실제 면적 기준이며 벽의 앞·뒷면 깊이와 원근을 반영합니다. 3/4 노출은 양쪽 벽이 합쳐서 과녁의 1/4을 가린다는 뜻입니다.
- 33~36단계는 기둥 뒤의 일정한 이동, 37~40단계는 불규칙한 속도 변화를 익힙니다. 가는 기둥 7개 뒤로 과녁의 약 3/4이 보이며, 77~80단계에서는 높낮이 변화도 더합니다. 기둥마다 독립된 충돌 상자가 있어 화살은 실제 열린 틈으로 지나가야 합니다.
- 5~8단계는 높은 고정 과녁입니다. 기존 41~44단계를 기본 과녁 바로 뒤로 옮기고, 같은 높이·거리·크기의 과녁에 무풍과 기본 장비 기준 목표 12·14·16·18점을 적용합니다. 41~44단계는 대각선 이동, 45~48단계는 낮은 담 너머 과녁입니다. 낮은 담은 과녁의 아래쪽을 가리며 중심은 보입니다. 완전히 숨은 과녁으로 넘어가기 전에 각도와 낙하를 익힙니다.
- 벽·기둥 구간의 위치는 라운드마다 왼쪽·가운데·오른쪽으로 달라집니다. 부분 가림은 과녁과 장애물 배치를 함께 옮겨 기준 노출 비율을 유지합니다. 장애물 구간은 시작할 때 높은 시점에서 실제 과녁을 보여주고, ‘과녁 보기’로 다시 확인할 수 있습니다. 벽에는 과녁 위치를 표시하지 않습니다.
- 49~72단계는 토끼·살쾡이·사슴·비둘기·독수리·치타를 각각 네 거리에서 따라갑니다. 토끼는 낮게 뛰고, 살쾡이는 짧은 보폭으로 달리며, 사슴은 더 길게 뜁니다. 비둘기는 짧고 빠르게 높이를 바꾸고, 독수리는 크게 솟구치고 빠르게 내려오며, 치타는 낮은 자세로 빠르게 달립니다.
- 동물은 무작위로 왼쪽 또는 오른쪽에서 나타나 반대편으로 지나갑니다. 한 번 통과하는 동안에도 속도가 연속적으로 달라집니다. 토끼는 짧고 뚜렷한 홉, 살쾡이는 반복적인 가감속, 사슴은 큰 도약, 비둘기는 빠른 상하 파동, 독수리는 큰 상하 급강하, 치타는 강한 가속 구간을 사용합니다. 몸체 폭으로 나눈 이동 속도는 이 종 순서대로 증가합니다. 각 개체에 고유 번호가 있어 꽂힌 화살이 다음 동물로 옮겨 붙지 않습니다. 113~116단계에서는 비둘기·독수리의 높낮이와 강한 바람을 함께 읽습니다.
- 73~80단계는 넓은 불규칙 이동과 기둥 사이 높낮이, 81~92단계는 한 사람 왕복·사람 행렬·행렬 사이 이동 과녁 순서입니다. 사람들은 과녁 바로 앞을 빠르게 가로막고, 여러 명이 겹쳐 지나가는 판은 짧은 틈이 열리는 시각을 겨눕니다. 장거리에서도 과녁과 함께 크기와 이동 범위를 조정하되 왕복 시간은 유지합니다. 사람에게 닿으면 해당 발사는 0점이므로 화살이 지나갈 길이 열리는 순간을 기다립니다. 93~96단계는 고정된 좁은 틈 뒤로 과녁이 움직여, 중앙에서는 절반이 보이고 이동 중에는 보이는 부분이 달라집니다.

그림을 그리는 동일한 경로·변환·클립으로 명중을 판정합니다. 옛 바깥 타원 안이더라도 귀 사이·다리 사이·몸 주변의 빈 공간은 빗나갑니다. 심장은 가슴의 작은 금색 표시로 보이며, 방향이 바뀌어도 그림·명중 부위·꽂힌 위치가 함께 뒤집힙니다. 움직이는 귀·발에 꽂힌 화살은 해당 부위의 실제 움직임을 따릅니다.

### 권장 장비에 맞춘 난이도

1~20단계는 기본 활, 21~48단계는 하위 활·석궁, 49~105단계는 중간 활·석궁, 106~220단계는 상위 활·석궁을 기준으로 조정합니다. 새 121~220단계는 거리별 장거리 화살을 함께 권장합니다. 기존 원형 과녁의 크기·경로와 벽 배치를 유지하고, 실제 동물 윤곽과 부위 점수에 맞춰 동물 미션의 참고 목표를 조정했습니다. 동일한 조준 흔들림·발사 타이밍·속도 편차 표본으로 권장 활과 석궁 각각을 검사합니다. 재배열 전 번호를 난이도 곡선과 무작위 배치의 기준으로 사용해 순서 변경으로 바람·크기·배치가 달라지지 않게 합니다. 별도 속도 조정으로 본편의 움직이는 과녁과 동물 표적을 기존의 1.15배 속도로 움직입니다. 원형 과녁의 경로 폭·높이는 유지하며 불규칙 이동 주기를 같은 비율로 줄입니다. 동물은 그 위에 종별 통과 속도·가감속·점프·상하 파동을 구분하고, 같은 거리에서 뒤에 나오는 종일수록 몸집 대비 속도가 높아지게 조정합니다. 사람은 별도의 빠른 왕복과 행렬 패턴을 사용하며, 정지 과녁과 접시·UFO 이벤트의 속도는 그대로입니다. 새 화살 부품 성능에 맞춰 기존 마지막인 120단계의 참고 목표는 30점입니다.

활과 석궁은 각 종류 안에서 성능 순위를 나눕니다. 활은 종류 내 1위가 기본, 2~4위가 하위, 5~7위가 중간, 8~10위가 상위입니다. 석궁은 종류 내 1~3위가 하위, 4~7위가 중간, 8~10위가 상위입니다. 같은 등급 안에서도 상점 성장 순서대로 그립감과 탄성이 조금씩 높아지고, 레어 석궁은 집탄성도 좋아집니다.

## 장비

### 활 10종, 석궁 10종

본편 무기 20종은 기본 활부터 레어 석궁까지 하나의 성장 순서를 따릅니다. 그립감과 탄성이 번갈아 조금씩 높아지고, 이미 높아진 능력치는 다음 무기에서도 유지됩니다. 활에서 석궁으로 바뀌어도 이전 성능이 떨어지지 않습니다. 활과 석궁은 같은 발사·감속 규칙을 사용합니다.

- 일반 석궁 5종은 단발입니다.
- 레어 석궁 5종만 3연발입니다. 한 번 놓으면 세 화살이 짧은 간격으로 발사되고 각각 독립적으로 충돌·낙하·바람을 계산합니다.
- 레어 석궁의 첫 화살은 조준한 방향으로 나갑니다. 나머지 두 발은 그 주변에 퍼지며, 집탄성이 35·50·70·84·96으로 높아질수록 더 좁게 모입니다. 세 화살이 정확히 한 좌표로 겹치지는 않습니다.
- 3연발은 발사 기회 1회를 사용하며 세 화살의 최고 점수 하나를 반영합니다. 한 발이라도 사람에게 닿으면 해당 발사 전체가 0점입니다. 보상과 진행도는 한 번만 처리합니다.
- 상위 장비에는 3배 조준경을 구매해 장착할 수 있습니다. 현재 무기에 구매하는 즉시 실제 3배 확대가 적용되고, 해당 무기를 다시 장착하거나 새 판을 시작해도 3배로 시작합니다. 확대 버튼으로 1·2·3배를 선택할 수 있으며 현재 조준점과 발사 방향은 유지합니다. 조준경은 그 장비에 영구 귀속되고 다른 장비로 옮길 수 없습니다.

### 화살 19종

화살은 촉·몸통·깃을 각각 가진 완성 장비입니다. 촉과 몸통의 무게를 따로 정하고 깃의 무게까지 더해 총 무게를 계산합니다. 촉을 바꾸면 그만큼 총 무게가 변하며, 몸통의 무게가 자동으로 상쇄되지 않습니다. 촉의 재질·형태, 몸통의 재질·지름, 깃의 재질·형태를 상점에서 비교할 수 있습니다.

일반 화살 12종은 성장 순서에 따라 총 무게가 24g에서 20g으로 조금씩 줄어듭니다. 같은 활과 당긴 힘에서 편차를 제외한 기준 발사 속도는 전체 구간에서 약 9.5% 높아집니다. 완성 화살의 유효 감속 계수는 0.14에서 0.0828로, 바람 영향은 나무 화살 대비 100%에서 60%로 줄고, 일관성은 35에서 95로 높아집니다. 상위 화살에서도 이전의 기본 성능을 유지하거나 개선합니다. 일관성이 높아지면 최저·최고 발사 속도가 기준값 쪽으로 모입니다.

큰 깃은 자세를 빨리 잡는 대신 깃 자체의 항력과 옆바람 영향도 커집니다. 긴깃 화살은 이 특성을 유지하면서 가는 알루미늄 몸통으로 완성 화살의 저항을 줄입니다. 작은 깃의 약한 자세 제어는 더 균일한 몸통과 촉 정렬로 보완합니다. 금빛·은빛은 강철 촉의 색상 마감입니다. 재질별 우열을 일반화하지 않고 각 완성 화살의 무게·굵기·형상·정밀도를 함께 설정합니다.

#### 부품 모델과 참고 자료

실제 화살의 구성과 공력 원리를 다음 자료에서 참고했습니다.

- [World Archery, Equipment](https://www.worldarchery.sport/sport/equipment): 알루미늄·카본·복합재 몸통, 세트의 무게·크기 일치, 깃의 비행 안정화 역할.
- [World Archery, How to fletch an arrow](https://www.worldarchery.sport/news/146302/archery-101-how-fletch-arrow-plastic-vanes): 작은 유선형 깃의 속도 유지와 큰 깃의 빠른 자세 안정화.
- [Bohning, The Best Fletching Options](https://www.bohning.com/the-best-fletching-options-for-your-olympic-recurve-arrows/amp/): 큰 깃의 빠른 안정화와 감속·옆바람 영향 사이의 관계. 제조사의 일반적인 구성 설명을 참고했습니다.
- [Park 외, Air flow around the point of an arrow (2013)](https://journals.sagepub.com/doi/10.1177/1754337111430569): 촉 뒤쪽의 형상에 따른 흐름 분리와 몸통 항력의 차이. 시험 조건에서 확인한 형상 효과를 참고했습니다.

게임의 무게·지름·항력·정밀도 수치는 플레이를 위해 정한 근사값이며 실제 제품의 측정값이 아닙니다. 총 무게는 촉·몸통·깃의 합이며, 기준 발사 속도는 총 무게의 제곱근에 반비례합니다. 유효 감속은 세 부품의 항력을 합쳐 질량을 반영하고, 바람 영향은 몸통·깃의 면적 계수와 질량으로 계산합니다. `getArrowConsistency`는 몸통 정밀도 50%·촉 정밀도 20%·깃 제어 30%를 합칩니다. 이 일관성으로 기존 `velocityBias`의 발사 속도 편차를 줄여 사격 간 편차를 근사합니다. 깃은 발사 에너지를 추가하지 않습니다. 스파인 변형, 무게중심의 앞쪽 비율(FOC), 내구성은 시뮬레이션하지 않습니다.

비행은 중력, 일정한 횡풍, 선형 공기 저항을 사용합니다. 일반 비행 구간은 렌더링 프레임 간격에 독립적인 해로 계산하고, 특수 화살은 지면 접촉 시점의 반발 또는 고정 시간 간격의 유도 보정을 더합니다.

### 특수 화살 2종

탄성 화살은 튕긴 뒤에도 중력·바람·공기 저항과 충돌 판정을 그대로 받습니다. 두 번째 지면 접촉은 착지로 끝나며, 벽에 닿거나 이미 과녁을 지나친 화살은 튕기지 않습니다. 화면과 궤적은 첫 지면 접촉에서 끊기지 않고 실제 반발 이후 비행까지 따라갑니다.

자석 화살의 5m는 과녁이 놓인 평면까지의 거리가 아니라 화살과 실제 표적 중심 사이 거리입니다. 움직이는 과녁·동물의 현재 위치를 향해 약하게 보정하고, 유도를 시작한 동물의 통과가 끝나면 다른 개체로 옮겨 붙지 않습니다. 과녁 평면을 지나면 유도가 끝납니다. 보정 가속도는 최대 24m/s², 회전 속도는 최대 1rad/s, 누적 보정량은 최대 4m/s로 제한합니다. 크게 빗나간 화살을 되돌리거나 명중을 보장하지 않으며, 벽·기둥의 기존 충돌 판정이 그대로 적용됩니다.

상점 그림에서는 탄성 화살의 둥근 탄성 촉과 스프링 모양의 목 부분, 자석 화살의 청록색 촉과 작은 U자 고리로 두 종류를 구분합니다.

## 장비 성장 순서와 가격

상점 기본 정렬은 기존 ID별 성장 순서로 고정합니다. 순위를 다시 계산해 가격이나 보유 장비의 위치가 뒤바뀌지 않습니다. 무기는 그립감과 탄성을, 일반 화살은 부품 조합에 따른 기준 속도·일관성·바람·감속 성능을 조금씩 개선합니다. 예를 들어 그립 30·탄성 40 → 그립 40·탄성 40 → 그립 40·탄성 50처럼 한 능력치가 오르면 이전 능력치는 유지됩니다. 총기도 그립감·장전·탄창 성능이 낮아지지 않습니다. 탄창은 2·4·6·8·10발로 두 발씩 늘고, 장전은 3초에서 1초까지 0.5초씩 짧아집니다.

무기의 기본 순서는 활 10종→단발 석궁 5종→레어 3연발 석궁 5종이며 종류별 필터를 제공합니다. 그립감·탄성·조준 안정 시간·집탄성으로 정렬하고, 화살은 바람 영향·전체 일관성·촉 무게로 정렬합니다. 총기는 탄창·장전 시간·그립감으로 비교합니다. 정렬은 표시용 복사본에만 적용하고 보유 ID·장착 ID·조준경 귀속은 바꾸지 않습니다. 상점 카드에는 성장 순위와 현재 장비의 안정 시간, 코인 가격과 부족한 코인을 보여줍니다. 화살에는 촉·몸통·깃의 재질과 형태, 부품별 무게와 총 무게를 함께 표시합니다. 바람·감속 영향은 나무 화살을 100%로 비교합니다.

본편 무기의 0부터 시작하는 성장 순위가 r일 때 가격은 500r + 50r(r−1)코인, 화살은 300r + 25r(r−1)코인입니다. 무기 가격 차이는 500·600·700·…·2,300코인, 화살 가격 차이는 300·350·400·…·900코인으로 점점 커집니다. 본편 한 판 최초 목표 달성 시 최대 75코인, 같은 단계 반복 달성 시 최대 62코인인 보상은 유지합니다. 첫 유료 활 500코인과 화살 300코인은 한 판 보상으로 살 수 없습니다.

상위 본편 무기의 새 조준경은 무기 가격의 20%를 50코인 단위로 올림한 가격입니다(최소 500코인). 220단계 확장 후에도 보유 장비·조준경·게임 코인과 기록을 이어서 사용합니다. 이벤트 총기 가격과 계정 총알·쭈 지급 규칙은 이 가격 조정과 별개입니다.

## 5판마다 접시·UFO 이벤트

본편 라운드를 5판 완료할 때마다 이벤트 준비 화면이 열립니다. 총기와 총알을 확인한 뒤 사격 시작 버튼을 눌러야 제한 시간과 표적 이동이 시작됩니다. 점수와 관계없이 완료한 판 수에 포함되며, 이벤트 플레이는 본편 판 수에 포함하지 않습니다. 본편 진행 화면에 다음 이벤트까지 남은 판 수를 표시합니다. 직접 사격 이벤트에 들어가는 버튼이나 이벤트 재도전·단계 이동은 제공하지 않습니다.

- 이벤트 난이도는 본편 5판 단위로 올라가며 최대 10단계입니다. 본편 누적 50판 이후에도 5판마다 10단계 이벤트가 이어집니다.
- 한 번에 2개에서 최대 10개까지 표적이 뜨고 한 이벤트에 세 차례 등장합니다. 초기에는 천천히 올라가고 후반에는 빠르게 지나갑니다.
- 8단계부터 접시와 불규칙하게 움직이는 UFO가 함께 등장합니다.
- 제한시간 동안 깬 접시·UFO 개수를 기록하며 표적 하나마다 10코인을 얻습니다. 최소 점수나 격파 수와 관계없이 본편 다음 판으로 계속할 수 있습니다. 깨진 표적은 사라지며 다른 탄환으로 중복 기록할 수 없습니다.
- 이벤트는 제한된 시간 동안 연속으로 쏩니다. 탄환이 날아가는 동안에도 다음 표적을 겨눌 수 있습니다. 본편의 화살 추적과 달리 이벤트는 전체 사격 화면을 유지합니다.
- 총기 장전바는 단계 제목과 사격장 사이에 표시합니다. 장전 중에는 남은 시간과 진행률, 완료되면 탄창의 남은 총알 수를 보여줍니다. 이벤트 동안 공간을 유지해 장전이 시작되어도 사격장 크기가 바뀌지 않으며, 아래쪽에 중복 장전바는 표시하지 않습니다.
- 탄창을 비우면 자동 장전하며, 장전 중 발사할 수 없습니다. 총기를 바꿨다가 돌아와도 해당 탄창과 남은 장전 시간을 유지합니다. 상점·도움말을 열거나 화면이 숨겨지면 게임 시계와 장전도 멈춥니다.
- 탄환은 전용 탄약을 사용합니다. 선택한 화살의 촉·날개나 당기는 시간은 총기의 탄속에 영향을 주지 않습니다.
- 총 5종의 출발 탄속은 모두 본편 최고 실제 탄속의 정확히 2배입니다. 완전 당김·최대 양의 편차에서 활·석궁 20종×화살 19종을 기존 `getSpeed`로 평가합니다. 현재 최대는 78.6127m/s이고 총알은 157.2254m/s입니다. 총알 속도 편차는 0이며 장비 값이 바뀌면 자동으로 다시 계산합니다. 탄창·장전·그립·탄환 항력의 차이는 유지합니다.
- 기본 총기의 36m 정면 탄환은 약 0.261초에 도달합니다. 표적 면을 지나친 총알은 즉시 빗나감으로 끝나며 공중에 고정된 점으로 남지 않습니다. 활·석궁의 화살은 계속 날아가고 낙하합니다.

## 이벤트 총알과 쭈

- 본편 누적 완료 판 수가 처음 5·10·15·…·50판에 도달할 때마다 총알 20발을 받습니다. 계정당 열 번의 달성 보상이며, 이미 받은 구간에서는 중복 지급하지 않습니다. 5·10·15·20판 보상을 같은 날 받았다면 사용 전 총 80발입니다.
- 첫 달성 보상을 받은 다음 날부터, 한국 시간 기준 하루 첫 확인 때 총알을 20발까지 보충합니다. 남은 총알에 20발을 더하지 않습니다. 0·5·19발은 20발이 되고, 20·21·80발은 그대로입니다.
- 20발 이상이어서 보충하지 않은 날에도 확인을 완료한 것으로 기록합니다. 그날 모두 소모해도 같은 날 다시 무료 보충되지 않습니다.
- 구매한 총알도 남은 총알에 포함해 일일 보충 여부를 계산하며 날짜가 바뀌어도 사라지지 않습니다. 추가 구매는 **10발에 5쭈**입니다. 가격과 지급량은 서버에서 결정합니다. 가격 변경 이전에 산 총알과 기존 결제 영수증은 그대로 유지합니다.
- 총알 한 발은 발사 승인 때 한 번 차감합니다. 탄창 장전·총기 변경·단계 재시작·이벤트 재입장은 총알을 늘리지 않습니다. 탄창에 든 수량도 보유 총알에 포함됩니다.
- 서버 응답을 기다리는 동안 이벤트 시계와 표적·탄환 움직임을 멈추고 놓았을 때의 조준 방향을 유지합니다. 승인된 뒤 발사하므로 통신 지연으로 남은 시간이 줄지 않습니다.
- 실패 여부를 모르는 구매·발사 요청은 원래 요청 번호로 확인합니다. 새로고침 후 이전 요청 확인만으로 새 구매나 발사를 실행하지 않습니다. 쭈 차감과 총알 지급은 하나의 서버 트랜잭션입니다.

## 코치

- 코치는 **무료 기본 기능**으로 처음부터 켜져 있습니다. 구매·쭈 잔액·로그인·이용 기간과 관계없이 사용하며, 게임 메뉴에서 켜거나 끌 수 있습니다. 켜기·끄기는 현재 브라우저에 저장하고 기존에 꺼 둔 설정도 유지합니다.
- 상점의 코치 구매 탭과 구매 요청을 제거했습니다. 구버전의 대기 중이던 구매는 기존 요청 번호와 영수증으로 결과를 확인하며, 복구 때문에 코치 설정을 강제로 켜지 않습니다. 과거 결제 영수증과 잔액은 보존하고 신규 코치 결제는 서버에서 차단합니다.
- 본편의 활·석궁을 당기는 동안 현재 조준의 실제 탄도와 0.10초 뒤 반응 시점의 탄도를 함께 예측합니다. 원형 과녁은 두 예측이 모두 8점 이상이고, 동물은 같은 개체를 두 예측에서 맞힐 때 좋은 발사 순간으로 판단합니다. 바람·장애물·낙하·탄성 화살·자석 화살을 반영합니다. 레어 석궁은 중앙의 첫 화살로 명중을 판단하고, 나머지 두 발이 발사 간격과 사람의 움직임을 고려해 사람에게 닿는지도 확인합니다. 주변 화살이 벽에 막혀도 중앙 화살의 점수는 유지합니다. 한 번 당길 때 정한 퍼짐을 예측과 실제 발사에 함께 사용합니다. 총기 이벤트에는 개입하지 않습니다.
- 예측은 초당 최대 16회이며, 좋은 타이밍이 올 때마다 **“쏴!”**를 알려 줍니다. 사격장 오른쪽 위에서 작은 ‘코치’ 이름과 굵은 ‘쏴!’가 금빛·주황색 만화 폭발 말풍선 안에 나타납니다. 말풍선은 확대 버튼과 상단 정보 아래에 작게 배치하며, 좋은 조준 상태에서 계속 켜지고 빗나가면 꺼집니다. 화면 크기에 맞춰 줄어들고 터치를 가로막거나 나타날 때 사격장 크기를 바꾸지 않습니다. 움직임 줄이기 설정에서는 등장 애니메이션을 생략합니다. 새로운 기회는 이전 음성부터 최소 450ms 뒤에 다시 알리고, 좋은 상태가 이어지면 최소 1.4초 간격으로 반복합니다. 기다리는 사이 기회가 사라지면 뒤늦게 말하지 않으며 음성은 겹치지 않습니다. 조준점을 옮기거나 자동으로 발사하지 않으며 명중을 보장하지 않습니다. 소리가 켜져 있으면 한국어 음성으로 말하고, 음성을 쓸 수 없는 환경에서는 짧은 신호음과 화면 안내를 사용합니다.
- 코칭은 브라우저 안에서 계산합니다. 과거 이용권 만료나 화면 복귀 때의 총알·지갑 조회 실패로 코치가 꺼지지 않습니다. 기존 서버 이용권 필드는 구버전의 상태 조회·영수증 복구 호환을 위해 보존하지만 기본 코치의 사용 조건으로 삼지 않습니다.

## 저장과 구조

- 게임 코인, 보유 장비, 선택한 활·화살·이벤트 총기, 장비별 조준경, 선택 단계, 본편 완료 판 수와 이벤트 기록을 브라우저에 저장합니다.
- 현재 저장 키는 `forest-archer-progress-v4`, 과제 순서는 `missions-220-v1`입니다. v4가 없으면 v3의 기록·재화·장비·설정을 모두 가져옵니다. 기존 41~44단계 기록은 5~8로, 기존 5~40은 9~44로 옮기며 1~4와 45~120은 같은 번호를 유지합니다. 선택 단계와 기존 120개 최고 점수에 같은 매핑을 한 번만 적용합니다. 이미 재배열된 `missions-120-v2`는 번호를 유지하며 새 121~220단계에는 기록을 만들어 넣지 않습니다.
- v4가 생긴 뒤에는 v3를 다시 가져오지 않아 옛 탭이 옛 순서로 저장해도 새 기록을 덮지 않습니다. 구 50단계 기록과 기존 120단계 기록은 각각의 매핑으로 구분해 이전합니다. 장비와 사격 점수는 다른 기기와 자동 동기화되지 않습니다.
- v4와 v3가 모두 없을 때에만, 2026-11-02에 시행한 초기화 정책에 따라 이전 v2의 코인·접시 교환 점수·안정제·보유 및 장착 장비·조준경·소리/코치 설정을 가져오고 사격 기록을 새로 시작합니다. 이미 v3에 저장된 기록은 이번 재배열에서 초기화하지 않습니다.
- 앞서 시행한 기록 초기화에서는 서버의 본편 완료 판 수도 한 번 0으로 만들고 초기화 이전의 미완료 판을 폐기했습니다. 이번 과제 순서 재배열에서는 서버 기록을 변경하지 않습니다. 총알 잔액·코치 이용 기간·쭈·구매 영수증·기존 달성 보상 이력은 보존합니다. 이미 받은 달성 총알은 같은 순번에서 다시 지급하지 않습니다. 이전 서버 상태는 비공개 백업에 보관합니다.
- 대기 중인 계정 구매·판 완료 요청은 원래 요청 번호와 서버 실행 번호·단계 값을 그대로 사용해 영수증을 확인합니다. 확장 때문에 과거 결제나 완료 요청의 내용을 다시 쓰지 않으며, 새로 시작하는 판부터 220단계 목록의 번호를 사용합니다.
- 220단계용 서버 마이그레이션은 기존 120단계에서 시작·완료 요청의 유효한 범위만 넓힙니다. 현재 무료 코치 처리를 포함한 함수에서 범위 조건만 교체하고 권한·검색 경로·RLS를 유지합니다. 계정 총알·완료 판 수·달성 보상 이력·코치 만료 시각·쭈 지갑·결제 영수증은 초기화하지 않습니다. 기존에 시작한 120단계 이하의 판도 계속 완료할 수 있습니다.
- 총알, 달성 보상, 일일 보충 날짜와 쭈 구매 내역은 계정별 서버 기록입니다. 과거 코치 만료 시각과 결제 영수증도 복구용으로 보존합니다. 브라우저 저장값으로 총알이나 보상 판 수를 지급하지 않습니다. 로그인한 오락실에서 이용합니다.
- 장비는 게임에서 모은 코인으로 구매합니다. 활·석궁의 화살은 계속 사용할 수 있고 이벤트 총알은 발사할 때 소모합니다. 총알 추가 구매는 오쭈다 쭈 지갑과 연결하며 순위 기록은 변경하지 않습니다. 코치는 쭈를 사용하지 않습니다.
- `engine.mjs`: 장비·220단계·이벤트 데이터, 탄도, 충돌, 동물 체력과 개체별 상태, 동물·사람·접시·UFO 움직임
- `animal-zones.mjs`: 동물 공통 그림·실루엣·부위 점수·움직이는 부위의 화살 부착·쓰러짐 변환
- `scenery.mjs`: 절차적 숲, 동물, 사람, 장애물, 활·석궁·총기·탄약 그림과 중심 명중의 금빛 연출
- `view.mjs`: 추적·미리보기 카메라, 투영과 가림 기하
- `cinematic.mjs`: 기록된 중심 명중의 마지막 비행과 충돌을 다시 보여주는 카메라 연출
- `game.mjs`: 입력, 3연발, 이벤트 연속 사격·장전, 진행, 저장, 상점, 렌더링
- `coach.mjs`: 현재·반응 시점의 탄도 예측과 코치 발사 신호 판단
- `ammo-client.mjs`: 계정 브리지, 총알 조회·사용·구매·판 완료, 과거 코치 요청을 포함한 재시도와 영수증 확인
- `index.html` / `style.css`: 한국어 UI, 반응형 레이아웃

## 검증

```sh
cd tests
npm run test:archery
```

장비 검증은 기존 ID·가격·상점 순서를 보존하면서 인접한 상위 장비의 기본 성능이 낮아지지 않는지 확인합니다. 화살 부품의 독립적인 질량·항력·바람 영향·정밀도와 이를 합친 기준 발사 속도·일관성을 검증하며, 총기의 두 발씩 늘어나는 탄창과 0.5초씩 짧아지는 장전도 확인합니다.

물리 검증은 일반 과제의 10·20·30·50m와 완전 가림 과제의 30·35·40·50m 순서, 원형 과녁의 노출 면적, 이동 중 기둥의 부분 가림, 기존 120단계와 새 100개 장거리 판의 여러 랜덤 배치 명중 가능성, 기둥 사이 통과, 이동 사람의 연속 충돌, 동물 개체 유지·부위 점수·빈 공간 통과·체력·사망 낙하·화살 부착, 레어 집탄성, 모든 이벤트 난이도의 다중 표적, UFO 경로, 총기 탄환과 탄창을 포함합니다. 게임 통합 검증은 실제 모듈을 실행하며 DOM과 시간만 대체합니다. 구매·저장·귀속 조준경, 10초 자동발사·장비별 0.5~2초 안정·능력치 정렬·점점 커지는 가격 차이, 3연발 점수와 보상, 220단계 진행, 기록의 일회성 초기화와 구매 자산 보존, 이벤트 전환·총기 분리·장전·다중 표적을 확인합니다.

브라우저 검수에는 실제 렌더러를 사용한 데스크톱과 390px 폭의 모바일 레이아웃이 포함됩니다. 개발용 검증 버튼은 별도 복사본에서만 사용하며 배포 코드에는 포함하지 않습니다.

중심 명중 연출의 검수 대상에는 원형 과녁 10점만 반응하는지, 마지막 3.4m의 실제 기록 경로와 명중 위치를 사용하는지, 접촉 순간 카메라가 튀지 않는지, 점수·코인이 한 번만 반영되는지가 포함됩니다. 초기 0.19초의 별 모양 충격과 이후의 파편 이동이 구분되는지, 가장자리 효과가 과녁 중앙을 가리지 않는지, 움직임 줄이기 설정에서 추가 카메라 움직임·입자 이동·가장자리 효과가 사라지는지도 확인합니다. 320px·640px·1280px 화면에서 효과가 과도하게 커지거나 캔버스 상태를 바꾸지 않아야 합니다.

코치 통합 검증은 무료 기본 사용, 빈 지갑·만료된 과거 이용권·계정 연결 없음, 메뉴 켜기·끄기와 저장값 보존, 무음·음성 미지원 환경, 화면 복귀 중 조회 실패, 과거 영수증 복구와 추가 결제 없음, 발사·조준 비개입을 확인합니다. 로컬 PGlite 결제 검증은 총알 10발/5쭈와 기본 기능 전환 뒤 코치 신규 결제 차단, 기존 영수증·잔액 보존, 중복 요청·소유자·상품 충돌, 잔액 부족, 원장 실패 시 전체 롤백을 확인합니다. 과거 유료 코치의 마이그레이션 검증도 유지합니다. 220단계 허용과 221단계 거절, 확장 전후 계정·실행·영수증 보존도 확인합니다. 기존 5판 단위 20발 지급은 최초 완료 50판까지만 적용되며, 220판을 완료해도 달성 보상은 총 200발입니다. 하루 20발까지 보충하는 규칙도 함께 검증합니다.
