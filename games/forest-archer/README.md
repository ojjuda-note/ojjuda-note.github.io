# 바람의 궁수

싱글게임용 테스트게임입니다. `index.html`을 정적 파일로 제공하며 별도 빌드가 필요 없습니다.

- 누른 채 조준하고 놓으면 발사하며, 10초가 지나면 자동 발사합니다.
- 매 당기기마다 1~10초 사이에 무작위로 정해진 0.5초 동안 조준 흔들림이 멈춥니다.
- 12단계의 바람을 화살 물리와 나뭇잎 이동에 함께 적용합니다.
- 장비는 게임 안에서 획득한 코인으로 구매·장착하며 별도 체험 모드는 없습니다.
- 진행도와 장비는 이 브라우저에 저장됩니다. 오락실 순위와 공용 지갑은 사용하지 않습니다.

검증: `npm --prefix tests run test:archery`
