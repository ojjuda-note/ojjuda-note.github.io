# 바람의 궁수

휴대폰과 데스크톱에서 플레이하는 숲속 활쏘기 게임. 정적 HTML/CSS/ES 모듈로 동작하며 빌드 단계나 백엔드는 필요하지 않습니다.

## 플레이

사격장 또는 아래 조준 영역을 누른 채 움직여 조준합니다. 손을 떼면 그 순간의 조준 방향과 당긴 힘으로 발사합니다. 키보드에서는 방향키로 조준하고 스페이스를 누르고 있다가 놓습니다. 10초 동안 놓지 않으면 현재 조준 방향으로 한 발을 자동발사합니다.

- 기본 조준 흔들림을 이전의 정확히 2/3로 완화. 상위 활도 같은 비율로 줄이며 불규칙한 움직임과 오래 당길 때의 피로는 유지
- 매번 당기기 시작 후 1~10초 사이, 무작위 시점에 정확히 0.5초간 조준 흔들림 없음
- 안정 구간은 시작 시각을 1~9.5초에서 균등하게 뽑으며, 안정 중에도 손가락·방향키 조준 가능
- 자동발사 남은 시간과 안정 중 표시, 10초 자동발사 후 손을 떼어도 추가 발사 없음
- 단계별로 강해지는 바람을 나뭇잎의 이동 방향과 속도로 표시
- 화살의 바람 반응을 이전의 2.5배로 강화. 나무·깃털·탄소·은빛 화살은 기본 화살 대비 바람 영향을 각각 0%·25%·50%·70% 줄이며, 장비 상점과 장착 정보에 표시
- 중력·바람·비행시간·이동 표적·장애물의 연속 충돌 계산
- 14~70m의 12개 단계: 고정 과녁, 이동 과녁, 새, 사슴, 담장, 복합 조건
- 활 4종과 화살 4종, 코인 구매와 영구 장착
- 코인·보유 장비·해금 단계·마지막 단계의 브라우저 로컬 저장
- 모든 단계에서 메인 화면이 화살을 0.32배 슬로모션으로 추적하며 명중·착지 후 조준 위치로 복귀
- 과녁과 장애물 뒤의 화살·궤적을 깊이순으로 가리고, 앞쪽 부분과 과녁 밖으로 빗나간 화살은 계속 표시
- 이동 과녁·새·사슴에 꽂힌 여러 화살이 각자의 명중 위치와 각도를 유지하며 함께 이동
- 장애물 단계 시작 시 높은 시점에서 실제 과녁을 미리 보여주고, 조준 중 ‘과녁 보기’로 재확인 가능. 벽의 과녁 윤곽선·위치 표시는 제거
- 초반 예상 궤적, 확대 및 조준 화면 이동, 효과음

## 구조

- `index.html`: 한국어 UI, 접근 가능한 메뉴와 모달
- `style.css`: 데스크톱/태블릿/휴대폰 반응형 레이아웃
- `engine.mjs`: 순수 탄도·충돌·흔들림·장비·단계 데이터
- `scenery.mjs`: 캐시를 사용하는 절차적 숲·동물·활·화살 그림
- `view.mjs`: 카메라 추적·복귀, 투영, 가까운 시야면 잘라내기, 가림을 위한 선분 분할
- `game.mjs`: 입력, 게임 진행, 저장, 상점, 렌더링

## 확인

```sh
cd tests
npm run test:archery
```

탄도·충돌·단계별 바람, 카메라·가림 기하, 실제 게임 모듈의 통합 시나리오를 검증합니다. 통합 검증에는 입력·5발 진행·구매·미구매 장비 사용 차단, 10초 자동발사와 중복 방지, 정확한 0.5초 안정 구간, 취소·화면 숨김 처리, 모든 단계의 동일한 슬로모션 시간, 추적·복귀·화면 크기 변경, 화살 가림과 움직이는 표적에 대한 부착이 포함됩니다. 통합 테스트는 DOM과 시간을 대체하지만 게임·물리·카메라 모듈은 실제 코드를 실행합니다.

초기 브라우저 검수에서 데스크톱과 390px 휴대폰 화면, 발사·명중·상점을 확인했습니다. 현재 버전의 구매·장착·5발 진행과 자동발사·안정 구간은 위 통합 테스트로 확인합니다. 휴대폰 검수는 브라우저 안의 좁은 뷰포트로 수행했습니다. 다른 기기 간 기록 동기화는 지원하지 않습니다.

오락실의 싱글게임에 테스트게임으로 등록되어 있습니다. iframe 실행 주소는 `/world.html?game=archery`이며 오락실 공용 코인·순위와는 연결하지 않습니다.
