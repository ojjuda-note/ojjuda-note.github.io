# 사천성

싱글 플레이 사천성 200단계. 같은 그림이 **2장 또는 4장**인 종류를 한 판에 섞고, 모든 층을 합쳐도 같은 그림은 최대 4장입니다. 패는 무작위로 배치하며 막히면 무료로 다시 섞습니다.

1~5단계 1층, 6~10단계 2층, 11~15단계 3층, 16~25단계 4층, 26~40단계 5층, 41~70단계 6층, 71~110단계 7층, 111~200단계 8층입니다. 각 층은 십자·고리·계단·모래시계·섬·다이아몬드·지그재그·성벽처럼 다양한 실루엣과 구멍을 가집니다. 윗층을 모두 비우면 아랫층이 열립니다. 층 사이에 패를 교차 연결하지 않습니다. 첫 15단계의 전체 패 수는 기존과 같고, 이후에는 난이도에 따라 늘어나다가 최대 1,200개로 제한합니다.

완료 시간은 오락실의 이번 달 게임순위에 자동 등록합니다. 회원과 손님을 합쳐 한 사람당 최고 기록 하나를 비교합니다. 완료한 단계가 높을수록 우선이며, 같은 단계는 가장 짧은 시간, 같은 시간은 먼저 달성한 순서입니다. 첫 패·힌트·섞기부터 시간을 측정하며 같은 판에서 다른 탭을 보는 동안에도 시간은 흐릅니다. 서로 다른 그림 또는 연결 경로가 막힌 두 패를 선택할 때마다 경과 시간에 10초가 누적되고, 화면 시간과 완료 기록에 모두 포함됩니다. 첫 패 선택·선택 취소·빈 칸·확대 및 이동 조작에는 가산 시간이 없으며, 새 판을 시작하면 가산 시간도 초기화됩니다. 기존 완료 기록은 그대로 보존합니다. 마지막으로 하던 레벨은 같은 브라우저에 자동 저장됩니다. 게임을 나갔다 다시 열거나 새로고침하면 마지막 레벨의 새 판과 새 실행 ID로 시작하며, 시간과 오답 가산은 초기화됩니다. 저장된 레벨이 없거나 1~200 범위의 정수가 아니면 1단계에서 시작합니다. 해금한 단계와 개인 기록은 보존하고, 등록 실패한 완료 기록은 동일한 계정에서 재전송할 수 있습니다.

게임판은 화면의 가로·세로에 맞춰 전체 보기로 시작합니다. 난이도별 패 수를 층마다 짝수로 나누고, 게임판 크기에 맞춰 화면 비율을 조절합니다. 배치의 구멍은 실제 빈 칸으로 남으며, 각 층의 실루엣은 무작위로 바뀝니다. 패를 섞거나 층을 바꿔도 이미 비운 칸과 전체 진행 시간은 유지됩니다. 화면을 회전하거나 크기를 바꿔도 패 위치·선택·진행 시간을 보존하고 표시 크기만 조절합니다. 단계·남은 패·시간과 힌트·섞기·확대 버튼만 표시하며, 순위·기록·도움말·효과음·다시 하기는 게임 메뉴에서 엽니다. 모든 단계에서 전체 보기 상태로 패를 직접 선택할 수 있습니다.

완료 화면에서 이전 레벨·지금 레벨 다시 하기·다음 레벨을 고릅니다. 같은 방문에서 선택하기 전에는 자동으로 이동하지 않습니다. 나갔다 다시 들어오면 완료 화면 대신 마지막으로 하던 레벨의 새 판을 엽니다. 다음 레벨을 고르지 않고 나가면 마지막 완료 레벨에서 시작하며, 이전·지금·다음 레벨을 고른 뒤 나가면 선택한 레벨에서 시작합니다. 1단계에서는 이전 레벨, 200단계에서는 다음 레벨을 선택할 수 없습니다.

공식 순위는 기존 캐주얼 게임 기록 API를 사용합니다. 시간은 1/100초 단위로 변환하며 보상 없이 미검증 기록으로 저장합니다. 기존 단계별 저장 기록을 보존하며 게시판과 게임 안의 공식 순위는 모두 종합 순위로 표시합니다.

힌트는 1회 3쭈, 직접 섞기는 1회 10쭈입니다. 로그인한 사용자의 공용 지갑에서 서버가 차감한 뒤 실행하며, 중복 클릭·통신 재시도는 같은 요청 ID로 확인합니다. 확인 대기 중인 구매는 원래 계정·요청 ID·단계·실행 ID로 확인하며, 확인한 효과는 새 판에 한 번 적용합니다. 이전 게임판과 시간은 복원하지 않습니다. 잔액 부족·비회원은 유료 기능을 실행하지 않으며, 막힌 판의 자동 재배치는 무료입니다.

두 손가락 확대·축소와 트랙패드 핀치는 게임판에만 적용합니다. 확대 후 한 손가락으로 이동할 수 있고, 조작 버튼과 상태 표시는 고정됩니다. 전체 버튼으로 화면 맞춤 상태로 돌아갑니다.
