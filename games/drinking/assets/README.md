# Drinking result glass

`result-glass-v2.webp` is the transparent glass artwork for the individual drinking-game result dialog.

- Created with the built-in image generation tool on 2026-11-14.
- Art direction: a photoreal, empty, heavy crystal lowball tumbler; frontal and symmetric; cool white reflections on the left and a restrained amber reflection on the right; transparent bowl and background; no liquid, ice, logo, caption, drawn outline, or table.
- Source: 1254 × 1254 RGBA PNG. Delivered as WebP at quality 92 with the original alpha channel preserved byte-for-byte.
- The liquid, lighting, and one-shot draining motion are presentation layers. They never calculate or submit game results.
- Keep the image and liquid in the same 1254 × 1254 SVG coordinate system. The outer viewBox crops only empty transparent padding at render time.
