# 술게임 문장 기준

문항 수를 채우는 것보다, 참가자가 한 번 읽고 무엇을 해야 할지 알 수 있는지를 먼저 확인한다. 문장별로 뜻과 게임 방식을 확인하며 고친다.

| 게임 | 문항의 역할과 말투 |
| --- | --- |
| 왕게임 | 번호를 받은 사람이 바로 수행할 짧은 명령. 두 사람 미션은 `둘이 `로 시작한다. |
| 손병호 | 해당 여부를 바로 판단할 한 가지 조건과 `접어`. 예: `흰 티 입은 사람 접어`, `목걸이 한 사람 접어`, `일주일 안에 키스한 사람 접어`. 옷차림·현재 상태·명확한 경험을 묻고, 토론이나 남의 속마음 추측을 요구하지 않는다. |
| 진실게임 | 여럿이 있는 술자리에서 한 사람이 자기 경험·선택·비밀을 솔직하게 답하는 짧은 질문. 커플끼리 관계를 상담하거나 둘의 성생활을 비교하는 문항은 넣지 않는다. 이 자리의 누군가를 고르더라도 본인의 마음과 선택을 묻고, 다른 사람의 사생활을 추측하거나 폭로하게 하지 않는다. |
| 소수파 | 한 번에 비교할 수 있는 두 선택지. 같은 기준과 비슷한 문장 구조로 쓴다. |
| 다른 미션 | 말과 소품 없이 혼자 몸짓으로 보여줄 행동 두 가지. 두 동작의 차이가 눈에 보여야 한다. |
| 이미지게임 | 어떤 행동을 할 것 같은 사람을 고르는 질문. 실제 사생활을 사실로 단정하지 않는다. |
| 시간폭탄 | 바로 여러 답을 댈 수 있는 이름·종류·물건 범주. 이유나 의견을 설명하게 하지 않는다. |
| 라이어 | 누구나 뜻을 이해하고 힌트를 말할 수 있는 단어. 정답을 드러내는 설명은 붙이지 않는다. |
| 초성 | 실제로 쓰는 두 글자 단어. 참가자에게는 초성만 보여주며 기존 5초 규칙을 유지한다. |

## 문장별 검토

- 실제 술자리에서 소리 내어 읽어도 자연스러운 말을 쓴다.
- 추상적인 표현보다 구체적인 말을 쓴다. 예: `친밀감의 속도` → `스킨십 진도`.
- `가상의`, `상상 속`, `설정으로`, `실제나 상상으로`를 습관처럼 붙이지 않는다. 상황극은 상황과 역할만 읽어도 알 수 있게 쓴다.
- 불필요한 수식어와 반복 지시를 덜어내되, 선택지·역할·동작·시간 조건은 흐리지 않는다.
- 성인용 질문의 솔직한 분위기를 유지하면서 노골적인 성행위 묘사나 원치 않는 접촉을 요구하지 않는다. 동의·패스 안내는 게임 화면에서 유지한다.
- 띄어쓰기만 바꾼 중복뿐 아니라, 같은 뜻을 다른 말로 반복한 항목도 확인한다.

## 적용 방식

각 JSON에는 바꾼 항목의 `from`과 `to`를 기록한다. 이미 적용한 원본과 SQL은 고치지 않는다. 새 SQL은 원문이 정확히 일치할 때만 문구를 수정하고, ID·활성 상태·진행 중인 방·투표·제한시간을 보존한다. 각 게임의 검토와 확인이 끝난 뒤 다음 게임을 진행한다.
