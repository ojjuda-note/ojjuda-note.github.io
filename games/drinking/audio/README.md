# 술게임 효과음

`table-foley-v1.wav`는 24 kHz 모노 표본 묶음이다. 각 구간은 ../feedback.js의 clips에 초 단위로 적혀 있다. 카드, 유리잔, 나무, 금속 소리를 장면에 맞게 자르고 음량을 맞췄다.

- 카드와 칩은 Kenney의 [Casino Audio](https://kenney.nl/assets/casino-audio), 유리와 나무는 [Impact Sounds](https://kenney.nl/assets/impact-sounds), 금속은 [RPG Audio](https://kenney.nl/assets/rpg-audio)에서 가져왔다. 모두 CC0.
- 발사음과 폭발음에는 steveygos93의 [Explosion2](https://freesound.org/s/80401/)를 TumeniNodes가 편집한 [Minetest Game의 tnt_explode](https://github.com/minetest/minetest_game/tree/master/mods/tnt)를 사용했다. 두 구간은 속도와 잔향을 다르게 편집했다. CC0.
- 모양 맞추기의 귀신 등장음은 analogchill이 스튜디오에서 녹음한 [scream.wav](https://freesound.org/people/analogchill/sounds/35716/)의 첫 비명이다. 앞의 무음을 자르고 1.07초로 줄여 끝을 페이드아웃했다. CC0.
