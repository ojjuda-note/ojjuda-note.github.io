# 컴퓨터 상대 캐릭터

사용자가 제공한 두 참고 사진을 바탕으로 내장 image_gen 도구로 제작했습니다.
원본 사진은 저장소에 포함하지 않았습니다.

- `normal-v1.png`: 정면의 무심한 표정, 짧고 헝클어진 검은 머리, 긴 얼굴, 연한 파란 줄무늬 셔츠를 유지한 고화질 게임용 초상. 투명 배경, 얼굴과 어깨만, 글자와 소품 없음.
- `surprised-v1.png`: 기본 초상의 인물·그림체·의상·크기를 유지하고 첫 번째 참고 사진처럼 눈을 크게 뜨고 입을 벌린 놀란 표정으로 변경. 투명 배경 유지.

두 PNG는 생성된 1254 × 1254 RGBA 원본을 변환 없이 사용합니다. 기본 표정은 컴퓨터 상대에게만 표시하며 화풀이 타격 시 놀란 표정으로 전환하고 연출 종료·취소 시 복구합니다.
