# 종합 점괘 원문 작성 기준

## 실제 원문과 조합 수 구분

- 목표는 **실제로 작성된 독립 원문 2,560개**이다. 이 숫자는 작업 목표이며, 검증 전 완료 수가 아니다.
- 분야별 640개를 각각 별도의 한마디·본문·행동 조언으로 작성한다.
- 카드 배열의 수, 문장 조합의 수, 동의어 교체의 수는 원문 개수에 포함하지 않는다.
- 조합용 짧은 문장들을 프로그램으로 이어 붙여 원문을 생성하지 않는다.
- 원문은 각 상황에 맞는 판단, 어려움, 구체적인 선택을 담아 따로 작성한다.
- 기존 카드 설명과 원문의 적용 조건을 구분한다. 실제 카드의 뜻·위치에 맞지 않는 원문을 무작위로 붙이지 않는다.

## 적용 조건

첫 번째 카드가 비추는 마음(키의 첫 자리):

0 새 출발·호기심 / 1 바람·선택 / 2 불확실함·걱정 / 3 애착·익숙함 / 4 책임·부담 / 5 피로·정체 / 6 상처·실망 / 7 자립·거리 / 8 자신감·성과 / 9 재검토·깨달음

두 번째 카드가 비추는 흐름(키의 둘째 자리):

0 제안·기회 / 1 만남·교류 / 2 확인·발견 / 3 충돌·어려움 / 4 지연·기다림 / 5 도움·협력 / 6 변화·전환 / 7 결실·마무리

세 번째 카드가 전하는 조언(키의 셋째 자리):

0 작게 시도하기 / 1 분명히 묻고 확인하기 / 2 한계·기준 지키기 / 3 도움을 주고받기 / 4 속도 낮추기 / 5 내려놓고 정리하기 / 6 꾸준히 익히기 / 7 받아들이고 소중히 여기기

이 적용 조건은 원문을 찾기 위한 분류다. 분류명이나 그 조합은 작성한 원문으로 세지 않는다.

## 원문 형식

각 파일은 ES 모듈이다. 각 행은 `["조건키", "한마디 정리", "종합 본문", "구체적인 행동 조언"]`이다.

- 한마디: 24~65자. 쉬운 말로 핵심 선택을 먼저 전한다.
- 종합 본문: 110~190자, 최소 3문장. 세 조건이 함께 작용하는 하나의 이야기를 쓴다. 카드별 설명을 나열하지 않는다.
- 행동 조언: 35~80자. 당장 할 수 있는 구체적인 행동이나 확인 방법을 제시한다.
- 모든 본문은 다른 원문과 별도로 작성한다. 문장 전체를 반복해 수를 채우거나 단어만 교체하지 않는다.
- 불편한 의미와 주의점도 숨기지 않는다. 모든 결과를 막연한 위로나 성공 이야기로 바꾸지 않는다.
- 타로는 상징을 해석하는 콘텐츠다. 예언·사실 확인·전문 상담처럼 표현하지 않는다. 사건, 금액, 상대의 마음이나 미래를 확정하지 않는다.
- 연애는 상대의 선택과 동의를 존중한다. 금전은 투자 수익·당첨·큰 지출을 보장하거나 부추기지 않는다.
- 신비로운 분위기는 유지하되 일상적인 말과 구체적인 장면을 사용한다.

## 배포 전 검수

실제 행 수, 서로 다른 원문 수, 완전 중복, 문장 재사용, 높은 유사도, 조건 누락, 실제 카드·순서 적용, 저장된 점괘의 재현성을 검사한다. 작성량과 검수 결과를 기록하며 완료하지 않은 수량을 홍보하지 않는다.
