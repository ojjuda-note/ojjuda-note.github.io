# 달의 마녀 타로 — 해석 자료와 집필 기준

## 무엇을 원문으로 세는가

원문 한 건은 파일에 따로 집필해 저장한 `조건키 · 한마디 · 종합 본문 · 행동 조언` 한 행이다. 카드 배열의 수, 문장을 조합해서 만들 수 있는 결과의 수, 카드별 설명을 덧붙인 결과는 원문 수에 더하지 않는다.

이 릴리스에는 전체운·연애운·금전운·일과 도전 각각 640건, 합계 2,560건을 작성했다. 실제 파일 검사 결과는 `audit.json`으로 확인한다. 원문 파일은 배열 리터럴이며, 공통 문장 은행을 이어 붙여 원문 수를 늘리는 생성기는 사용하지 않는다. 요청된 5,000건을 모두 채웠다고 표시하지 않는다.

이 자료는 **오쭈다가 작성한 상징 해석과 생활 적용 예시**다. 전통 원전에 2,560개의 이러한 점괘가 수록되어 있다는 뜻이 아니며, 실제 미래를 검증한 정보도 아니다.

## 카드와 원문이 연결되는 방식

첫째 자리는 지금의 마음, 둘째 자리는 살펴볼 흐름, 셋째 자리는 선택의 조언으로 읽는다. 각 카드가 해당 자리에서 강조하는 의미를 `../spread-patterns.js`에 명시했다. 의미 분류는 원문을 고르는 편집 기준이며, 카드의 뜻 전체나 유일한 전통 해석을 대신하지 않는다.

첫 자리의 10가지 마음, 둘째 자리의 8가지 흐름, 셋째 자리의 8가지 조언에 맞춰, 분야별로 **실제로 작성된** 원문을 찾는다. 이 분류의 곱을 계산했다는 이유로 원문이 있다고 간주하지 않는다. 각 키에 대응하는 원문 행이 모두 존재해야 앱을 시작할 수 있다.

선택한 원문의 한마디·종합 본문·행동 조언에 실제 세 카드의 구체적인 의미와 주의점을 함께 제시한다. 같은 의미 분류에 속하는 다른 카드들은 종합 원문을 공유할 수 있다. 이 경우에도 실제 카드별 의미는 결과에 반영되며, 공유된 원문을 새 원문으로 다시 세지 않는다.

같은 콘텐츠 버전에서 **같은 세 카드·같은 여는 순서·같은 분야**는 같은 해석을 돌려준다. 다시 열기나 복사할 때 관련 없는 문장을 무작위로 바꾸지 않는다. 무작위 카드 추첨과 해석 원문 선택은 별개다. 매번 반드시 새로운 원문이 나온다고 보장하지 않는다.

입력이 빠졌거나 알려지지 않은 카드라면 다른 카드로 대신 채우지 않는다. 원문 누락도 공통 문장으로 대체하지 않고 오류로 처리한다.

## 참고 자료와 오쭈다의 해석 구분

- A. E. Waite, *The Pictorial Key to the Tarot*:
  - [Part II — 주요 카드의 상징](https://en.wikisource.org/wiki/The_Pictorial_Key_to_the_Tarot/Part_2)
  - [Part III — 네 무늬의 카드와 전통 점술 의미](https://en.wikisource.org/wiki/The_Pictorial_Key_to_the_Tarot/Part_3)
- `../card-foundations.js`는 전통 그림을 참고한 한국어 설명과 현대 생활에 적용한 주의점이다. 원문 전체의 번역이나 전통 해석의 완전한 목록이 아니다.
- 원전 안에서도 서로 엇갈리는 뜻이 소개된다. 해석의 차이를 숨기거나 하나의 풀이를 사실 확인으로 제시하지 않는다.
- 별·컵 6·컵 8·소드 7·펜타클 7에는 원전이 소개한 다른 풀이와 이 앱이 중심에 둔 해석을 따로 펼쳐 볼 수 있다. 해당 설명은 Part III의 정방향 항목을 참고한다.
- 낯선 카드 이름은 쉬운 말로 풀이한다. 완드·컵·소드·펜타클에 붙인 생활 주제 안내는 이 앱의 읽기 방식이며, 각 무늬가 오직 그 뜻만 가진다는 설명이 아니다.
- 이 게임은 정방향만 사용한다. 궁정 카드는 특정 성별·나이의 사람이라고 단정하지 않고 태도와 역할로 읽는다. 세 자리의 역할과 분야별 상황 예시는 이 앱을 위한 편집 방식이다.
- 개별 카드 화면은 상징 설명, 자리와 주제에 따른 풀이, 생활 예시, 주의점을 구분하고 참고 자료 링크를 제공한다. 종합 화면은 한마디를 먼저 보여 주며 카드별 설명을 다시 나열하지 않는다.
- 각 단원은 제목 → 핵심을 먼저 말하는 소제목 → 상세 내용으로 표시한다. 문단을 나누거나 핵심을 앞으로 옮긴 결과를 새 원문 수에 더하지 않는다.
- 상실·갈등·부담·정체 등 불편한 상징도 남긴다. 실제 사고, 수익, 이별, 상대의 속마음을 확인했다는 문구로 바꾸지 않는다. 카드의 상징은 미래 예측의 정확도를 입증하지 않는다.

## 검수와 재현

```sh
node scripts/audit-tarot-corpus.cjs --output games/moonlit-tarot/fortune-corpus/audit.json
node tests/tarot-corpus.test.cjs
node tests/tarot-ui.test.cjs
```

검사는 실제 행 수와 서로 다른 본문 수, 키의 누락·중복, 한마디·본문·행동 길이, 완전 중복, 문장 전체의 반복, 높은 문자 유사도를 확인한다. 높은 유사도는 검토 신호이며, 수치가 낮다고 의미까지 모두 독창적이라는 뜻은 아니다. 표본을 읽는 편집 검토와 함께 사용한다.

카드 연결 검사는 세 장을 뽑아 순서를 정하는 456,456개 배열이 해석 키에 도달하는지 확인한다. **456,456은 검사한 카드 배열 수이며, 집필한 원문 수가 아니다.** 카드·순서·분야를 바꿀 때의 차이, 같은 배열의 재현성, 잘못된 입력의 거절도 검사한다. 이 검사는 해석 연결의 정확성을 다루며 미래 예측의 정확성을 측정하지 않는다.
