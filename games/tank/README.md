# 오쭈다 탱크게임

사용자가 제공한 `tank-game.zip`의 화면·조작·포탄·지형 물리를 컴퓨터 대전과 온라인 2~12인 게임으로 연결했다.

## 이용

오락실 → 멀티 게임 → 탱크게임. 시작 화면은 공통 `game-entry.css`의 흰 카드·보라색 버튼을 사용하고, 혼자 하기 / 같은 기기 / 온라인 대전을 고른다.

혼자 하기는 로그인한 회원 1명과 컴퓨터 1~11명이 대결한다. 컴퓨터는 서버에서 바람·지형에 맞춰 무료 기본탄만 발사한다. 매 발 5% 확률로 정밀 조준하고, 나머지는 각도와 힘을 크게 빗나가게 한다. 빗나가는 탄은 실제 물리로 미리 계산해 산탄·폭발·낙하로 우연히 맞는 경우도 줄인다. 차례가 지나도 정확도가 올라가지 않는다. 컴퓨터 차례는 자동 진행하며 쭈를 차감하지 않는다. 내 특수탄은 온라인과 같은 가격이다. 차례 시간 제한이 없고 내 탱크가 파괴되면 끝난다. 그만하기로 처음 화면에 돌아오고, 종료 후 같은 상대 수로 다시 할 수 있다. 혼자 하는 방은 공개 목록·방 번호 입장에서 제외된다. 연결을 닫았다 다시 열면 24시간 이내의 진행 중 경기를 이어 할 수 있다.

같은 기기는 로그인한 회원 한 명의 기기에서 2~12명이 번갈아 조작한다. 시작 화면에서 인원을 고르면 바로 전투에 들어간다. 컴퓨터나 차례 시간 제한이 없으며, 첫 번째 플레이어가 탈락해도 남은 사람들이 계속한다. 모든 유료탄은 로그인한 계정의 쭈에서 차감한다. 방 번호 입장·공개 대전방·친구 초대·게임 순위에는 포함되지 않는다. 다시 하기는 같은 인원으로 시작한다.

온라인 대전은 로그인한 회원이 방을 만들거나 8자리 방 번호/열린 방 목록으로 참가한다. 방장이 2명 이상 모였을 때 시작한다. 게임 화면을 닫아도 다시 열면 진행 중인 방으로 복귀한다. 항복한 참가자는 관전한다. 90초와 직전 포탄 비행 시간 안에 차례를 완료하지 않으면 차례가 넘어가며, 3회 연속 놓치면 탈락한다.

| 탄 | 발사당 가격 |
|---|---:|
| 일반탄·대형탄·산탄 | 무료, 무제한 |
| 통통탄·굴착탄·흙폭탄·치료탄·이사탄 | 1쭈 |
| 분열탄·굴러탄 | 2쭈 |
| 핵탄·관통탄·유도탄·벙커버스터 | 3쭈 |

탱크는 기존보다 15% 크게 그리며, 포구 위치와 명중 판정도 같은 크기를 사용한다. 핵탄을 제외한 모든 포탄의 효과 반경은 20% 확대한다. 분열탄의 자탄·관통탄의 후속 폭발·흙폭탄·치료탄도 포함하며 기본 피해량과 가격은 유지한다. 유도탄의 적 탐색 반경은 기존 핵탄 반경 200을 사용하고 폭발 반경만 커진다.

핵탄은 노란 방사능 표식이 있는 발사체와 궤적으로 구분되며, 비행 중에는 실제 탄 이름이 표시된다. 핵탄은 원래의 큰 폭발 범위(반경 200)로 터지며, 강한 피해와 발사당 3쭈 가격을 유지한다.

맵 밖에서 터진 포탄도 실제 폭발 중심과 반경을 사용한다. 폭발 범위가 전장 가장자리에 닿으면 해당 지형을 깎고 탱크에 피해를 준다. 흙폭탄은 닿는 땅을 쌓고 치료탄은 범위 안 탱크를 회복한다. 이사탄이 맵 밖에 떨어지면 이동하지 않는다. 먼 곳의 폭발은 지형에 영향을 주지 않으며 화면 안으로 옮겨 그리지 않는다.

벙커버스터는 표적탄의 탄착점에 하늘에서 수직 미사일을 호출한다. 표적탄은 피해나 지형 변화를 일으키지 않는다. 미사일은 바람에 밀리지 않고 같은 가로 위치로 내려와 좁은 통로(반경 8)를 뚫고 지표 아래 140까지 들어간 뒤 반경 86.4의 지하 폭발을 일으킨다. 맵 바닥보다 깊이 내려가지는 않는다. 기본 피해량은 일반탄과 같은 34이며, 비워진 지하 공간 위의 흙과 탱크는 기존 중력·낙하 피해 규칙을 따른다. 표적탄·미사일·지하 폭발은 한 차례, 한 발사 가격 3쭈로 처리된다. 화면에는 표적 조준점과 미사일 모양, 낙하·관통·지하 폭발 단계가 표시된다. 맵 밖의 탄착점도 실제 위치를 유지하고 지하 폭발 범위가 가장자리에 닿으면 땅을 깎는다.

낙하 피해는 기존 계산값의 5배다. 착지 속도 5 이하의 낮은 낙하는 피해가 없고, 그보다 빠른 착지는 `round((속도 - 5) × 4) × 5` 피해를 준다. 벙커버스터·다른 폭발로 땅이 무너지거나 이동하다 떨어질 때 모두 같은 규칙을 적용한다.

탱크 체력이 0이 되는 순간 불꽃·파편·효과음이 한 번 나온다. 화면 갱신이나 재접속으로 이미 파괴된 탱크를 다시 폭발시키지 않는다. 파괴 효과는 연출이며 추가 피해나 지형 파괴를 일으키지 않는다.

새 경기의 전장 가로 길이는 기존의 3분의 2다. 2~6명은 1,600, 7~9명은 2,133, 10~12명은 2,667 게임 좌표 단위를 사용한다. 맵 높이는 유지한다. 경기마다 가로 길이를 저장하며, 예전 저장 경기는 지형과 탱크 위치를 보존하기 위해 기존 크기로 이어간다.

바람은 매 차례 바뀌고 조준·충전·포탄 비행 중에는 고정된다. 연속으로 같은 바람이 나오면 먼저 뽑힌 세기 구간 안에서 다시 뽑아 구간별 확률을 유지한다. 서버가 경기별 날씨 시드·진행 위치·현재 바람을 저장하므로 모든 참가자와 재접속 화면이 같은 바람을 사용한다. 바람 세기는 0~10이며, 최대 물리적 힘도 이전의 절반이다. 0~3은 70%, 4~7은 20%, 8~10은 10% 확률로 나온다. 기존 저장 경기의 강한 바람도 새 최대치로 제한한다.

각도기를 누르거나 끌어서 0~180도를 직접 맞춘다. ◀ 버튼은 포신을 왼쪽으로, ▶ 버튼은 오른쪽으로 0.5도씩 기울인다. 파워는 − / + 버튼으로 1씩 조절하거나 버튼 위 파워 막대를 누르거나 끌어서 5~100 사이로 정한다. 각도·파워 버튼은 누르는 즉시 한 번 조절하고, 0.3초 이상 길게 누르면 0.06초마다 같은 간격으로 반복한다. 손을 떼거나 입력이 취소되면 멈추며, 화면 회전·창 이탈·탄 선택·차례 전환에도 반복을 중단한다. 각도기 방향키도 좌우 버튼과 같은 방향으로 0.5도씩 움직인다. 이전에 저장한 0.25도 단위 값도 그대로 보존한다. 맞춘 각도와 힘은 그대로 유지되고 발사 버튼을 누르면 설정한 값으로 한 발 나간다. 마지막 발사 각도와 힘은 플레이어마다 따로 저장하며, 다음 내 차례와 이어하기에서 그대로 복원한다. 새 경기에서 아직 발사하지 않은 탱크는 90도·힘 5로 시작한다. 비행·상대 차례에는 각도와 파워를 변경할 수 없다. 키보드 위/아래는 각도, 왼쪽/오른쪽은 탱크 이동이며, 각도기에 초점이 있으면 방향키로 각도를 조절한다.

무료 기본탄(일반탄·대형탄·산탄)은 플레이어마다 마지막 선택을 저장하고, 직접 바꾸기 전까지 다음 내 차례에 이어서 쓴다. 유료 특수탄은 한 번 발사한 뒤 기억한 기본탄으로 돌아간다. 저장된 경기에서도 선택을 복원한다.

휴대폰은 가로·세로 모두 플레이할 수 있다. 전체 화면 진입 시 화면 방향을 잠그지 않는다. 좁은 세로 화면은 상태·이동·조준 조작부를 아래쪽에 쌓고 게임 목록 버튼 공간을 남긴다. 회전하면 화면 크기와 카메라만 조절하며 지형·탱크·차례·선택한 각도와 파워는 그대로 유지한다.

## 운영 구조

- 진입: `world.html`, 지연 로딩: `world-game-assets.js`, 같은 출처 iframe 연결: `world-tank-game.js`.
- 클라이언트 `engine.mjs`와 Edge Function의 `engine.mjs`는 동일해야 한다. 서버만 명중·체력·지형·차례를 확정한다. 브라우저는 확정된 명령을 재생한다.
- `tank` Edge Function은 Auth로 회원을 검증한다. `tank_online_service` RPC는 `service_role`에만 허용된다. 방 상태는 RLS가 활성화된 비공개 스키마에 보관한다.
- 행 잠금과 상태 버전 확인을 거쳐 발사 결과·지갑 차감·구매 기록을 한 트랜잭션으로 반영한다. 재시도는 같은 요청 UUID를 사용한다. 잔액 부족이나 충돌 시 게임과 지갑 모두 변경하지 않는다.
- 2초 간격의 저장 상태 조회로 여러 기기를 동기화한다. 방장은 전투를 계산하거나 중계하지 않으므로 방장이 나가도 전투가 진행된다.
- 로그인 키와 세션은 기존 오쭈다 클라이언트가 관리한다. iframe에 토큰을 전달하지 않는다.
