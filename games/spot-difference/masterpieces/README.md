# 명화 틀린그림찾기 원본 출처

이 디렉터리의 `sources/`에는 미술관이 CC0로 공개한 JPEG 20점을 보관합니다. 원본 파일은 미술관이 제공한 바이트 그대로 저장했으며, 자르기·크기 변경·재압축·색 보정을 하지 않았습니다. 게임에서 사용하는 변형 이미지는 해당 원작을 바탕으로 만든 게임용 파생 이미지입니다.

메타데이터와 다운로드 URL, 원본 크기, 파일 용량, SHA-256은 [`../masterpiece-sources.json`](../masterpiece-sources.json)의 `artworks` 배열에 있습니다. 한국어 제목은 게임 표시용 번역이며, 미술관이 제공한 제목과 작가명은 `originalTitle`과 `originalArtist`에 함께 기록했습니다.

## 이용 조건 확인

- 확인일: 2026-11-01.
- 메트로폴리탄 미술관 19점: 각 작품 API에서 `isPublicDomain: true` 및 `primaryImage` URL을 확인했습니다. [Open Access 정책](https://www.metmuseum.org/hubs/open-access)은 공개 대상 이미지와 기초 메타데이터의 CC0 재사용 및 변형을 허용합니다.
- 클리블랜드 미술관 1점: 작품 API에서 `share_license_status: "CC0"`를 확인했습니다. [Open Access 정책](https://www.clevelandart.org/open-access)과 [작품 페이지](https://www.clevelandart.org/art/1960.81)에서 재사용·변형 허용을 확인했습니다. 제공되는 `print` JPEG를 그대로 저장했습니다.
- 라이선스: [CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/). 미술관의 게임 승인이나 보증을 의미하지 않습니다.
