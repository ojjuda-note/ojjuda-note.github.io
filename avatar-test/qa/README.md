# 아바타 의상 검수

검수 단위는 **착용 조합 하나와 포즈 하나**다. 승인 목록은 `approved-fits.json`에 있다. 같은 옷도 색상, 함께 착용한 아이템, 포즈가 달라지면 별도 조합으로 취급한다.

2026년 11월 25일에 추천 코디 15개와 추가 착용 조합 6개를 기본·청순·귀염·섹시·발랄·미니미에서 확인했다. 400×656 원화에서 목, 양쪽 어깨·팔꿈치·손목, 허리, 양쪽 허벅지·무릎·발목을 살폈다. 추가 조합은 셔링 원피스의 와인·미드나이트 블루, 기본 웨이브·앵클부츠 착용, 정장·트레이닝복의 니하이 부츠 착용이다.

세이지 니트와 크로스백에 조거 팬츠 또는 테이퍼드 슬랙스를 입힌 두 조합도 여섯 포즈에서 확인했다. 발랄 포즈에서는 치마를 입힌 원화와 비교해 무릎 바깥쪽의 옷감과 조거 옆줄이 이어지고, 무릎 안쪽에서 천이 접히며, 양쪽 발목이 부츠에 맞는지 확대해서 살폈다. 이전 126건 중 원화가 달라진 4건을 다시 검사했고, 두 조합을 더한 승인 목록은 총 138건이다.

## 다음 검사

```sh
python3 avatar-test/qa/check_fits.py
```

기본 코디와 원화 파일이 지난번과 모두 같으면 승인된 조합을 즉시 제외한다. 파일이 달라지면 Chromium에서 코디를 실제로 입혀 각 포즈의 RGBA 픽셀을 비교한다. 같은 조합의 픽셀이 그대로면 확대 검사를 건너뛴다. 신규 조합이나 한 픽셀이라도 달라진 포즈는 ‘확인 필요’로 출력하며 종료 코드는 1이다. 색상과 투명도도 비교한다.

사용자가 어색한 부분을 표시하면 픽셀이 같은 승인 건도 다시 연다. 지적된 옷과 포즈를 착용한 상태에서 원화와 나란히 비교한 뒤 승인 여부를 갱신한다.

렌더링에는 Python Playwright와 Chromium이 필요하다. 설치된 브라우저는 `--chromium 경로`로 지정할 수 있다. `--render`는 파일이 같아도 픽셀 지문을 검증한다. `--url https://ojjuda.kr/avatar-test/`는 배포본에서 추가 카탈로그까지 불러온다. 같은 Chromium 버전을 쓰면 브라우저의 색 변환 차이로 인한 재검사가 줄어든다.

추천 코디 밖의 조합은 `--cases 파일.json`으로 함께 검사한다. 예를 들어 아래처럼 조합을 지정한다.

```json
{
  "교복 · 니하이 부츠": {
    "look": "교복",
    "steps": [{"category": "신발", "item": "스웨이드 니하이 부츠"}]
  }
}
```

`--report 결과.json`은 확인할 조합과 새 지문을 기록한다. 검사기는 승인 목록을 수정하지 않는다. 추가·변경 조합을 확대 확인한 뒤에만 해당 포즈의 지문을 승인 목록에 반영한다. 해결되지 않은 조합이 남아 있으면 `completeSnapshot`을 `false`로 둔다. 전체 조합이 통과한 시점에만 파일 지문과 검수일을 갱신한다.

## 2026-11-25 재검수 — 니하이 부츠

사용자 화면에서 셔링 원피스의 허벅지 끝이 수평으로 잘리고 부츠 입구와 이어지지 않는 결함이 확인되었다. 종전 승인 중 니하이 부츠 6개 조합 × 6개 포즈(36건)를 재검수 대상으로 되돌렸다. `trimLegsAtBoots`의 직사각형 절단과 부츠 원화의 입구 윤곽/겹침을 각각 대조해야 한다. 픽셀 지문이 일치하더라도 이 결함은 통과시켜서는 안 된다.

```sh
python3 avatar-test/qa/check_fits.py --render --capture-dir /tmp/avatar-fit-review --report /tmp/avatar-fit-review/pending.json
```

`index.json`과 함께 원본 400×656 PNG와 보간 없는 4배 확대 PNG를 저장한다. 원본과 확대본을 나란히 확인하여 피부 절단, 빈틈, 관절 및 앞뒤 레이어 순서, 부츠 입구·무릎·발목 윤곽을 검사한다. 원화 보정 및 실제 착용 검증 전에는 승인 목록을 복원하거나 배포하지 않는다. 이 변경은 재검수 준비이며 원화 수정 자체는 포함하지 않는다.

## 추가 사용자 지적 — 골지 니트와 헤어

니트도 검수 제외하지 않는다. 클래식 플리츠 스커트와 버클 앵클부츠 두 디자인만 개별 아이템 재검사에서 제외하고, 다른 의상과 함께 착용한 전체 합성은 확인한다. 종전 추천 코디·추가 조합 138개 포즈의 승인을 전부 취소한다.

```sh
python3 avatar-test/qa/check_fits.py --all-items --render --capture-dir /tmp/avatar-all-fits --report /tmp/avatar-all-fits/pending.json
```

실제 UI 카탈로그의 모든 비제외 아이템·색상을 착용해 6개 포즈를 출력한다. 상의 및 원피스는 모든 헤어 디자인·색상과 장착 안 함 상태의 교차 조합도 검사한다. 특히 헤어 교체 시 원래 헤어에 가려진 목, 어깨, 쇄골, 가슴, 옷 가장자리의 투명 공백을 확인한다. 배경은 신체 연결 검수 대상에서 제외한다. 이는 검사 대상 선정 및 증거 수집이며, 픽셀 해시만으로 외형을 자동 승인하지 않는다.
