# 아바타 의상 검수

검수 단위는 **착용 조합 하나와 포즈 하나**다. 승인 목록은 `approved-fits.json`에 있다. 같은 옷도 색상, 함께 착용한 아이템, 포즈가 달라지면 별도 조합으로 취급한다.

2026년 11월 25일에 추천 코디 15개와 추가 착용 조합 6개를 기본·청순·귀염·섹시·발랄·미니미에서 확인했다. 400×656 원화에서 목, 양쪽 어깨·팔꿈치·손목, 허리, 양쪽 허벅지·무릎·발목을 살폈다. 추가 조합은 셔링 원피스의 와인·미드나이트 블루, 기본 웨이브·앵클부츠 착용, 정장·트레이닝복의 니하이 부츠 착용이다.

## 다음 검사

```sh
python3 avatar-test/qa/check_fits.py
```

기본 코디와 원화 파일이 지난번과 모두 같으면 승인된 조합을 즉시 제외한다. 파일이 달라지면 Chromium에서 코디를 실제로 입혀 각 포즈의 RGBA 픽셀을 비교한다. 같은 조합의 픽셀이 그대로면 확대 검사를 건너뛴다. 신규 조합이나 한 픽셀이라도 달라진 포즈는 ‘확인 필요’로 출력하며 종료 코드는 1이다. 색상과 투명도도 비교한다.

렌더링에는 Python Playwright와 Chromium이 필요하다. 설치된 브라우저는 `--chromium 경로`로 지정할 수 있다. `--render`는 파일이 같아도 픽셀 지문을 검증한다. `--url https://ojjuda.kr/avatar-test/`는 배포본에서 추가 카탈로그까지 불러온다. 같은 Chromium 버전을 쓰면 브라우저의 색 변환 차이로 인한 재검사가 줄어든다.

추천 코디 밖의 조합은 `--cases 파일.json`으로 함께 검사한다. 예를 들어 아래처럼 조합을 지정한다.

```json
{
  "교복 · 니하이 부츠": {
    "look": "교복",
    "steps": [{"category": "신발", "item": "스웨이드 니하이 부츠"}]
  }
}
```

`--report 결과.json`은 확인할 조합과 새 지문을 기록한다. 검사기는 승인 목록을 수정하지 않는다. 추가·변경 조합을 확대 확인한 뒤에만 해당 포즈의 지문을 승인 목록에 반영한다. 해결되지 않은 조합이 남아 있으면 `completeSnapshot`을 `false`로 둔다. 전체 조합이 통과한 시점에만 파일 지문과 검수일을 갱신한다.
